## Проверка документов

Проверочный script запускается Python из окружения проекта и читает только документы/контракты. Он сравнивает исходный inventory с immutable Git-версией начала подготовки, а актуальный inventory — с прочитанным снимком текущего YAML. Для новых документов применяется `git diff --no-index --check /dev/null <document>`; общий diff checkout не считается diff этой задачи из-за параллельных изменений.

Проверяемые условия:

1. Все 50 исходных operationId/method/path перечислены один раз; единственная снятая операция — создание обзора. Все 49 текущих операций имеют целевой маршрут.
2. Целевой реестр содержит 55 уникальных method/path: текущие 49, дополнительная операция создания сессии, четыре дополнительных операции после разделения уровней настроек и чтение receipt.
3. Все 77 исходных component schemas перечислены один раз; 72 текущие схемы покрыты, пять снятых отмечены явно: CardSource, DigestRequest, Event, ReviewRestart, DigestCreated.
4. 13 отдельных тикетов имеют статус/label, описание результата, критерии и проверки. Все внутренние зависимости существуют, циклов нет. Внешняя зависимость обозначена отдельно и не объявляется выполненной.
5. Все локальные Markdown-ссылки существуют. В спецификации присутствуют все семь разделов шаблона и 42 пронумерованные истории.
6. В новых документах нет whitespace errors и выполненных checklist-пунктов задач. Имена удалённых функций встречаются только как исходный контекст, снятые элементы или явный запрет их возвращения.

Окончательный прогон: `.venv/bin/python /tmp/oko-independent-api-doc-check.py` — PASS. Проверены исходные 50/77, текущие 49/72, целевые 55 операций, 13 задач, 17 документов, DAG, локальные ссылки, whitespace, семь разделов шаблона и 42 истории. В предварительном прогоне исправлена трактовка exit code 1 у `git diff --no-index` для нового файла; затем обнаружены и удалены лишние пустые строки в конце документов.

Прочитанный снимок текущего canonical YAML сохранён в `/tmp/oko-independent-api-observed-openapi.yaml`; SHA-256 `f344a3c71d5c8dafac1154bfe81289ecaf051278614f813f192bb137ae2a9fe5`, наблюдавшийся HEAD `b0db07d870c148177c72e3019ea853158d289873`. Это фиксация входа проверки, не обещание неизменности параллельно редактируемого checkout.

## Ограничения

- Ранняя сверка 50/77 прошла; повторная сверка против живого checkout обнаружила переход к 49/72 и завершилась assertion failure. Документы актуализированы, финальная проверка использует отдельные исходный и текущий snapshots. Это отказ предположения об неизменном checkout, не ошибка тестируемого API.
- Общий snapshot diff включал большой объём параллельных изменений; они не включались в файлы этой задачи, не откатывались и не использовались как наши результаты.
- Код приложения, canonical OpenAPI, baseline, генераторы, generated-библиотеки, тесты и действующие архитектурные документы этой задачей не изменялись. Изменения ограничены новым каталогом спецификации.
- Тесты приложения, генерация, HTTP/Playwright и typecheck в ходе подготовки документов не запускались. Результаты предыдущего ревью относятся к той версии, а не к будущему API 3.0.0.
- Работоспособность будущего API и окончание внешней миграции не утверждаются. Ни задачи реализации, ни коммит, ни запуск личных источников, ни публикация/перезапуск не выполнялись.
