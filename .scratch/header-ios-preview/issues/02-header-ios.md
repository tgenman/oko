# 02: Шапка Око в стиле iPhone

Type: task
Status: done
Label: ready-for-agent
Blocked by: None (can start immediately)

**Основание:** [Спецификация](../spec.md), разделы о шапке и панели состояния. Разбиение согласовано пользователем 2026-10-14.

**What to build:** читатель видит название и логотип «Око» и все шесть действий на одном уровне, а ход работы — отдельной строкой ниже. Оформление следует текущему прототипу A: белые группы кнопок с цветными иконками, отдельная кнопка состояния и красное действие остановки. Обновление источников, подключение фида, управление фидами и папками, настройки, панель состояния и остановка сохраняют действующее поведение.

**Blocked by:** None (can start immediately). Оформление карточек не требуется для завершения этой задачи. Существующий прототип — источник контекста, а не блокирующая задача реализации.

## Acceptance criteria

- [x] На широком экране бренд и все действия выровнены по вертикальному центру одного ряда; короткий или длинный статус расположен ниже и не вытесняет кнопки на второй уровень.
- [x] Группы кнопок и иконки соответствуют варианту A; названия действий, доступные имена, обработчики и состояния доступности сохранены. Изменения стилей ограничены шапкой и не меняют вёрстку карточек, область открытого материала или формы настроек.
- [x] На узком экране все действия доступны горизонтальной прокруткой верхнего ряда и клавиатурой. Статус переносится внутри своей строки; страница не получает горизонтальное переполнение из-за шапки. Действия не заменены скрытым меню.
- [x] Кнопка состояния показывает действующие значения «Проблемы · N», «Состояние», «Нет связи с Око» и «Око остановлено». Число проблем и текст хода работы динамические; обычный ход работы не оформлен как предупреждение.
- [x] Панель состояния открывается и закрывается прежним способом, возвращает фокус и сохраняет журнал диагностики и переходы к настройкам. На широком экране верх панели учитывает фактическую высоту новой шапки; на узком сохраняется существующее полноэкранное представление.
- [x] Действия шапки проверены через существующий браузерный интерфейс читателя с временным HTTP-сервером и синтетическими данными: обновление, открытие добавления и настроек, состояния кнопки проблем, открытие/закрытие панели и подтверждённая остановка.
- [x] Playwright проверяет выравнивание, длинный статус, горизонтальную доступность кнопок, фокус и положение панели на широком и узком экранах. Сохранены и просмотрены скриншоты исходного и нового вида на одинаковых данных и размерах браузера, включая открытие панели. Computer Use не используется без специального явного разрешения пользователя.
- [x] Выполнены затронутые браузерные проверки панели состояния и регрессия списка материалов, проверен diff. Результаты, команды, скриншоты и ограничения записаны отдельно; проверки прототипа не выданы за проверки реализации.

## Ограничения

Не менять выполнение команд, черновики настроек, классификацию проблем, хранение или обработку. Строка хода работы пока остаётся под кнопками: будущий перенос не входит в задачу. Кнопка «Убрать статус», переключатель A/B/C, демонстрационные диалоги и примерные значения макета не переносятся в продукт. Реализация начинается по отдельному указанию пользователя.
