# 03: Оформление карточек без изменения вёрстки

Type: task
Status: done
Label: ready-for-agent
Blocked by: None (can start immediately)

**Основание:** [Спецификация](../spec.md), разделы о сохранении карточек и визуальных проверках. Разбиение согласовано пользователем 2026-10-14.

**What to build:** список карточек получает нейтральное оформление в стиле настроек iPhone: цвета фона, текста, разделителей, выделения, наведения и фокуса. Читатель продолжает пользоваться текущими непрерывными строками с превью слева, текстом справа и разделителями дат. Размеры, плотность, порядок сведений и действия списка сохраняются.

**Blocked by:** None (can start immediately). Новая шапка не требуется для завершения этой задачи. Общие стили не создают продуктовой зависимости: изменения ограничиваются списком карточек.

## Acceptance criteria

- [x] Сохранён состав строки-кнопки: превью слева; справа заголовок, необязательное состояние, необязательный фрагмент текста, источник и дата. Карточки не превращены в отдельные плитки; сведения не перемещены и не скрыты ради оформления.
- [x] Геометрия соответствует текущему списку: превью 76×76 px, отступ строки 16 px, промежуток 12 px, минимальная высота 112 px. Сохранены размеры шрифтов, межстрочные интервалы, насыщенность, двухстрочные ограничения заголовка и фрагмента, правила обрезки и переноса источника и даты.
- [x] Сохранены нижние разделители строк, разделители дат, заголовок области, отдельный счётчик и меню списка. Не добавлены промежутки между карточками или внешние скруглённые контейнеры; скругление превью остаётся текущим.
- [x] Меняются только визуальные свойства, описанные спецификацией. Вторичные сведения читаемы; выбранная строка, наведение и клавиатурный фокус различимы. Изменения не затрагивают оформление шапки, открытого материала или вложенных форм.
- [x] Сохранены текущая сетка читателя, два разделителя ширины, ширина списка по умолчанию 440 px, пользовательская настройка и существующее приспособление к доступному пространству. Реальные превью не заменены синтетическими изображениями из макета.
- [x] Прежние действия выбора мышью и клавиатурой, сортировка, счётчики, состав чтения и смысл «Просмотрено» сохранены. Обновление данных не сбрасывает выбранную ширину, фокус или положение прокрутки; поздние ответы и превью не меняют другую область чтения.
- [x] Через Playwright проверены длинные заголовки, фрагменты и имена источников, состояния «Изменено» и «Загружается», отсутствие превью, событие и обзор. Проверки используют существующий браузерный интерфейс читателя с временным HTTP-сервером и синтетическими данными.
- [x] На одинаковых данных, размерах браузера и ширине списка Playwright снимает скриншоты до и после правки; сохранение геометрии проверено, скриншоты просмотрены. В артефактах видны карточки в контексте читателя, список при штатной ширине и выбранная строка. Computer Use не используется без специального явного разрешения пользователя.
- [x] Выполнены затронутые браузерные проверки списка материалов, проверен diff. Команды, результаты, скриншоты и ограничения записаны отдельно; исторические результаты проверки прототипа сохранены и не заменяют приёмку реализации.

## Ограничения

Не менять вёрстку и плотность карточек, дерево чтения, открытый материал, состав чтения, сортировку, фильтрацию, сбор, обработку или хранение. Не вводить настройки оформления или переключаемые темы A/B/C. Если оформление прототипа расходится с текущей геометрией карточек, сохранять геометрию. Реализация начинается по отдельному указанию пользователя.
