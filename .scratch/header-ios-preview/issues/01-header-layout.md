# Шапка Око в стиле настроек iPhone

Type: prototype
Status: open

## Вопрос

Как разместить все действия на одном уровне с логотипом «Око», а строку состояния — отдельно под ними? Строка состояния в будущем переедет в другое место. Визуальный ориентир — настройки iPhone.

## Прототип

[Исходник](../../../frontend/header-ios-prototype.html) — отдельный throwaway HTML рядом с существующими UI-прототипами. Использует stylesheet читателя и синтетический контекст из трёх колонок; не подключает приложение и API. Варианты доступны на одной странице через `?variant=A|B|C`, стрелки нижней панели и клавиатуры. Состояние раскрывается в «Состояние макета».

Запуск из корня checkout:

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory frontend
```

Открыть: http://127.0.0.1:8766/header-ios-prototype.html?variant=A

- A: две белые группы действий, цветные иконки, отдельные кнопки «Проблемы · 1» и остановки; ближе всего к группам настроек iPhone.
- B: свободная панель с синими текстовыми действиями и контурными иконками; статус отделён тонкой линией.
- C: одна белая группа со всеми действиями, разделители, без иконок.

Во всех вариантах бренд и действия выровнены по центру одной строки. Статус расположен ниже. «Убрать статус» позволяет оценить будущую шапку. На узком экране ряд действий прокручивается горизонтально вместо переноса на второй уровень.

## Уточнение карточек — 2026-10-14

Пользователь попросил сохранить существующую вёрстку и менять только дизайн. Прежние отдельные карточки с источником сверху заменены строками по актуальному DOM из `frontend/material-list.js`; геометрия берётся из `frontend/style.css`.

Сохранены: превью 76×76 слева, текстовый блок справа (заголовок, состояние, двухстрочный фрагмент, источник и дата), разделители дат, заголовок списка с отдельным счётчиком и меню, ширина списка 440 px, непрерывные строки без промежутков и внешних скруглений. Восстановлены пять колонок читателя, включая два разделителя. В прототипе карточек переопределяются только фон, цвет, цвет границ и фокуса. Изображения заменены синтетическими SVG-заглушками без подключения личных источников; тексты и даты взяты из предоставленного скриншота.

Фактическая проверка: настоящий браузер подтвердил ширину списка 440 px, превью 76 px, padding строки 16 px, промежуток 12 px. Показаны пять строк и пять разделителей дат. Проверены выбор второй и возврат к первой карточке и переключение A/B/C/A; вёрстка карточек общая для всех вариантов. `node --check`, ESLint `no-undef` и `git diff --check` прошли. Автоматические наборы продукта не запускались; правки остаются в прототипе.
