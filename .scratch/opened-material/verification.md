## Реализация

Основной текст открыт без callout; история A — отдельными свёрнутыми блоками ниже. При сокращении фильтром полный исходник той же ревизии раскрывается отдельно. Медиа не дублируются. Настройка Show Original Publication удалена из UI, поле API сохранено для совместимости.

Общий markdown-it 15.0.3 преобразует Markdown в React-элементы без вставки HTML. Ссылки проверяются после нормализации; переводы строк внутри подписи заменяются пробелом, внутри явно заданного адреса удаляются с отступами. Для reference-ссылки многострочный адрес требует явных `<…>`: иначе следующий абзац нельзя отличить от продолжения адреса. Код и окружающие абзацы сохраняются.
