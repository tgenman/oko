Реализовать четыре направления и исследование версий без изменения публичного HTTP-контракта. Один интеграционный PR; ручное обновление из #156/#157 не входит в задачу.

## Порядок

Локальные SQL-правки и пакетное чтение → компактный состав и массовое завершение. Состояние сбора и измерение версий независимы. Итоговая приёмка зависит от всех направлений.

## Критерии приёмки

- [x] Выборка заданий открытого материала не сканирует посторонний архив; новая миграция добавляет обратный индекс ссылок, старые миграции неизменны.
- [x] Факты фидов, карточек, связей и разрешений читаются ограниченными пакетами; снимок живёт только внутри синхронного чтения.
- [x] Сводка не читает тяжёлые диагностики, подробности ограничены выбранным фидом; общие правила состояния сохранены.
- [x] Preview сохраняет карточки, публикации и Telegram members без сборки полного представления; массовое завершение выполняет один расчёт достижимости после удаления принадлежностей, сохраняя атомарность и post-commit очистку.
- [x] Стоимость одного/шести вариантов списка измерена; новая модель версий не внедряется.
- [x] Выполнены HTTP, PostgreSQL, SQLite и Playwright проверки; сохранены фактические измерения и ограничения, независимые Standards/Spec ревью.
