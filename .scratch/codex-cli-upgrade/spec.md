# Актуальный CLI Codex для Око

Status: done

2026-10-13. Пользователь поручил перевести Око на актуальный CLI, проверить изоляцию и доступность актуальных моделей в настройках.

## Объём

- Использовать установленную актуальную сборку для диагностики, каталога и обработки; не выдавать встроенный каталог старого Homebrew CLI за актуальный.
- Сохранить допуск по точному хешу и внешнюю изоляцию, запреты инструментов, одноразовые задания, предварительную проверку лимитов и очистку временных копий.
- Проверить файловые запреты и синтетический запрос с новой сборкой, без личных материалов.
- Через настоящий HTTP и браузер подтвердить актуальные варианты для всех четырёх действий.
- Сохранённые настройки моделей и готовые результаты не менять автоматически. Прежние посторонние изменения checkout сохранить отдельно.

## Проверка

Использовать текущие HTTP/adapter/browser seams. Автоматические проверки — синтетические; реальная проверка CLI — только специально подготовленный синтетический вход и каталог, без личных подписок. Фактический результат записать в `docs/verification/codex-cli-upgrade.md`.

## Результат

Переход выполнен, изоляция и актуальные модели проверены. Фактические результаты и ограничения: [отчёт](../../docs/verification/codex-cli-upgrade.md).
