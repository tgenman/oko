# 04: Показывать сгруппированные ошибки API в долговечной нижней панели

Status: done
Approval: разбиение, зависимости и проверки согласованы 2026-10-12
Execution: реализация разрешена пользователем 2026-10-12

**What to build:** Пользователь открывает нижнюю диагностику из шапки и видит исключения HTTP API с контекстом и traceback. Повторы объединяются; последние 100 групп и счётчики сохраняются после перезапуска.

**Blocked by:** None

**Основание:** [Согласованная спецификация](../spec.md).

**Покрытие:** D01, D03, D04 (серверные возникновения), D05, D07 (серверная запись), D09 (журнал на диске).

## Acceptance criteria

- [x] Тоггл и число групп видны в шапке. Панель располагается снизу и сохраняет выбранную карточку, открытый материал и положение чтения.
- [x] Исключения HTTP API, включая обработанные ошибки действий и проверок запросов, фиксируются при закрытой панели.
- [x] Группа показывает контекст фида/операции, тип/сообщение, счётчик, первое/последнее время и раскрываемый traceback.
- [x] Группировка соответствует спецификации: одинаковый источник/операция, тип, сообщение и место возникновения; разные фиды остаются раздельными.
- [x] Повтор переносит группу наверх; прохождение одного сбоя через несколько границ не увеличивает счётчик искусственно.
- [x] Хранятся последние 100 групп по последнему возникновению; появление 101-й удаляет самую давно возникавшую. Перезапуск сохраняет данные группы.
- [x] Доступ к журналу требует текущую локальную сессию. Токены и учётные данные скрываются до сохранения/отображения, без переменных стека.
- [x] Чтение журнала доступно при неисправном основном хранилище; ошибка записи на диск отражается явно и не нарушает чтение/обработку.

## Testing Decisions

Через HTTP проверить обработанные и неожиданные ошибки, групповую идентичность, лимит, перезапуск, локальную защиту и недоступность диска; в браузере — тоггл, счётчик, порядок, раскрытие traceback и сохранность чтения. Этот путь самодостаточен без формы RSS.

Согласованные границы: публичный HTTP API читателя и существующий браузерный сценарий; утверждены вместе с разбиением. Проверки внутренних методов не являются приёмкой.

## Completion

Продемонстрировано поведение задачи и выполнены её критерии. Изменения не нарушают уже готовые ветви; согласованная спецификация определяет общие ограничения. Наличие преждевременного локального черновика не означает готовность задачи.
