# 02: Открывать существующий фид без дублей

Status: done
Approval: разбиение, зависимости и проверки согласованы 2026-10-12
Execution: реализация разрешена пользователем 2026-10-12

**What to build:** При повторном добавлении узнавать существующую подписку, показывать «Уже добавлен» и открывать её настройки. Повтор из двух вкладок также возвращает одну подписку.

**Blocked by:** 01: Проверить и добавить RSS/Atom по URL

**Основание:** [Согласованная спецификация](../spec.md).

**Покрытие:** U05.

## Acceptance criteria

- [x] Повторный URL распознаётся по существующим правилам идентичности подписок.
- [x] Форма показывает «Уже добавлен» и открывает настройки существующего фида.
- [x] Название, папка, транспорт, разрешения и остальные настройки не перезаписываются; лишняя папка не создаётся.
- [x] Повторная попытка и одновременное добавление одного источника из двух вкладок создают максимум одну подписку.
- [x] Повтор после перезапуска открывает ту же подписку с прежними настройками.

## Testing Decisions

Через HTTP проверить уникальность, сохранность настроек и конкурирующие запросы; в браузере — сообщение и переход к существующим настройкам. Новый отдельный механизм идентичности не вводить.

Согласованные границы: публичный HTTP API читателя и существующий браузерный сценарий; утверждены вместе с разбиением. Проверки внутренних методов не являются приёмкой.

## Completion

Продемонстрировано поведение задачи и выполнены её критерии. Изменения не нарушают уже готовые ветви; согласованная спецификация определяет общие ограничения. Наличие преждевременного локального черновика не означает готовность задачи.
