# Прототип открытого материала

Вопрос: как показывать актуальный текст как основное содержимое, а прежние версии — свёрнутыми ниже?
GitHub: не привязан. Пользователь выбрал A 21 октября 2026. Перенос не выполнен; сейчас разрешена только подготовка спецификации.

Спецификация выбранного поведения: [основной текст, история и Markdown](../opened-material/spec.md).

Запуск: `npm run prototype:material`.
URL: http://127.0.0.1:5187/?variant=A (также B и C).

- A: отдельный свёрнутый callout на каждую прежнюю версию.
- B: один свёрнутый callout со всей историей.
- C: шкала истории с отдельными свёрнутыми версиями.

Во всех вариантах актуальная версия — обычный открытый текст; ссылки показаны HTML-ссылками. Прототип использует подготовленный JSX, он не реализует Markdown parser для рабочего читателя. Данные синтетические, API не вызывается, действия рабочего shell отключены. Варианты переключаются стрелками и параметром URL. Код подключается только отдельным Vite dev-сервером; рабочий entrypoint не изменён.
