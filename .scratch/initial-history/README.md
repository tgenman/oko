# Начальная загрузка истории

Разбиение, зависимости и границы проверок согласованы пользователем. Реализация разрешена вызовом implement-spec и выполняется на интеграционной ветке codex/initial-history.

- [Спецификация](spec.md)
- [Решения проектирования и критерии приёмки](design.md)

| Задача | Блокируется | Проверяемый результат |
| --- | --- | --- |
| [01 — RSS/YouTube](issues/01-rss-youtube-history.md) | Нет | Выбор истории, загрузка, прогресс и перезапуск |
| [02 — Telegram](issues/02-telegram-history.md) | 01 | Оба режима, альбомы и восстановление |
| [03 — Пауза](issues/03-pause-history.md) | 01, 02 | Пауза истории при продолжающемся сборе новых публикаций |
| [04 — Исходы загрузки](issues/04-history-outcomes.md) | 01, 02 | Ошибки, повторные попытки и полнота |
| [05 — Ограничения RSS](issues/05-rss-history-limits.md) | 01 | Ограниченное окно, неизвестные даты и предупреждения |
| [06 — Совместимость](issues/06-existing-feeds.md) | 01, 02 | Старые фиды, повторное подключение и OPML |

Начальная доступная задача — 01. После неё доступны 02 и 05; после завершения 02 доступны также 03, 04 и 06. Нумерация не добавляет зависимостей между задачами, которые не перечислены в их Blocked by.

Проверки: существующий HTTP API читателя и браузерные действия; узкие проверки сборщиков для особенностей источников. Эти границы подтверждены вместе с разбиением.

При публикации задач родительская спецификация сохранялась без изменения согласно to-tickets. При начале implement-spec её состояние обновлено с учётом подтверждения проверок и разрешения на реализацию.
