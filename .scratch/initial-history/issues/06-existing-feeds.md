# 06: Существующие фиды и совместимость

**What to build:** Повторное подключение открывает существующий фид с сохранением его настроек и истории. Старые фиды показывают фактическую начальную границу вместо редактирования глубины, которое не расширяет историю.

**Blocked by:** 01 — Начальная история RSS/YouTube; 02 — Начальная история Telegram.

**Status:** ready-for-agent

- [ ] Повторное подключение существующего источника открывает его без дубля.
- [ ] Введённый при повторном подключении режим истории не изменяет прежнюю границу, набор, прогресс, паузу или настройки фида.
- [ ] Редактируемая «Глубина истории в днях» заменена информацией о начальной загрузке для существующих фидов.
- [ ] Старые фиды сохраняют существующую границу и курсор; обновление интерфейса и хранения не запускает повторную историю.
- [ ] Для старых данных отображаются только известные параметры истории; ранее не сохранённые количество и прогресс не выдумываются.
- [ ] OPML сохраняет прежнее поведение и не начинает требовать выбора новых параметров.
- [ ] Расширение истории существующего фида отдельным действием не добавляется.

**Проверки:** HTTP API читателя: повторное подключение, сохранение настроек и границы, перезапуск со старыми данными и OPML-импорт. Браузерный сценарий открытия существующего фида и отображения начальной истории.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history. Задача сохраняет существующую историю и правила подключения. Реализация требует отдельного разрешения пользователя.
