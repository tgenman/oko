# 06: Существующие фиды и совместимость

**What to build:** Повторное подключение открывает существующий фид с сохранением его настроек и истории. Старые фиды показывают фактическую начальную границу вместо редактирования глубины, которое не расширяет историю.

**Blocked by:** 01 — Начальная история RSS/YouTube; 02 — Начальная история Telegram.

**Status:** done

- [x] Повторное подключение существующего источника открывает его без дубля.
- [x] Введённый при повторном подключении режим истории не изменяет прежнюю границу, набор, прогресс, паузу или настройки фида.
- [x] Редактируемая «Глубина истории в днях» заменена информацией о начальной загрузке для существующих фидов.
- [x] Старые фиды сохраняют существующую границу и курсор; обновление интерфейса и хранения не запускает повторную историю.
- [x] Для старых данных отображаются только известные параметры истории; ранее не сохранённые количество и прогресс не выдумываются.
- [x] OPML сохраняет прежнее поведение и не начинает требовать выбора новых параметров.
- [x] Расширение истории существующего фида отдельным действием не добавляется.

**Проверки:** HTTP API читателя: повторное подключение, сохранение настроек и границы, перезапуск со старыми данными и OPML-импорт. Браузерный сценарий открытия существующего фида и отображения начальной истории.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history. Задача сохраняет существующую историю и правила подключения. Реализация требует отдельного разрешения пользователя.

**Результат:** Повторное новое подключение Telegram открывает существующий фид без изменения папки, auto_read или начальной истории; явное редактирование подключения по feed_id сохранено. Для старых фидов показаны только сохранённый первоначальный период и отсутствие исторического прогресса. Поле редактирования глубины удалено.

**Проверено:** 4 HTTP-сценария совместимости (RSS/Telegram, OPML/перезапуск, старый курсор без повторной истории), 1 браузерный сценарий, 23 существующих сценария настроек/Telegram.
