# 04: Ошибки и полнота материалов

**What to build:** Пользователь видит фактические исходы начальной загрузки: сохранённые, неполные, ожидающие повторной попытки и окончательно недоступные материалы. Ошибка отдельного материала не блокирует остальную историю.

**Blocked by:** 01 — Начальная история RSS/YouTube; 02 — Начальная история Telegram.

**Status:** done

- [x] «Загружено» отражает сохранённые материалы по обычным правилам источника, а не найденные ссылки или готовые тезисы.
- [x] Неполные материалы показаны отдельно от полных; доступное содержимое можно читать.
- [x] Временная ошибка повторяется с задержкой и не блокирует остальные материалы. Ожидание видно, например: «Загружено 19 из 20 · 1 ожидает повторной попытки».
- [x] Окончательная недоступность определяется по семантике источника, а не по одному временному сбою; она показана отдельно и не вызывает бесконечных повторов.
- [x] Недоступная публикация не заменяется другой за пределами выбранного набора.
- [x] История завершена, когда выбранные материалы сохранены либо отмечены окончательно недоступными; наличие неполноты остаётся видимым.
- [x] Готовность AI-обработки не задерживает завершение истории.
- [x] Исходы и ожидание повтора сохраняются после перезапуска. Подробности исключений доступны в существующей диагностике.

**Проверки:** HTTP API читателя с управляемыми временными ошибками, окончательным удалением, неполным материалом и незавершённой AI-обработкой. Браузерный сценарий прогресса и ошибок; проверки сохранения исходов после перезапуска.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history. Обычные правила полноты материала сохраняются; новая задача делает исходы истории наблюдаемыми. Реализация разрешена вызовом implement-spec и завершена.

**Validation:** 3 HTTP outcome scenarios passed (durable retry/partial/deleted, delayed recovery, terminal completion and rediscovery); browser outcome scenario passed; 51 existing history/source checks passed; mypy clean.
