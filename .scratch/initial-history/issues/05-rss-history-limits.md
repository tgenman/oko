# 05: Ограниченное окно и неизвестные даты RSS

**What to build:** Пользователь понимает ограничения начальной истории RSS/YouTube: видит доступный объём, неизвестную дату и предупреждение о точности выбора или полноте периода.

**Blocked by:** 01 — Начальная история RSS/YouTube.

**Status:** ready-for-agent

- [ ] Если из запрошенных 100 публикаций доступны 15, загружаются доступные и показано «Запрошено 100, доступно 15».
- [ ] В режиме даты ограниченное окно сопровождается предупреждением, что полнота истории за период не подтверждена.
- [ ] Отдельная загрузка архива YouTube не запускается; используются доступные записи текущего фида.
- [ ] RSS-запись без даты включается в режим даты и показывается с пометкой «Дата неизвестна», без выдачи времени загрузки за дату публикации.
- [ ] В режиме количества записи без даты учитываются по порядку фида, если новые записи идут первыми.
- [ ] Неоднозначный порядок сопровождается предупреждением, что точность выбора последних N не подтверждена.
- [ ] Повторный сбор и перезапуск не заменяют первоначальный набор публикаций новым окном фида.

**Проверки:** HTTP API читателя с ограниченным RSS/YouTube-окном, отсутствующими датами и изменением окна после первого сбора. Узкие проверки разбора даты и порядка при необходимости. Браузерный сценарий предупреждений и фактического объёма.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history. Объём доступного окна отличается от полноты архива источника. Реализация требует отдельного разрешения пользователя.
