# 02: Начальная история Telegram

**What to build:** При подключении Telegram пользователь выбирает последние N публикаций либо историю начиная с даты. Загрузка использует общий контракт начальной истории, сохраняет целые альбомы и продолжается после перезапуска.

**Blocked by:** 01 — Начальная история RSS/YouTube: общий контракт подключения, границы и состояния истории.

**Status:** done

- [x] Форма Telegram предлагает оба режима с теми же значениями по умолчанию и правилами валидации, что и RSS/YouTube.
- [x] Настройки истории сохраняются до первого сбора подключённого источника.
- [x] Последние N выбираются при первом успешном обращении и остаются неизменными во время порционного обхода.
- [x] Telegram-альбом считается одной публикацией и загружается целиком, в том числе на границе количества и порции.
- [x] Выбор истории темы форумной группы ограничен подключённой темой.
- [x] Новые публикации собираются дополнительно и не изменяют исторический набор или его прогресс.
- [x] Настройки фида показывают выбранную границу и прогресс; перезапуск продолжает ту же историю без дублей.
- [x] Существующие правила отметок чтения сохраняются.

**Проверки:** HTTP API читателя с управляемой историей Telegram; количество, дата, новые поступления и перезапуск. Браузерный сценарий подключения. Узкие проверки сборщика для альбомов на границе порций и отдельной темы форума.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history. Использовать общий контракт задачи 01 и обычные правила Telegram. Реализация разрешена вызовом implement-spec.

**Проверено:** HTTP, браузер и граница собственного Telegram worker; отчёт — ../verification/02-telegram-history.md.
