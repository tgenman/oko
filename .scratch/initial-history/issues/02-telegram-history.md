# 02: Начальная история Telegram

**What to build:** При подключении Telegram пользователь выбирает последние N публикаций либо историю начиная с даты. Загрузка использует общий контракт начальной истории, сохраняет целые альбомы и продолжается после перезапуска.

**Blocked by:** 01 — Начальная история RSS/YouTube: общий контракт подключения, границы и состояния истории.

**Status:** ready-for-agent

- [ ] Форма Telegram предлагает оба режима с теми же значениями по умолчанию и правилами валидации, что и RSS/YouTube.
- [ ] Настройки истории сохраняются до первого сбора подключённого источника.
- [ ] Последние N выбираются при первом успешном обращении и остаются неизменными во время порционного обхода.
- [ ] Telegram-альбом считается одной публикацией и загружается целиком, в том числе на границе количества и порции.
- [ ] Выбор истории темы форумной группы ограничен подключённой темой.
- [ ] Новые публикации собираются дополнительно и не изменяют исторический набор или его прогресс.
- [ ] Настройки фида показывают выбранную границу и прогресс; перезапуск продолжает ту же историю без дублей.
- [ ] Существующие правила отметок чтения сохраняются.

**Проверки:** HTTP API читателя с управляемой историей Telegram; количество, дата, новые поступления и перезапуск. Браузерный сценарий подключения. Узкие проверки сборщика для альбомов на границе порций и отдельной темы форума.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history. Использовать общий контракт задачи 01 и обычные правила Telegram. Реализация требует отдельного разрешения пользователя.
