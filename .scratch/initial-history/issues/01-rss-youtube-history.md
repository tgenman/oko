# 01: Начальная история RSS/YouTube

**What to build:** При подключении RSS/Atom или YouTube пользователь выбирает последние N публикаций либо историю начиная с даты. Выбранная история загружается порциями с видимым прогрессом и продолжается после перезапуска, а новые публикации собираются дополнительно.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] В форме доступны два взаимоисключающих режима; по умолчанию — последние 20 публикаций.
- [ ] Количество — целое число от 1 без произвольного верхнего лимита. Некорректные значения и будущая дата отклоняются с понятной ошибкой.
- [ ] Режим даты включает выбранный день с 00:00 в часовом поясе пользователя. Сохранённая граница не сдвигается при смене часового пояса.
- [ ] Режим и граница сохраняются вместе с новым фидом до первого сбора.
- [ ] Последние N фиксируются при первом успешном обращении к источнику; новые публикации не вытесняют выбранную историю и не расходуют N.
- [ ] В настройках фида виден прогресс: «Загружено 7 из 20» либо «Загружено 37 публикаций с 1 октября» без неизвестного общего количества.
- [ ] Материалы доступны для чтения по мере сохранения; готовность тезисов не задерживает историю.
- [ ] После перезапуска сохраняются граница, набор и прогресс. Повторная доставка не создаёт дублей и не увеличивает счётчик повторно.

**Проверки:** HTTP API читателя с управляемыми RSS/Atom-ответами и YouTube-фидом; подключение, валидация, новые поступления, загрузка 7 из 20 и перезапуск. Браузерный сценарий формы и прогресса.

**Граница задачи:** Общий контракт состояния должен поддерживать последующие задачи. Особенности неизвестной даты и ограниченного окна доводятся в задаче 05, расширенные исходы ошибок — в 04.

**Контекст:** Спецификация «Выбор начальной истории при подключении источника» в локальном трекере initial-history; разделы Solution, Implementation Decisions и Testing Decisions. Реализация требует отдельного разрешения пользователя.
