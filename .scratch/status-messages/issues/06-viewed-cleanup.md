# 06: Просмотр и удаление при открытой панели в нескольких вкладках

Status: done
Specification: [Состояние работы и сообщения Око](../spec.md)

**What to build:** Просмотр очищает содержимое также из текущих проблем, подробностей и недавней истории во всех вкладках, сохраняя актуальную ошибку физического удаления до его подтверждённого завершения.

**Blocked by:** 02 — Проблемы источников и материалов; 03 — Ошибки действий пользователя; 04 — Завершение и восстановление истории.

- [x] Заголовки, содержимое, превью и ссылки удалённых материалов не остаются в проблемах и истории; разрешены только служебные отметки.
- [x] Раскрытая запись не препятствует очистке; поздние результаты не возвращают удалённое.
- [x] Ошибка физического удаления остаётся актуальной, просмотр не обозначает ложного исправления.
- [x] Во всех вкладках согласованы число групп и состояние; повторная доставка не удваивает проблему.
- [x] HTTP и браузер подтверждают A19–A20 и сохранение защиты от поздних ответов.

**Verification:** [Фактический отчёт](../../../docs/verification/status-messages.md). Реализация: `codex/status-messages`; эталон макета: `codex/status-panel-prototype`.
