# 01: Панель состояния — от отсутствующей модели до исправления

Status: done
Assignee: primary
Specification: [Состояние работы и сообщения Око](../spec.md)

**What to build:** Читатель видит компактный ход работы и актуальную проблему невыбранной модели, открывает панель A, переходит к выбору модели и наблюдает исчезновение проблемы после подтверждённого исправления.

**Blocked by:** None (can start immediately).

- [x] Проблема имеет структурированную идентичность, область и доступное действие; текст ошибки не служит контрактом.
- [x] Шапка не растёт от сообщений; счётчик считает группы, фоновые проблемы не открывают панель.
- [x] Панель соответствует выбранному A в стиле настроек; исправление модели открывает нужный раздел и допускает возврат.
- [x] На широком и узком экране работают «Готово», Esc, повторное открытие, клавиатура и возврат фокуса; чтение и прокрутка сохраняются.
- [x] Доступ к техническому журналу сохранён; обычные ожидания не считаются проблемами, скрытия нерешённых нет.
- [x] Путь подтверждён через HTTP с синтетическим обработчиком и настоящий браузер. Покрытие: A01, A05, A06, A11, A14, A24.

**Verification:** [Фактический отчёт](../../../docs/verification/status-messages.md). Реализация: `codex/status-messages`; эталон макета: `codex/status-panel-prototype`.
