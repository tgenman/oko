# 04: Завершение проблем и восстановление истории

Status: done
Specification: [Состояние работы и сообщения Око](../spec.md)

**What to build:** Решённые и потерявшие актуальность проблемы переходят в недавнюю историю, сохраняются сутки и корректно восстанавливаются после перезапуска.

**Blocked by:** 01 — Панель состояния.

- [x] Подтверждённое исправление различимо с потерей актуальности; начатый повтор не считается успехом.
- [x] Раскрытая завершённая запись остаётся на месте до закрытия подробностей, но уже исключена из счётчика.
- [x] Суточный срок начинается при завершении, не продлевается закрытием или перезапуском; состояние после восстановления сверяется заново.
- [x] Очистка диагностики не очищает актуальные проблемы; история исключений остаётся отдельной.
- [x] Проверка модели демонстрирует весь путь; остальные виды проблем используют тот же жизненный цикл.
- [x] HTTP и браузер подтверждают A09–A10, A18, восстановление и отсутствие дублей.
