# 05: Потеря связи, неотправленные ошибки и остановка

Status: done
Specification: [Состояние работы и сообщения Око](../spec.md)

**What to build:** При недоступном сервере читатель различает устаревшее состояние и неотправленную ошибку, а после восстановления получает свежие сведения без самопроизвольного открытия панели.

**Blocked by:** 03 — Ошибки действий пользователя; 04 — Завершение и восстановление истории.

- [x] При отсутствии первого ответа состояние неизвестно; после потери связи остаются последние сведения с временем обновления, без ложного нуля.
- [x] Действия, требующие связи, недоступны; работают проверка связи и автоматическое обновление после восстановления.
- [x] Неотправленные ошибки помечены «Не сохранено» и доставляются после восстановления; закрытие до доставки может потерять запись, серверная сохранность не обещается.
- [x] Подтверждённая остановка различима с потерей связи; поздние ответы не оживляют остановленный интерфейс.
- [x] Проверены браузерные и HTTP сценарии A15–A17, A23, включая неизвестный исход записи.

**Verification:** [Фактический отчёт](../../../docs/verification/status-messages.md). Реализация: `codex/status-messages`; эталон макета: `codex/status-panel-prototype`.
