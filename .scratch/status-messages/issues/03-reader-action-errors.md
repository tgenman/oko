# 03: Ошибки действий пользователя

Status: done
Specification: [Состояние работы и сообщения Око](../spec.md)

**What to build:** Неудавшееся действие видно рядом с ним и в панели как одна проблема с исходным контекстом; поздний ответ не изменяет другую форму или новый ввод.

**Blocked by:** 01 — Панель состояния.

- [x] Ошибки пользовательских действий поступают в панель независимо от права показа в текущей форме.
- [x] Закрытие формы не устраняет проблему и не открывает её снова автоматически; обратный переход ведёт к нужному объекту.
- [x] Успешный повтор завершает соответствующую проблему; явный сброс соответствующего черновика делает её неактуальной, не затрагивая другие изменения.
- [x] Неизвестный исход записи явно различим с подтверждённым отказом; после восстановления связи состояние сверяется, безусловного повторения уже выполненного действия нет.
- [x] Сохраняются черновики и согласование поздней успешной записи, исключены дубли одной ошибки.
- [x] Поведение проверено через HTTP и браузер с задержанными ответами: A12–A14, A16, A21–A22.
