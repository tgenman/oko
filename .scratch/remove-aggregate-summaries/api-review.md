# Семантическое изменение API 1.0.0 → 2.0.0

Согласованное несовместимое удаление групповой суммаризации: удалены POST /api/digests/{scope}/{owner}, настройки events/event_hours/digests/prompt_digest/schedule/digest_days, выбор моделей событий/обзоров, групповые поля карточки/материала и review_restarts. Обработчик принимает только filter/theses. Оставшиеся действия относятся к отдельным публикациям.

Frontend и generated SDK/DTO обновляются вместе с сервером. Внешних потребителей в репозитории нет. Старые запросы удалённого маршрута получают 404, старые поля строгих моделей — ошибку валидации. SQLite обновляется до начала обработки: групповые результаты/задания удаляются, оригиналы и актуальные индивидуальные результаты сохраняются. Вкладки прежнего frontend требуют перезагрузки при обновлении сервера.

Проверки: план и фактические результаты записываются отдельно в docs/verification/remove-aggregate-summaries.md. Обновление baseline фиксирует согласованное изменение контракта и не является свидетельством прохождения проверок или независимого ревью.
