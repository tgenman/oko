# Настраиваемый лимит запросов Telegram

Дополнение к [спецификации](spec.md) по поручению пользователя 2026-10-21.
База изменения: `4302f100508e68a8a222b53d734206f5c4cb7e69`.

- В Настройках Око появляется `Telegram Request Limit`, запросы в секунду.
- Одно конечное число от 0,1 до 10 включительно; по умолчанию 2.
  Оно задаёт общий HTML-бюджет Telegram web и отдельный бюджет каждого сервера медиа.
  Бюджет не распространяется на MTProto.
- Используются существующие явные Save, Reset и Discard Change. Reset возвращает
  default 2; значение сохраняется после перезапуска. У папки и фида этого поля нет.
- Новое значение применяется к следующим допускам без перезапуска и отмены
  выполняющихся запросов. Изменение настройки не меняет принятые ИИ-результаты.
- Сохранённая пауза 429 сохраняет deadline при сохранении и сбросе лимита.
- HTTP: существующий PATCH `/api/v3/settings/oko/global` с `telegram_http_rps`
  (число или null); отдельный GET `/api/v3/settings/telegram-http` с value/origin.
  Закрытые ответы общих настроек и SettingKey не расширяются; command keys пусты,
  как для глобального интервала обновления. Остальные настройки сохраняют поведение.

## Проверка

HTTP с временным Store и MockTransport: default, ошибки ввода, отсутствие
переопределений папки/фида, сохранение/сброс/перезапуск, реальные интервалы HTML
и медиа, сохранение 429 и отсутствие отмены активного запроса.
Playwright: сохранение, проверка чисел, сброс, закрытие/открытие, поздний ответ
и новый черновик, отказ записи и Discard Change, desktop/mobile screenshots.
Фактические результаты фиксируются отдельно.
