# Telegram: полная локальная копия и явная перезагрузка поста

Status: done
GitHub: https://github.com/tgenman/oko/issues/65
Blocked by: 01

## Результат

Реализовать правила материалов [спецификации](../spec.md) для web и аккаунта:
обычное обновление не перечитывает полные копии; неполные догружаются.
В контекстном меню — полная повторная загрузка всех вложений через существующий
HTTP retry. Старая копия остаётся текущей до полной успешной замены.
Временные ошибки повторяются после паузы, окончательные прекращают попытки
с видимой причиной. Лимит и вынужденные паузы соблюдаются.

## Критерии приёмки

- [x] HTTP-сценарии проверяют оба способа доступа, отсутствие повторного fetch полных копий и догрузку неполных.
- [x] Явная перезагрузка получает все вложения, сохраняет старую копию при ошибке, повторяет временные ошибки и прекращает окончательные.
- [x] Изменённый и неизменный результат сохраняют существующее согласование обработки и показ версий.
- [x] Меню проверено Playwright; скриншот снят и просмотрен.
- [x] Проверки и ограничения записаны отдельно; Standards и Spec ревью завершены.
