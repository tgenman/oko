# Telegram web: общий HTTP-бюджет и сохранённые паузы

Status: ready-for-agent
Blocked by: Нет

## Результат

Реализовать HTTP-часть [спецификации](../spec.md): общий HTML-бюджет 2 запроса/с,
отдельный бюджет 2 запроса/с на сервер медиа, включая подключение и редиректы.
429 закрывает общий допуск своей группы. Обе формы Retry-After, нарастающая
пауза без заголовка, сохранение после refresh/restart. Ожидание не блокирует RSS,
чтение, удаление и остановку. MTProto FloodWait сохраняет существующие правила.

## Критерии приёмки

- [ ] Общая частота и изоляция групп проверены через HTTP с синтетическими ответами.
- [ ] Retry-After в секундах/дате, ручное обновление и перезапуск проверены.
- [ ] Отмена, редиректы, аватары, медиа и остановка скачиваний после 429 проверены.
- [ ] Результаты и ограничения записаны отдельно; независимое ревью завершено.
