## Критерии приёмки

- [x] Обновления дают устойчивый ID видео, ссылку, заголовок, время публикации и превью; импортированные YouTube-фиды подключаются без второго экземпляра источника.
- [x] Получение субтитров проверено выбранным адаптером; при отсутствии показано «Субтитры недоступны», summary по одному заголовку не выдумывается.
- [x] Для уровня «Высокая» автоматически запрашиваются субтитры и тезисы; для остальных это включается режимом фида. Обработка соблюдает эффективный промпт, разрешения и выбранную модель.
- [x] Полное видео и аудио для ASR не скачиваются. В UI доступны тезисы, превью и копирование ссылки; неготовые этапы и повтор видны явно.
- [x] Продолжение сбора, повтор страницы и ошибки работают по общему контракту, другие источники не блокируются.
- [x] Просмотр удаляет субтитры, превью, тезисы и временные результаты; позднее задание не возвращает контент, закрытие вкладок прекращает обработку.
- [ ] Проверены доступные и отсутствующие субтитры, важность, ошибки и перезапуск через API; выполнена ограниченная реальная проверка поставщика обновлений/субтитров. Общий AI-контракт проверяется через подмену внешней модели; настоящий путь может использовать Codex или llama.cpp.

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта.
