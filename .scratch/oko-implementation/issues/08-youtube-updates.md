# 08: Обновления и тезисы YouTube

**What to build:** Подключить YouTube-канал, читать карточки обновлений и автоматически получать тезисы важных видео по доступным субтитрам, без скачивания видео.

**Blocked by:** [06: Тезисы через локальную модель](06-ollama-theses.md)

**Status:** ready-for-agent

**Label:** ready-for-agent

**Основание:** [Спецификация первой версии](../../oko-product/spec.md), [Глоссарий](../../../GLOSSARY.md), [Макет A и его ограничения](../../oko-product/prototype/README.md).

**Покрытие спецификации:** A02 A03 A06 A19 A26 A28 A32. Критерии применяются к поведению, введённому этой задачей; общие гарантии расширяются следующими задачами.

## Критерии приёмки

- [ ] Обновления дают устойчивый ID видео, ссылку, заголовок, время публикации и превью; импортированные YouTube-фиды подключаются без второго экземпляра источника.
- [ ] Получение субтитров проверено выбранным адаптером; при отсутствии показано «Субтитры недоступны», summary по одному заголовку не выдумывается.
- [ ] Для уровня «Высокая» автоматически запрашиваются субтитры и тезисы; для остальных это включается режимом фида. Обработка соблюдает эффективный промпт, разрешения и выбранную модель.
- [ ] Полное видео и аудио для ASR не скачиваются. В UI доступны тезисы, превью и копирование ссылки; неготовые этапы и повтор видны явно.
- [ ] Продолжение сбора, повтор страницы и ошибки работают по общему контракту, другие источники не блокируются.
- [ ] Просмотр удаляет субтитры, превью, тезисы и временные результаты; позднее задание не возвращает контент, закрытие вкладок прекращает обработку.
- [ ] Проверены доступные и отсутствующие субтитры, важность, ошибки и перезапуск через API; выполнена ограниченная реальная проверка поставщика обновлений/субтитров. Codex не является блокером: путь демонстрируется через Ollama.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.
