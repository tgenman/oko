**What to build:** Настроить обзоры по расписанию, обновить вручную и сжать историю папки за выбранный период с доступом к исходникам и полным удалением при просмотре.

## Критерии приёмки

- [x] Режимы оригиналов, тезисов и обзоров сочетаются; промпт, период, расписание и обработчик наследуются, отдельные поля переопределяются.
- [x] «Обновить сейчас» запускает обзор; открытие папки — нет. Расписание действует только при работающем Око, пропущенные тики объединяются в актуальную обработку.
- [x] «Сжать историю» по умолчанию выбирает всё непросмотренное папки с изменяемым периодом. Состав фиксируется по ID и версиям; новые поступления не добавляются задним числом.
- [x] Повторное сжатие разворачивает состав старых непросмотренных сводок и карточек событий; исходники входят один раз, прежние summary не становятся новыми публикациями.
- [x] Оригиналы и медиа раскрываются до просмотра. Создание обзора не меняет просмотр и не является самостоятельным триггером Telegram-подтверждения.
- [x] Просмотр сводки удаляет саму сводку и весь обработанный набор, включая скрытые и неупомянутые материалы. Подтверждения Telegram передаются общим механизмом по набору ID; недоступный ещё адаптер подтверждения не нужен для теста этого контракта.
- [x] Для смешанной сводки требуется обработчик, разрешённый всему набору; иначе ожидание явного выбора. Большие наборы обрабатываются частями без потери состава; промежуточные результаты также удаляются.
- [x] Проверены сто исходников, повторное сжатие, скрытые материалы, расписание и перезапуск, отказ модели, изменение разрешений и просмотр во время генерации. Одна сводка увеличивает счётчик на одну карточку.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.
