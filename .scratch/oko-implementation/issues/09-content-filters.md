**What to build:** Настроить фильтры рекламы и тем, читать очищенное представление, раскрывать скрытое с причиной и исправлять ошибочную фильтрацию.

## Критерии приёмки

- [ ] Полностью рекламная публикация скрывается; вставка удаляется только из представления. Исходник и медиа остаются до просмотра; монтаж видео не добавляется.
- [ ] Тематический промпт поддерживает примеры и исключения. На примере политики скрывается бытовая уголовная хроника, сохраняются политические преследования и изменения законодательства; это не глобальное правило всех фидов.
- [ ] «Показать скрытое» отображает причину и позволяет вернуть материал. Исправление той же версии сохраняется после повторной обработки.
- [ ] Скрытые карточки исключены из счётчика, но доступны для проверки и дальнейшего включения в обработанный набор сводки.
- [ ] Фильтрация использует общий обработчик и ограничения AI; недоступная модель даёт ожидание, не ложное заключение «рекламы нет».
- [ ] Просмотр удаляет исходники и производные представления с причинами, содержащими контент; остановленная фильтрация не возвращает их.
- [ ] Проверены UI возврата, API-состояние и небольшой набор смысловых примеров; тесты механики с подставной моделью не заменяют проверку качества настоящей модели.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.
