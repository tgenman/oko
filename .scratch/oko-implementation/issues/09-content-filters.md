## Критерии приёмки

- [x] Полностью рекламная публикация скрывается; вставка удаляется только из представления. Исходник и медиа остаются до просмотра; монтаж видео не добавляется.
- [x] Тематический промпт поддерживает примеры и исключения. На примере политики скрывается бытовая уголовная хроника, сохраняются политические преследования и изменения законодательства; это не глобальное правило всех фидов.
- [x] «Показать скрытое» отображает причину и позволяет вернуть материал. Исправление той же версии сохраняется после повторной обработки.
- [x] Скрытые карточки исключены из счётчика, но доступны для проверки и дальнейшего включения в обработанный набор сводки.
- [x] Фильтрация использует общий обработчик и ограничения AI; недоступная модель даёт ожидание, не ложное заключение «рекламы нет».
- [x] Просмотр удаляет исходники и производные представления с причинами, содержащими контент; остановленная фильтрация не возвращает их.
- [x] Проверены UI возврата, API-состояние и небольшой набор смысловых примеров; тесты механики с подставной моделью не заменяют проверку качества настоящей модели.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.


## Реализация и приёмка — 2026-10-09

Реализован путь фильтрации, очищенного чтения и возврата: общий AI-контракт для llama.cpp/Codex, атомарные файлы решений, устойчивое исправление по версии, API, UI A, счётчики и очищенный вход тезисов. Восстановление после падения, отмена, удаление и медиа проверены через API с временным настоящим хранилищем.

Пять смысловых примеров прошли на настоящем изолированном Codex с явно разрешённым синтетическим фидом. **Текущая локальная Qwen3.5-0.8B Q8_0 не прошла качество фильтрации**: пропуски, невалидные решения и нарушение исключения. Тикет закрывает функциональность и приёмку через Codex; пригодность этой маленькой модели для фильтрации не заявляется. Более способную локальную модель нужно проверить отдельно; автоматической замены обработчика нет.

Сценарий UI возврата и оригинала проверен с настоящими результатами. Подробные примеры и ограничения: [отчёт](../../../docs/verification/content-filters.md).
