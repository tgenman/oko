## Критерии приёмки

- [x] Сбор получает устойчивые идентификаторы в области фида, ссылки и время; используется GUID либо нормализованный URL. Сомнительное совпадение не скрывает материал автоматически.
- [x] Выполняется попытка сохранения полного текста и картинок; при неудаче видны анонс, ссылка и пометка неполноты, доступен повтор загрузки.
- [x] ID и задания страницы фиксируются до продвижения позиции. Повтор страницы и перезапуск не создают дубли и не пропускают сохранённые задания; просмотренный ID/URL не загружается вновь.
- [x] Первый сбор соблюдает выбранный период, дальнейший продолжает сохранённую позицию. Недоступная история обозначается как пробел, а не полный успех.
- [x] Отдельные ошибки источников не останавливают остальные; UI показывает этап, N/M, итог и различает недоступность, авторизацию и ограничение частоты.
- [x] Просмотр удаляет текст, изображения и промежуточные файлы; остановленная или поздняя загрузка не возвращает контент. Логи не содержат статьи.
- [x] Проверены API-сценарии через контролируемый HTTP-источник и одна ограниченная реальная RSS-интеграция; результат реальной проверки отделён от тестов с подменами.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.
