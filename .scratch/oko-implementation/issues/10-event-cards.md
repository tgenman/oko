# 10: Объединение новостей в события

**What to build:** Получить одну карточку события из нескольких публикаций папки, видеть все источники, обновления и противоречия, затем удалить весь связанный контент.

## Критерии приёмки

- [ ] Дедупликация ограничена одной папкой, ещё не удалёнными материалами и настраиваемым окном, по умолчанию 24 часа.
- [ ] Карточка хранит точный состав исходников независимо от ссылок в ответе модели; UI показывает все ссылки с копированием каждой и доступ к исходникам.
- [ ] Существенные новые факты выделены как обновление; противоречия атрибутированы источникам, не подменены единым утверждением.
- [ ] Объединённая карточка считается одной; время — самой новой входящей публикации, важность — максимум важности её фидов, равенства сортировки стабильны.
- [ ] Смешанный набор проверяется по разрешениям всех фидов; недопустимое не отбрасывается молча ради облачного вызова.
- [ ] Просмотр удаляет состав и производный контент, инвалидирует пересекающиеся представления, но не отмечает посторонние исходники просмотренными. Смысловой истории после удаления нет.
- [ ] Точный просмотренный ID/URL не возвращается; новый пересказ с новой идентичностью может появиться. AI-результат на удалённом или устаревшем наборе отклоняется.
- [ ] Проверены окно, разделение папок, ссылки, конфликты, новые факты, сортировки и гонка с просмотром; реальные примеры качества дополняют детерминированные API-тесты.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.
