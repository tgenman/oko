# 10: Объединение новостей в события

**What to build:** Получить одну карточку события из нескольких публикаций папки, видеть все источники, обновления и противоречия, затем удалить весь связанный контент.

**Покрытие спецификации:** A09 A10 A15 A17 A18 A26 A27 A28. Критерии применяются к поведению, введённому этой задачей; общие гарантии расширяются следующими задачами.

## Критерии приёмки

- [x] Дедупликация ограничена одной папкой, ещё не удалёнными материалами и настраиваемым окном, по умолчанию 24 часа.
- [x] Карточка хранит точный состав исходников независимо от ссылок в ответе модели; UI показывает все ссылки с копированием каждой и доступ к исходникам.
- [x] Существенные новые факты выделены как обновление; противоречия атрибутированы источникам, не подменены единым утверждением.
- [x] Объединённая карточка считается одной; время — самой новой входящей публикации, важность — максимум важности её фидов, равенства сортировки стабильны.
- [x] Смешанный набор проверяется по разрешениям всех фидов; недопустимое не отбрасывается молча ради облачного вызова.
- [x] Просмотр удаляет состав и производный контент, инвалидирует пересекающиеся представления, но не отмечает посторонние исходники просмотренными. Смысловой истории после удаления нет.
- [x] Точный просмотренный ID/URL не возвращается; новый пересказ с новой идентичностью может появиться. AI-результат на удалённом или устаревшем наборе отклоняется.
- [x] Проверены окно, разделение папок, ссылки, конфликты, новые факты, сортировки и гонка с просмотром; реальные примеры качества дополняют детерминированные API-тесты.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.


## Результат — 2026-10-09

Реализованы карточки событий через API и UI A: полный состав, ссылки/копирование/оригиналы с медиа, обновления и атрибутированные противоречия. Окно 24 часа и включение настраиваются для Око/папки; временные границы итоговых групп проверяются. Публичный AI требует разрешений всех фидов. Просмотр атомарно отмечает состав и ставит восстанавливаемое удаление; поздние/устаревшие результаты не принимаются. Отдельные видео без субтитров не участвуют в событиях.

Проверки: 118 тестов, typecheck, браузер A; настоящий Codex корректно объединил Казань, выделил обновление и конфликт 24/30 мест, оставил Омск и спутник отдельными. Качество событий локальной Qwen отдельно не проверено. Ограничение набора — 100 публикаций без усечения; превышение даёт явную ошибку. Standards/Spec: 0 открытых замечаний после исправления двух findings.
