# 01: Первый путь читателя

**What to build:** Запустить Око, получить публикацию через тестовый источник, прочитать её в раскладке A, скопировать ссылку, удалить явной отметкой и перезапустить приложение без возвращения удалённого.

**Blocked by:** None (can start immediately)

**Status:** done

**Label:** ready-for-agent

**Основание:** [Спецификация первой версии](../../oko-product/spec.md), [Глоссарий](../../../GLOSSARY.md), [Макет A и его ограничения](../../oko-product/prototype/README.md).

**Покрытие спецификации:** A15 A24 A25 A26 A27 A28 A29 A30 A31. Критерии применяются к поведению, введённому этой задачей; общие гарантии расширяются следующими задачами.

## Критерии приёмки

- [x] Один локальный Python-процесс обслуживает UI и API только на loopback; повторный запуск открывает существующий экземпляр. Изменение состояния защищено от запросов посторонней страницы, содержимое не исполняет скрипты.
- [x] Тестовый адаптер проходит настоящую очередь и сохраняет текст через SQLite и Markdown; материал доступен в колонках «папки → карточки → материал», а не только в памяти страницы.
- [x] Открытие и копирование ссылки не меняют просмотр. Явный просмотр немедленно убирает карточку и удаляет контент; повтор действия безопасен, остаются только ID, ссылки и служебные отметки.
- [x] Задания обнаружения, записи и удаления восстанавливаются после принудительной остановки. Сбой между записью файла и фиксацией базы не даёт ложной полноты; сироты разбираются. Повреждение базы не приводит к её молчаливому пересозданию.
- [x] Удаления завершаются до возобновления сбора; поздний результат задания не возвращает просмотренный материал. Ошибка удаления видна и повторяется.
- [x] Закрытие одной из двух вкладок сохраняет работу; закрытие последней и кнопка остановки прекращают задания и завершают процесс за конечный проверяемый срок. После сна запросы ждут живого UI; автозапуска нет.
- [x] Контент не архивируется в логах и постоянном браузерном кэше; удаление сбрасывает материал в открытых вкладках.
- [x] API-тесты используют настоящие временные SQLite и файлы, подменённый источник и управляемое время; проверены перезапуск процесса и браузерный путь чтения. Все последующие адаптеры обязаны расширять эти проверки для своих данных.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.
