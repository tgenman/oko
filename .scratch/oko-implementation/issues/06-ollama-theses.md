## Критерии приёмки

- [x] UI позволяет указать endpoint и модель, проверить доступность, выбрать эффективный обработчик по наследованию; локальность проверяется по реальному режиму, не по названию провайдера.
- [ ] Тестовая публикация из первого пути читателя обрабатывается настоящим адаптером llama.cpp. Тезисы отображаются рядом с раскрываемым оригиналом; промпт и режим применяются из настроек.
- [x] Общий контракт задания включает операцию, точный набор ID/версий, версию настроек, промпт, обработчик и поколение. Модель не получает полномочий менять файлы или состояние приложения.
- [x] Ответ проверяется по схеме и допустимым исходным ID/ссылкам; частичный поток и HTTP-успех без завершённого результата не признаются готовыми тезисами.
- [x] Недоступность, исчезнувшая модель и ограничения дают ожидание/ошибку без fallback. Перед каждым вызовом проверяется допустимость всего входа; запрещённое публичному AI не отправляется в непроверенный удалённый обработчик.
- [x] Смена разрешений или версий отменяет устаревшую работу. После остановки, просмотра или позднего ответа результат не публикуется; временные входы, ответы и тезисы удаляются вместе с исходником.
- [x] Прогресс отражает этапы, а не выдуманный процент модели; отмена не останавливает общий сервер llama.cpp. Соблюдается ограниченный параллелизм AI-заданий.
- [x] API-тесты используют подмену модели, отдельная ограниченная проверка — реальную локальную модель и небольшой набор качества/атрибуции. Если модель не настроена, это фиксируется как непроверенная интеграция, а не зелёная приёмка.

## Общие условия выполнения

Реализовать законченный путь через хранение, API, UI и проверки поведения. Основные тесты — через API с настоящими временными SQLite/файлами и подменами внешних систем; браузер проверяет действия читателя. Восстановление, отмена и удаление проверяются для всех добавленных типов содержимого. Использовать глоссарий и раскладку A; не возвращать исключённые функции или смысловой архив. Реальные подключения проверять отдельно на ограниченном наборе; не выдавать подмены за проверку аккаунта. Более поздние адаптеры используют общий контракт без необходимости завершать все независимые ветви заранее.

## Первоначальное выполнение Ollama

Код, API и UI реализованы. Приёмка настоящей модели ожидает настроенный Ollama: стандартный endpoint недоступен, Ollama не найден в PATH. [Отчёт](../../../docs/verification/ollama-theses.md).
