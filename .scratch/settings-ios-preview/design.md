# Предварительный дизайн настроек

Статус: ожидает согласования дизайна. Реализация основного интерфейса не начата.

Запрос: настройки в стиле iPhone, сначала показать новый дизайн.

Макет: [prototype.html](prototype.html). Запуск из checkout: `python3 -m http.server 8769 --bind 127.0.0.1 --directory .scratch/settings-ios-preview`, затем открыть `http://127.0.0.1:8769/prototype.html`.

Светло-серый фон, белые группы со скруглениями, компактные строки, значения справа, зелёные переключатели, синие действия. На компьютере — диалог над читателем, на телефоне — весь экран. Промпты, расписание и подключения открываются отдельно. Переключатель уровня демонстрирует синтетические Око/папку/фид; выбор настоящего объекта остаётся частью существующего меню фидов и папок.

Предлагаемое поведение: переключатели и выбор значения сохраняются сразу, текстовые формы — по «Готово». Это изменение относительно существующего сохранения каждого поля отдельной кнопкой, его нужно согласовать вместе с дизайном. В реализации сохранить отдельное наследование и отдельный сброс каждого поля, черновики по объектам, защиту от поздних ответов, ошибки и подтверждение фактической записи. Макет сброса лишь показывает место действия и не реализует наследование.

Модель Codex, усилие и Fast сохраняют отдельные параметры для четырёх видов обработки. Названия моделей и состояние подключений в макете условные. Для YouTube поля прокси появляются только при выборе прокси; пустые поля сохраняют учётные данные. Расписание действует только при работающем Око. Настройки событий недоступны на уровне фида.

## Фактическая проверка

2026-10-13: настоящий headless Chrome через Playwright, локальный HTTP-сервер, без API Око. Проверены desktop 1200×940 и mobile 390×844, переходы, переключатель тезисов, сохранение промпта в памяти, появление полей прокси, четыре набора параметров Codex. Ошибок JavaScript и горизонтального переполнения на главном мобильном экране нет. Снимки: desktop.png, mobile.png, reading.png. Визуально проверены главный desktop и mobile.

Первый проверочный запуск остановился на неточном accessible-name селекторе «Чтение»; повтор с селектором перехода прошёл. Производственные HTTP/browser-наборы не запускались: код продукта не менялся. Личные данные и подключения не использовались.
