# 06: Субтитры YouTube

Status: done
Assignee: primary implementer
Label: ready-for-agent
Blocked by: 02

Родитель: [Переработать настройки Око в стиле iPhone](01-settings-redesign.md).
Спецификация: [Настройки Око в стиле iPhone](../spec.md).

**What to build:** пользователь видит действительный статус получения субтитров и на отдельном экране настраивает прямое подключение или прокси, явно сохраняет подключение и управляет сохранёнными учётными данными.

**Blocked by:** 02 — главный экран настроек, переходы и адаптивный диалог.

- [x] Из группы «Подключения» Око доступен экран субтитров YouTube. Текущее состояние, причина паузы и время следующей попытки берутся из ответа сервера, не из демонстрационных данных.
- [x] При прямом подключении поля прокси скрыты; при выборе прокси доступны адрес HTTP/HTTPS, логин и пароль. Переключение способа не очищает сохранённые учётные данные и сохраняет черновик формы.
- [x] Сохранение явно подтверждается и использует существующий контракт подключения. Прокси применяется только для субтитров; сохранение не запускает проверку YouTube.
- [x] Пустые логин и пароль сохраняют прежние данные. Их удаление выполняется отдельным явным действием, скрытие полей не считается удалением.
- [x] Неверный ввод и ошибка записи сохраняют черновик. Ввод во время записи не затирается; поздний ответ после закрытия/повторного открытия не меняет текущий экран.
- [x] В настоящем браузере через HTTP проверены статус паузы, оба способа подключения, появление полей, пустые учётные данные, удаление, ошибки, поздние ответы и отсутствие проверки при сохранении. Внешний YouTube не вызывается; компьютерный и мобильный вид проверены, результаты записаны отдельно.
