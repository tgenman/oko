## Что изменено

Распознанные виджеты без URL сохраняют типизированный ExternalMedia и статус external. Доступный текст и локальные ресурсы сохраняются, внешние ресурсы остаются неполной локальной копией. Состояние только внешних вложений не создаёт material-incomplete, ошибку истории или повтор при неизменном обновлении фида. Изменившееся наблюдение источника допускает сбор; явный HTTP retry сохранён.

Реальные ошибки не подавляются. Прежняя пригодная локальная копия имеет приоритет. Если ранее сохранённый файл исчез, ограничение веб-доступа не превращает потерю в нормальную внешнюю пометку. Обновление полной текстовой версии до текста с внешним вложением допускается без синтетической ошибки.

API и generated-библиотеки передают внешние вложения текущей/исторической ревизии, ограничение размера веб-просмотра, метаданные и локальную обложку. Список получает набор типов. Карточки B используют существующего владельца blob, обложка не дублируется. Значки A на превью имеют подпись типа, hover/focus-пояснение и доступны в имени строки. Внешняя неполнота не предлагает Retry Download.

Прототипы сохранены в локальной ветке `codex/telegram-external-prototype-20261021` на исходном коммите `8f76c1ea65ecc7dea92925b34c335d105f76175b`; throwaway entries удалены из рабочей ветки. Архив содержит согласованную финальную формулировку видео и все альтернативы.
