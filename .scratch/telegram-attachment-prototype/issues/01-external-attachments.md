# Telegram: внешние аудио и видео без ложных ошибок

GitHub: https://github.com/tgenman/oko/issues/74
Status: done
Blocked by: Нет

Реализовать согласованную [спецификацию](../spec.md) целиком, включая C1–C13.

Один последовательный вертикальный срез: типизированное ограничение веб-доступа → сохранение и отсутствие ложных проблем → OpenAPI/проекции → карточка B и значок A → HTTP/браузерная приёмка и независимое ревью. Изменения связаны общим состоянием доступности, поэтому отдельных параллельных задач реализации нет.

Граница проверок: существующий HTTP interface читателя с временным хранилищем и синтетическими HTML/медиа; настоящий UI через Playwright. Реальные ошибки загрузки и локальные лимиты сохраняются. Личные источники и аккаунты не используются. Запрос не включает обновление пользовательского экземпляра.

## Результат

C1–C13 реализованы. Итоговый полный прогон на 824a2a4 — PASS; Standards и Spec review завершены без открытых замечаний. [Фактическая проверка](../implementation-verification.md). Рабочий экземпляр не обновлялся.
