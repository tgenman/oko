# Прототип включения Око — 2026-10-19

Вопрос: Stop заменяется на Start после выключения; Start возвращает включённое состояние.
Ветка скилла: LOGIC, один автономный HTML с состоянием в памяти.
Исходник: frontend/power-state-prototype.html. Открывается в браузере без сборки.

## Фактическая проверка

Playwright + headless Google Chrome, 1440×1100, автономный HTML, вымышленные данные.
- Пройден цикл Stop → Stopping… → Start → Starting… → Stop.
- После ошибки включения Start остаётся доступна; повтор успешно включает модель.
- Пройдены все три пошаговых сценария: обычный цикл, повторное нажатие, ошибка и повтор.
- Ошибок JavaScript в браузере: 0.
- Скриншот выключенного состояния: /tmp/oko-power-stopped.png; просмотрен.
- Первый запуск Chrome в sandbox не состоялся; запуск вне sandbox успешен.
- В первом скрипте ожидание ошибки совпало с демонстрационной кнопкой. После исправления
  ожидания по текущему состоянию проверка повторена и подтвердила Start · доступна.

## Ограничения и решение

Настоящий runtime не изменён. Сейчас Stop закрывает Store и завершает HTTP-сервер
(oko/reader/runtime.py, oko/__main__.py); способ повторного запуска ещё не выбран.
Прототип не доказывает реальный перезапуск или восстановление данных.
Пользователь ещё не подтвердил модель; переноса в production, коммита архива
и публикации issue пока нет. После выбора сохранить primary source по prototype skill.
