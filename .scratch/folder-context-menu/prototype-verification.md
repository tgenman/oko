# Прототип меню папки — 2026-10-19

Вопрос: как должно выглядеть меню папки рядом с существующим деревом читателя?
Вариант пока не выбран. Production-реализация не изменена.

## Запуск

```sh
node frontend/src/reading/folder-menu-prototype.mjs
```

URL: http://127.0.0.1:5186/folder-menu-prototype.html?variant=A

- A: список действий как у фида.
- B: заголовок папки и группы действий.
- C: панель из четырёх действий.

Переключение: нижняя панель, стрелки клавиатуры вне меню/диалога/полей ввода,
или `?variant=A|B|C`. Правый клик и Shift+F10 открывают меню папки.
Демонстрационные данные живут в памяти, Reset demo возвращает исходное состояние.
Папки Design и Technology непустые, Empty Folder позволяет попробовать удаление.
Настройки представлены одним демонстрационным полем.

Использованы настоящий ReaderShell, SourceIcon и стили читателя;
транспорт и production entry point не подключены. Маршрут отсутствует в production
build inputs, launcher запрещает production, entry ограничен localhost.

## Фактические проверки

- `tsc --noEmit --pretty false`: успешно.
- Playwright с установленным Google Chrome: показ вариантов A/B/C;
  предупреждение при Delete непустой папки, переименование Design → Creative Work,
  подтверждение удаления Empty Folder — успешно.
- Сняты и просмотрены четыре скриншота: A/B/C и предупреждение.
- В этом проходе `pageerror` не зарегистрирован.

Начальный запуск браузера через стандартный Playwright executable не состоялся:
браузер этого релиза не установлен. Повтор использовал установленный Google Chrome.
