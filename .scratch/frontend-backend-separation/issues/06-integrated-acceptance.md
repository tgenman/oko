# 06: Приёмка разделения целиком

Status: done

**What to build:** Совместная работа явно разделённых фронтенда и бэкенда подтверждена через настоящий HTTP interface и браузер. Архитектурные документы описывают итоговую implementation, а отчёт фиксирует выполненные проверки и ограничения.

**Blocked by:** 02 — Проверяемый контракт открытого материала; 03 — Проверяемый контракт состояния работы; 04 — Единый транспорт всех действий читателя; 05 — Самостоятельный фронтенд при одном запуске. Тикет 01 требуется транзитивно через 02 и 03.

Спецификация: [явное разделение фронтенда и бэкенда](../spec.md). Реализация поручена пользователем через implement-spec 2026-10-13.

- [x] Проверены все критерии приёмки спецификации на совместном результате тикетов, включая один запуск, общий транспорт, контракты, вложенные imports и защиту выдачи файлов.
- [x] Сквозной сценарий без подмены browser fetch подтверждает совместную работу списка чтения, навигации, открытого материала и действий с настоящими временными SQLite/файлами.
- [x] Настоящий браузер подтверждает настройки и черновики, поздние ответы, успешную запись после закрытия формы, медиа, просмотр и остановку. Серверные сценарии сохраняют состав чтения, выполнение и восстановление.
- [x] Полный действующий набор проверок включает проверку контрактов и обнаружение всех браузерных modules и проходит с синтетическими источниками/моделями. Личные подписки, Telegram-аккаунт и настоящий обработчик не используются.
- [x] Выполнено ревью соответствия спецификации и правилам проекта. Замечания устранены и проверены в затронутом объёме.
- [x] Действующие архитектурные документы отражают итоговое владение, размещение и interface; исторические отчёты сохраняют результаты своих версий.
- [x] Отдельный отчёт перечисляет фактически выполненные наборы, результаты и ограничения. При неуспешном полном прогоне и успешном ограниченном повторе указаны оба результата.
