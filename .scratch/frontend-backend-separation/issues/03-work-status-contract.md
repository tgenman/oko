# 03: Проверяемый контракт состояния работы

Status: done

**What to build:** Пользователь получает прежние сведения о ходе работы, источниках, ошибках и восстановлении через проверяемый контракт состояния. Браузер корректно показывает работающий, ожидающий, ошибочный и остановленный читатель.

**Blocked by:** 01 — Проверяемый контракт списка чтения; нужен общий механизм экспорта и проверки схем.

Спецификация: [явное разделение фронтенда и бэкенда](../spec.md). Реализация поручена пользователем через implement-spec 2026-10-13.

- [x] Инвентаризированы варианты статуса: работа источников, начальная история и догрузка, внешние ожидания, отметки чтения Telegram, ошибки, диагностика, восстановление обзоров и остановка.
- [x] Настоящие ответы статуса и соответствующие браузерные снимки проверяются по одному серверному описанию через механизм тикета 01; неизвестные данные не подменяются выдуманными defaults.
- [x] В настоящем браузере сохраняются прогресс, ошибки, сведения об источниках и доступные действия восстановления, включая незавершённую работу.
- [x] Остановка и поздний ответ статуса не возвращают очищенное содержимое и не включают недоступные действия.
- [x] Контракт не переносит владение выполнением, отменой или восстановлением из Runtime и Store в браузер и не обещает транзакционный снимок нескольких запросов.
- [x] Несовместимый ответ или снимок обнаруживается проверкой. Затронутые HTTP- и браузерные сценарии проходят с синтетическими adapters; фактический результат записан отдельно.

## Результат

Критерии выполнены. Фактические проверки, первоначальные падения, итоговые повторы и независимое ревью записаны в [общем отчёте](../../../docs/verification/frontend-backend-separation.md).
