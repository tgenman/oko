# Дерево папок и фидов для чтения

Состояние: проектирование. Реализация не разрешена в этой задаче.

## Согласовано

- Образец представления — приложенный пользователем список News Explorer.
- Сверху «Все материалы», ниже раскрываемые тематические папки с фидами. Один элемент занимает одну строку; длинное название обрезается многоточием, полное доступно при наведении.
- Клик по папке выбирает материалы папки, по фиду — материалы фида. Стрелка отдельно сворачивает папку. Выбранная строка подсвечивается.
- Настройки остаются в отдельном меню.
- Счётчики справа показывают непросмотренные исходные публикации, включая представленные событиями и обзорами. Скрытые фильтром публикации исключаются. Нулевой счётчик не показывается.
- «Возможности проверки изменений» переносится из боковой панели в настройки соответствующего фида. В строках дерева — иконка, название и счётчик.
- При выборе фида показываются целиком события и обзоры, содержащие его публикации, с обозначением всех источников. Счётчик фида учитывает только его исходные публикации.
- Фиды внутри папки сортируются по названию. Существующий порядок папок сохраняется; ручное перетаскивание не добавляется.
- При первом открытии все папки раскрыты. Состояние раскрытия запоминается локально. Сворачивание папки не меняет выбранный фид и список материалов.
- Используются общие локальные значки YouTube, Telegram и RSS без запросов за аватарами или favicon.
- Проблема сбора обозначается небольшим значком предупреждения в строке фида, краткая причина доступна при наведении, подробности — в диагностике. Сообщения не раздвигают дерево.
- При выборе фида действия завершения разбора папки, сжатия истории папки и создания обзора папки отключены. Они доступны при выборе папки.
- Мобильная версия не поддерживается и не входит в задачу; адаптивную выдвижную панель не добавляем.
- Счётчики включают обнаруженные, но ещё не загруженные непросмотренные публикации. Переключатель «Показать скрытые» меняет список материалов, но не счётчики: скрытые публикации в них не входят.
- Папки и фиды без материалов остаются в дереве без счётчика. После удаления выбранного фида выбирается его папка; если удалена и папка — «Все материалы».

## Проверенные факты и изменение поведения

Сейчас sidebar содержит только папки; фильтра чтения по фиду нет. Счётчик папки считает видимые карточки, в том числе событие или обзор как одну карточку. Новый согласованный счётчик меняет эту семантику; число публикаций отделено от числа карточек в GLOSSARY.md. Исторические спецификации описывают прежнее поведение.

Порядок папок уже существует, фиды идут в порядке добавления. Вложенных папок нет. У фидов доступны тип и транспорт, но нет сохранённых favicon/аватаров. Дерево папок и фидов в меню настроек выбирает объект редактирования, а не область чтения.

## Завершение проектирования

Решения 14–17 подтверждены пользователем: общий подсчёт уникальных публикаций, сохранение выбранного перемещённого фида с раскрытием новой папки, двойной клик в настройки и предупреждение в диагностику, изменение ширины с локальным сохранением без вложенных папок.

Полное описание поведения, технических решений и проверок опубликовано в [спецификации](spec.md) со статусом `ready-for-agent`. Открытых продуктовых вопросов нет. Реализация не разрешена текущим запросом.
