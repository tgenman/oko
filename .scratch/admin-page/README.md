# Прототип админки Око

Одноразовый прототип, только синтетические данные в памяти. Не запускает Око,
не подключается к подпискам и не меняет рабочую установку.

Запуск из корня checkout: `npm run prototype:admin`.

- [A — Обзор](http://127.0.0.1:5191/admin?variant=A): компактное управление, подробности в панели.
- [B — Источники](http://127.0.0.1:5191/admin?variant=B): список источников с поиском и подробностями выбранного.
- [C — Сначала проблемы](http://127.0.0.1:5191/admin?variant=C): постоянная колонка управления, открытый разбор проблем.
- [Читатель](http://127.0.0.1:5191/?variant=A): синтетический контекст новой шапки.

Варианты переключаются нижней панелью и стрелками клавиатуры; URL сохраняет вариант.
«Состояние и сценарии» показывает состояние и позволяет сбросить пример или завершить сбор.
Start/Stop, обновление и повтор ошибки меняют только состояние макета. Состояние сбрасывается
при перезагрузке. Настройки и переход к публикации обозначены заглушками.

Выбран A; применён iPhone-style существующего клиента.
После завершения дизайна сохранить все варианты в отдельной одноразовой ветке
и указать её в задаче реализации; в основной ветке оставить выбранное решение.
Текущая подготовка не является производственной реализацией.
