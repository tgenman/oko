# Улучшения среды после ретроспективы Source

GitHub: https://github.com/tgenman/oko/issues/43

Пользователь разрешил реализацию всех четырёх предложений 2026-10-19.

1. Расширить существующий Clock помощником, задающим clock и wall_clock вместе; проверить управляемое истечение сессии через HTTP.
2. Параллельный runner сразу сообщает упавший тест, краткую причину, лог и точечный повтор, включая --compact. Полные логи, остальные сценарии, отмена и итоговый код сохраняются.
3. Команда подготовки worktree переиспользует установленные node_modules/.venv, собирает frontend и вызывает validate_frontend. Установка, перенос данных/секретов, изменение Git и запуск личного экземпляра не входят в неё. Ошибка останавливает последовательность.
4. Существующий GitHub exporter готовит MCP-вызов поиска с кратким выводом number/title/state/url. Полный ответ сохраняется отдельно; выбранная задача читается через fetch_issue. Сеть и авторизация остаются у подключённого плагина. Проверка — синтетические ответы, включая ошибку и запрос с кавычками.

Seams проверки: существующий HTTP interface с временной SQLite и CLI инструментов с временными Git/файлами и синтетическими процессами. До реализации соответствующего поведения — падающая проверка. После целевых — полный runner и независимые Standards/Spec review. Фактические результаты записываются отдельно. Таймауты и пропуски существующих сценариев не меняются.
