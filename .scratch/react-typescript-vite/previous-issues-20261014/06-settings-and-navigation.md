# 06. Редактор настроек и меню

Status: ready-for-agent
Blocked by: 05

Спецификация: [spec.md](../spec.md). Реализация пока не разрешена.

## Результат

Меню, страницы и поля настроек работают в React; черновики принадлежат объектам, а сообщения и навигация — текущему контексту показа.

## Объём

- Использовать generated SDK settings/subscriptions/параметров фида из canonical OpenAPI; не создавать локальные wire-схемы.
- Первым перенести одно поле с наследованием/save/reset/discard и сценарием «сохранение A → ввод B → назад/закрыть → ответ A → открыть».
- Затем перенести все поля, дерево выбора владельца, эффективные значения, страницы/Back, адаптивный список/детали и оболочки трёх меню.
- Держать черновики и исходы незавершённых записей выше размонтируемых полей. Навигация не сохраняет и не уничтожает черновики; успешная запись согласуется после ухода.
- Неперенесённые формы подключений временно получают отдельные контейнеры со своим DOM. Оба renderer не должны владеть одним поддеревом.

## Приёмка

- [ ] Поздняя запись A обновляет сохранённое значение и сохраняет более новый черновик B; разные поля/объекты не смешиваются.
- [ ] Save, reset наследования и discard различаются; ошибки не стирают ввод. Ожидаемые ошибки и диагностика сохранены.
- [ ] Back, закрытие/Escape, повторное открытие того же меню и смена владельца не допускают старые сообщения/переходы.
- [ ] Фокус после обновления, opener, клавиатура и видимость страниц соответствуют текущему поведению.
- [ ] Старые renderers полей/навигации удалены, все перенесённые обращения типизированы; внешний интерфейс меню остаётся рабочим для панели и дерева чтения.

## Проверка

`test_ui_lifecycle.cjs`, `test_settings_navigation.cjs`, `test_separate_menus.cjs` и затронутые HTTP settings/subscriptions. Снимки заполненной формы, наследования, ошибки и мобильных переходов. Все пять текущих lifecycle-регрессий остаются в общей приёмке.
