# 10. Общий React root и завершение миграции

Status: ready-for-agent
Blocked by: 09

Спецификация: [spec.md](../spec.md). Реализация пока не разрешена.

## Результат

Production-приложение целиком использует React + strict TypeScript и Vite build; промежуточное сосуществование renderer завершено.

## Объём

- Собрать один React root, соединить перенесённых владельцев и удалить legacy bootstrap, временные адаптеры, старые entry и разрешения на production JS.
- Проверить остаточные прямые DOM-записи: оставить только обоснованные refs/media/focus/measurement операции в своём владельце, а не вторую отрисовку компонентов.
- Проверить полноту контрактов для всех потребителей, error boundaries/диагностику, отсутствие дублированной сессии и потерянной очистки.
- Обновить README, инструкции проверок и действующие архитектурные документы по фактическому результату. Исторические отчёты и исследовательские прототипы сохранить вне сборки.

## Приёмка

- [ ] Ни один product route/UI-сценарий не зависит от удалённого legacy; нет второй JS/TS реализации и незавершённых migration flags.
- [ ] OpenAPI lint/совместимость, codegen обеих библиотек, route/HTTP drift, Swagger, typecheck, lint/hooks, build, HTTP/security, browser, Python/lifecycle и CLI проходят на подготовленном дереве задачи.
- [ ] Проверен установленный пакет без checkout/Node, свежесть build в checkout и запуск из другого cwd.
- [ ] Просмотрены финальные desktop/mobile скриншоты основных состояний; текущая вёрстка и содержание сохранены.
- [ ] Независимое ревью проверило соответствие спецификации, владельцев, поздние ответы, сборку/выдачу и отсутствие необоснованных новых зависимостей.
- [ ] Отчёт содержит фактические команды, результаты, падения/повторы и ограничения; все выполненные задачи переведены в done только по доказательствам.

## Проверка

По правилам task-changes подготовить изолированное дерево и выполнить `./scripts/check all` с реализованными frontend-наборами. Не подменять полный результат выборочным повтором. Smoke установки и просмотр снимков фиксируются отдельно. Коммит/публикация/перезапуск личного экземпляра не входят автоматически в завершение.
