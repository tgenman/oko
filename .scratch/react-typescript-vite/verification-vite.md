# Проверка задачи 02 — существующий читатель через Vite

2026-10-14. Исходная база: `c9382d0`. Исполнитель: vite. Проверки выполнялись в отдельном checkout на временных хранилищах, синтетических источниках и adapters; пользовательский экземпляр не перезапускался.

## Результат

Исходный JavaScript сохранён в единственном экземпляре. Vite собирает прежний HTML/интерфейс; Python выдаёт готовые assets на прежнем origin. Настроена отдельная строгая проверка TypeScript. React 19.3.0, Vite 8.3.4 и TypeScript 5.9.3 закреплены точно: TS 7.0.2 заменён после обнаруженной несовместимости compiler API с генератором @hey-api/openapi-ts 0.97.3. Согласованные API-first зависимости добавлены для следующего среза.

Build содержит хешированные JS/CSS и проверку целостности; указатель на полное поколение меняется атомарно. Watch проверяет содержимое файлов, переживает атомарную замену редактором и сохраняет прежние assets для открытых вкладок. Неудачная сборка сохраняет предыдущий результат. Отсутствующая, устаревшая и повреждённая сборки останавливают создание приложения до Runtime/Store. Обычный запуск не вызывает Node/npm.

## Фактические проверки

- Red: проверка отсутствующей сборки сначала упала, поскольку прежний create_app создавал приложение без готового интерфейса. После реализации прошла; проверяется отсутствие каталога данных.
- `check ui`: итоговый полный прогон PASS — syntax, lint, build (strict typecheck + Vite + freshness), 11 HTTP, 111/111 browser, diff; 87.45 сек. Отчёт: `.scratch/check-runs/20261014T124741Z-a5757397/report.json`.
- Первый полный прогон: 108/111 браузерных сценариев. Три падения были связаны с предположениями о несобранном URL отдельного CSS и транспортного модуля; сохранены независимая paint-layer проверка геометрии и публичный transport entry через согласованные хешированные assets. Guard также зафиксировал изменение тестового файла исполнителем во время прогона. Повтор выполнялся без изменений checkout.
- Промежуточный целевой повтор: 5/5 browser прошли; HTTP выявил ошибочное распознавание modulepreload как CSS. Уточнена проверка реальных stylesheet и всего графа imports. Итоговый прогон выше включает исправление.
- HTTP/build целевые проверки: 8/8 — выдача JS/CSS, безопасность путей/Host/Origin, отсутствие/устаревание/повреждение до хранения, неудачная сборка, публикация полных watch-поколений и сохранение прежних assets.
- Проверки runner: 32/32 в запуске frontend-build + development runner; mypy для статической выдачи PASS. Ограниченный запуск в sandbox упирался в запрет ps; тот же набор выполнен с разрешённым доступом.
- После замены TS выполнены strict typecheck, build, build:check; ES import генератора успешен. Повторена целевая HTTP/build проверка и mypy. Браузерное поведение не менялось.
- Сняты и просмотрены desktop/mobile снимки шапки читателя и формы добавления фида. Surface suite сравнила геометрию 34 состояний при переключении paint-only CSS; утверждения сохранены.
