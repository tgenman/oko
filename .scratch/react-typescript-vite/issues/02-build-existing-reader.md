# 02: Существующий читатель через сборку Vite

**What to build:** Пользователь запускает прежний интерфейс обычным способом, а разработчик собирает и проверяет его через Vite.

Blocked by: None (can start immediately).

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Подготовлены совместимые зависимости React/TypeScript/Vite и отдельная строгая проверка типов; существующий JavaScript временно подключён без копирования реализации.
- [ ] Python выдаёт готовый production build на прежнем origin; авторизация, CSP, MIME и ограничения доступа к файлам сохранены.
- [ ] Отсутствующая, устаревшая и неуспешная сборки имеют проверяемое поведение; генераторы и npm не запускаются при обычном пользовательском запуске.
- [ ] Watch build публикует согласованный набор assets; runner проверяет фактическую загрузку HTML, chunks и CSS, не изменяя source checkout.
- [ ] Настоящий HTTP/browser и просмотр desktop/mobile снимков подтверждают прежние действия и оформление; этот prefactor завершён до переноса компонентов.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
