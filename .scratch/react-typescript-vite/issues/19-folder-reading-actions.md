# 19: Обзоры и завершение тематической папки

**What to build:** Читатель создаёт обзор или завершает чтение папки с прежним предварительным составом, подтверждением и обработкой конфликта.

Blocked by: 05 — Сессия вкладки, сбор и остановка.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Операции обзоров, пересоздания и завершения папки используют generated DTO/SDK и React-диалоги.
- [ ] Сохранены период/даты, preview/token, обработка изменившегося состава, скрытые и ещё не загруженные материалы по серверным правилам.
- [ ] Поздний ответ не меняет другой контекст; успешная команда согласует чтение и другие вкладки без очистки незатронутого материала.
- [ ] Выбор папки, список и открытый материал подключаются через действующие interfaces; их React-перенос не является блокером.
- [ ] Настоящий HTTP/browser проверяет успех, конфликт и закрытие диалога во время запроса; прежние renderers команд удалены.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
