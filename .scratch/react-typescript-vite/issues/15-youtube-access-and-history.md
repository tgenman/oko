# 15: Доступ к YouTube и догрузка истории

**What to build:** Пользователь настраивает доступ к YouTube и запрашивает историю выбранного фида по количеству или дате.

Blocked by: 14 — Прогресс и управление историей фида.

Status: done

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [x] Настройки доступа и операции истории YouTube используют canonical DTO/SDK и React, не меняя прежние статусы ошибок.
- [x] Сохранены ожидание, ручное продолжение, предупреждение об ограничении RSS, сохранённые значения и настройки доступа.
- [x] Поздний старт/ответ не меняет другой фид и новый ввод; возвращение к экрану показывает актуальный прогресс.
- [x] Используется общий interface истории, а не отдельная копия её правил.
- [x] HTTP/browser используют синтетические YouTube adapters; реальные внешние запросы не нужны, прежние renderers удалены.

- [x] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.

Verification: [React settings](../../../docs/verification/react-settings.md).
