# 01: Полный контракт API и самостоятельный Swagger

**What to build:** Разработчик читает полный действующий контракт Око в локальном Swagger, даже когда читатель остановлен.

Blocked by: None (can start immediately).

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Описаны все существующие операции читателя, их параметры, запросы, ответы, ошибки, security и media; inventory реального HTTP сопоставлен со стабильными operation IDs.
- [ ] OpenAPI становится редактируемым источником контракта; сохранены optional/null, PATCH, фактические content types и статусы, примеры синтетические.
- [ ] Локальный Swagger показывает bundled-спецификацию без Runtime, источников и моделей; внешних assets/validator и автоматических API-вызовов нет.
- [ ] Валидация спеки, полнота маршрутов и выбранные настоящие HTTP-сценарии подтверждают начальный baseline; браузерный тест проверяет видимые операции.
- [ ] Контракт полон до переноса React-потребителей; текущий читатель продолжает работать с прежним поведением.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
