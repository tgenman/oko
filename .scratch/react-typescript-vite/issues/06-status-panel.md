# 06: Панель состояния и действия восстановления

**What to build:** Пользователь читает текущие проблемы и завершённые действия в React-панели и переходит к нужному действию восстановления.

Blocked by: 05 — Сессия вкладки, сбор и остановка.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Полная панель использует typed status; раскрытие деталей, порядок и место карточки выражены состоянием, а не чтением DOM.
- [ ] Раскрытая завершившаяся карточка удерживается по прежним правилам; polling не теряет фокус и не переставляет сообщения произвольно.
- [ ] Переходы к настройкам/материалу и команды восстановления сохраняют текущие interfaces ещё не перенесённых владельцев; контрактные вызовы не дублируются.
- [ ] Сохранены mobile dialog, inert, Escape, возврат фокуса и различение отсутствия связи/подтверждённой остановки.
- [ ] Настоящий UI на синтетическом HTTP и просмотр снимков подтверждают поведение; старый renderer панели удалён, диагностика пока остаётся в выделенном контейнере.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
