# 16: Дерево областей чтения

**What to build:** Читатель выбирает все материалы, тематическую папку или фид и сохраняет удобную навигацию при обновлении каталога.

Blocked by: 05 — Сессия вкладки, сбор и остановка.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Navigation/folders и необходимые catalog operations используют generated DTO/SDK, дерево отображается React-владельцем.
- [ ] Сохранены счётчики публикаций, сортировка фидов, раскрытие папок, выбор после перемещения/удаления и переход к настройкам.
- [ ] Поздний каталог не меняет более новый выбор; текущий список и открытый материал получают прежний interface выбора независимо от их renderer.
- [ ] Ширина, фокус, прокрутка, resize и недоступность localStorage сохраняют прежнее поведение.
- [ ] HTTP/browser и desktop/mobile снимки подтверждают результат; старые renderers дерева удалены.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
