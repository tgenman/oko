# 06. Дерево, список и действия чтения

Status: ready-for-agent
Blocked by: 05

Спецификация: [spec.md](../spec.md). Реализация пока не разрешена.

## Результат

Навигация, список и команды читателя работают в React, сохраняя серверный состав чтения и поведение списка при обновлениях.

## Объём

- Перенести reading-tree/feed-tree-view, material-list, toolbar и диалоги обзоров/завершения папки из app.js.
- Сохранять выбор после изменения каталога, раскрытие папок, размеры колонок, сортировку, скрытые материалы и scroll anchor по областям.
- Установить стабильную идентичность строк и превью; освобождать ресурсы при смене области/версии/удалении. Polling не пересоздаёт неизменные медиа.
- Сохранить preview/token завершения папки, конфликты и межвкладочное согласование. Описать недостающие wire-контракты команд.
- Открытый материал до этапа 07 остаётся отдельным владельцем с прежним interface и исключительным контейнером.

## Приёмка

- [ ] Список, счётчики и состав папки берутся с сервера; frontend не выводит membership самостоятельно.
- [ ] Неизменный polling сохраняет строки, превью, focus/scroll; поздний ответ другой области их не возвращает.
- [ ] Просмотр удаляет затронутые карточки и переводит фокус по прежним правилам без автоматического открытия следующей.
- [ ] Обзоры, завершение папки и конфликт preview работают; остановка и другая вкладка согласуются с действующей сессией.
- [ ] Оформление, resize клавиатурой/указателем и адаптивное поведение сохранены; старые renderers удалены.
