# 14: Прогресс и управление историей фида

**What to build:** Пользователь видит начальную/дополнительную загрузку истории, её исходы и управляет паузой и продолжением.

Blocked by: 09 — Все настройки и редактор фида.

Status: done

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [x] Прогресс и действия истории работают через generated DTO/SDK и React в редакторе выбранного фида.
- [x] Сохранены количество/дата, предупреждения о доступном окне, точные значения, состояния ожидания, паузы/продолжения и итоговые исходы.
- [x] Задержанный ответ не меняет историю другого фида и не стирает новый выбор; повторное открытие показывает сохранённое состояние.
- [x] Загрузка из формы добавления остаётся совместимой через существующий interface; задача не требует завершения новых форм RSS/Telegram.
- [x] Настоящий HTTP/browser подтверждает поведение на синтетических фидах; общий progress/history renderer удалён и предоставлен interface для YouTube.

- [x] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
