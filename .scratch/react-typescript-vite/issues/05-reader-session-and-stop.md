# 05: Сессия вкладки, сбор и остановка

**What to build:** Пользователь запускает сбор, останавливает Око и работает с несколькими вкладками с прежней семантикой через typed API.

Blocked by: 03 — Первый React-сценарий через сгенерированные библиотеки.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Операции сессии, сбора и остановки подключены к generated DTO/SDK; toolbar отражает реальные исходы и доступность команд.
- [ ] Один владелец управляет heartbeat, polling, BroadcastChannel и закрытием/восстановлением вкладки; прежние интервалы, lease/grace и допуск результатов сохранены.
- [ ] Повторный React setup/cleanup не удваивает циклы и не отправляет stop/close; keepalive, token и диагностические headers сохраняются.
- [ ] Неизвестный сетевой исход не вызывает повтор команды; смена области, просмотр и остановка не принимают старые ответы.
- [ ] HTTP и Playwright подтверждают stop, закрытие последней вкладки, повторное открытие и межвкладочное согласование; выделен стабильный interface обновления для следующих UI-срезов.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
