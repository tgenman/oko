# 11: Подключение и переподключение Telegram

**What to build:** Пользователь подключает Telegram-фид или меняет его подключение, сохраняя аккаунт, тему форума, историю и автопрочитывание.

Blocked by: 09 — Все настройки и редактор фида.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Аккаунты, темы, проверка и подключение используют generated DTO/SDK и React-формы.
- [ ] Новый источник и переподключение существующего фида сохраняют разных владельцев черновиков; переключение между фидами их не смешивает.
- [ ] Начальная история, выбор папки и автопрочитывание сохраняют текущие значения и семантику.
- [ ] Поздние каталоги/ответы и успешная запись после ухода корректно согласуются без возврата пользователя в старый экран.
- [ ] HTTP/browser используют синтетический Telegram adapter; ни аккаунт пользователя, ни реальные диалоги не вызываются, заменённые renderers удалены.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
