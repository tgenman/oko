# 12: Импорт OPML

**What to build:** Пользователь выбирает OPML, проверяет план и конфликты и получает импортированные фиды без потери текущего контекста.

Blocked by: 08 — Меню, переходы и одно поле настроек.

Status: done

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [x] Preview и подтверждение импорта используют существующий JSON wire-формат через generated DTO/SDK, а ввод/план отображаются в React.
- [x] Новый файл инвалидирует старый preview; выбор конфликтов и подтверждение относятся к текущему файлу.
- [x] Успешный импорт обновляет каталог после закрытия, но не открывает прежнее меню и не уничтожает черновики нового.
- [x] Сохранены браузерный файловый ввод, ошибки, мобильная навигация и возврат к списку фидов.
- [x] Настоящий HTTP/browser проверяет успех, конфликт и задержанные ответы; старый renderer импорта удалён.

- [x] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.

Verification: [React settings](../../../docs/verification/react-settings.md).
