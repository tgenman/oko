# 12: Импорт OPML

**What to build:** Пользователь выбирает OPML, проверяет план и конфликты и получает импортированные фиды без потери текущего контекста.

Blocked by: 08 — Меню, переходы и одно поле настроек.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Preview и подтверждение импорта используют существующий JSON wire-формат через generated DTO/SDK, а ввод/план отображаются в React.
- [ ] Новый файл инвалидирует старый preview; выбор конфликтов и подтверждение относятся к текущему файлу.
- [ ] Успешный импорт обновляет каталог после закрытия, но не открывает прежнее меню и не уничтожает черновики нового.
- [ ] Сохранены браузерный файловый ввод, ошибки, мобильная навигация и возврат к списку фидов.
- [ ] Настоящий HTTP/browser проверяет успех, конфликт и задержанные ответы; старый renderer импорта удалён.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
