# 08: Меню, переходы и одно поле настроек

**What to build:** Пользователь открывает меню, меняет одно поле, уходит и возвращается без потери черновика и ошибочной навигации.

Blocked by: 05 — Сессия вкладки, сбор и остановка.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Меню и стек страниц имеют React-владельца; неперенесённые формы сохраняются в непересекающихся legacy-контейнерах.
- [ ] Одно текстовое поле с наследованием использует generated настройки от запроса до сохранения и React-показа; методы и HTTP-ошибки сохранены.
- [ ] Проверен сценарий сохранить A → ввести B → Back/закрыть → ответ A → открыть: сохранено A, черновик B остался.
- [ ] Save, reset наследования и discard различаются; поздние успехи/ошибки не меняют новый объект или повторно открытое меню.
- [ ] Сохранены opener, Escape, клавиатура и адаптивный переход списка/деталей; есть interface текущего контекста и каталога для следующих форм.
- [ ] HTTP/browser и снимки подтверждают сценарий; старый renderer перенесённого поля удалён без переноса всех форм заодно.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
