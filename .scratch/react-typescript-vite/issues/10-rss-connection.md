# 10: Подключение RSS

**What to build:** Пользователь проверяет RSS-источник, выбирает папку и начальную историю, затем получает подключённый фид.

Blocked by: 08 — Меню, переходы и одно поле настроек.

Status: ready-for-agent

Parent: [Спецификация](../spec.md). Подготовка тикета не разрешает реализацию.

- [ ] Проверка и создание RSS-фида используют canonical DTO/SDK и React-форму; сохраняются реальные сообщения проверки и ошибки.
- [ ] Поддержаны выбор существующей/новой папки и начальная история по количеству/дате; переключение вкладок сохраняет положенный ввод.
- [ ] Успешная запись очищает только отправленные значения и обновляет каталог даже после закрытия формы; поздний ответ не навигирует новый контекст.
- [ ] Типизированные catalog operations переиспользуются без новой схемы; ещё не перенесённые части интерфейса получают прежнее onChanged-согласование.
- [ ] HTTP/browser с синтетическим фидом и desktop/mobile снимки подтверждают успех, ошибку и поздний ответ; прежний renderer RSS удалён.

- [ ] Для затронутого сценария сохранены существующие API/security, оформление и поведение; реальные HTTP/browser-проверки выполнены на временных данных и синтетических adapters. Фактический результат записан отдельно.
