# Три самостоятельных меню с сохранением контекста пользователя

## Outcome

Пользователь отдельно добавляет фиды, управляет фидами и папками и настраивает Око, не теряя черновики или место чтения. Этот тикет охватывает согласованную спецификацию целиком: граница диалогов, выбор объекта, переходы и черновики составляют единый пользовательский сценарий и общий жизненный цикл интерфейса.

## Acceptance

- [ ] Три кнопки и три самостоятельных диалога, только один открыт.
- [ ] Вкладки RSS/YouTube, Telegram, OPML; существующие возможности подключения сохранены.
- [ ] Добавление и дубль открывают нужный фид; массовый импорт открывает список; успешное добавление очищает форму.
- [ ] Папки и фиды группируются в списке; настройки выбранного объекта и наследование доступны.
- [ ] На узком экране список и детали разделены переходом и кнопкой «Назад».
- [ ] Общие настройки и подключения моделей находятся в настройках Око.
- [ ] Telegram переподключается внутри настроек без новой начальной истории.
- [ ] Черновики форм и разных объектов сохраняются до закрытия вкладки; закрытие и переключение не сохраняют автоматически.
- [ ] Прогресс и управление историей доступны; читательское состояние, позиция и фокус возвращаются после закрытия/Escape.
- [ ] Браузерные проверки нового поведения и существующие регрессии проходят; визуально проверены широкий и узкий экраны.
- [ ] Независимые ревью Standards и Spec не оставляют открытых замечаний; итоговая проверка документирована.

## Testing

Существующая браузерная граница настоящего интерфейса, управляемые ответы внешних источников. Существующий HTTP API для регрессий сохранения. Применять tdd вертикальными сценариями; тестировать наблюдаемое поведение, не структуру модулей. Личные данные и реальные модели не использовать.
