# Создание папки из Move to Folder — прототип

Вопрос: как вводить название новой тематической папки из второго списка
контекстного меню фида? Вариант пока не выбран; production-поведение не изменено.

## Просмотр

```sh
node frontend/src/reading/create-folder-prototype.mjs
```

http://127.0.0.1:5187/create-folder-prototype.html?variant=A

- A — New Folder… после разделителя открывает отдельный диалог.
- B — пункт заменяется полем под существующими папками.
- C — весь второй список заменяется формой с возвратом к выбору папки.

Нижняя панель переключает варианты и обновляет URL. Вне меню и поля работают
стрелки влево/вправо. Правый клик, щелчок по Naked Science или Shift+F10
открывает меню повторно. Reset demo сбрасывает данные.

Общее поведение: Create & Move создаёт папку и переносит выбранный фид.
Внешние пробелы обрезаются, пустое и занятое название отклоняются.
Cancel/Escape не создаёт папку и не переносит фид; возвращает к списку папок.
Текущая папка отмечена галочкой. Все данные синтетические, только в памяти;
серверный транспорт и личные подписки не подключены.

Предложение для выбора: A. Отдельный диалог даёт обычное поле с понятными
подтверждением и отменой; список назначения остаётся простым меню.
Это рекомендация, а не зафиксированное решение пользователя.
