# New Folder в Move to Folder

Пользователь выбрал вариант A и поручил реализацию 2026-10-19.
New Folder… под разделителем второго списка открывает диалог с названием,
Cancel и Create & Move. Подтверждение создаёт новую папку и перемещает фид;
пустое/занятое название отклоняется, пробелы по краям обрезаются.

PATCH /api/v3/feeds/{identity} расширен полем new_folder, несовместимым с folder_id.
Создание папки и перенос выполняются в одной SQLite-транзакции под блокировкой
Runtime. Ошибка валидации сохраняет каталог; неизвестный исход не повторяется
автоматически. Поздний ответ согласует данные, не закрывая новый диалог.
