# Компактный список и владение UI
Status: claimed
Assignee: root
Spec: ../spec.md

Новый владелец списка: строки, превью, меню/счётчик/даты, фокус, прокрутка, локальная сортировка/ширина, поздние ответы и ошибки. Связать с существующим владельцем открытого материала. Синтетические браузерные данные позволяют работать независимо от тикета 01; интеграционная приёмка зависит от него.

Контракт строки: существующие поля плюс `snippet` (plain text) и `feed_title` (имя фида). Источники групп остаются в `sources`. Для локальных превью используются существующие `images` и `attachments`.

Приёмка: критерии 1–3, 6–14 в браузере.
