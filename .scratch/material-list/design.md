# Список материалов в стиле News Explorer

Status: resolved

Согласованное поведение и критерии приёмки: [спецификация](spec.md). Реализация отдельно разрешена и завершена; [проверка](../../docs/verification/material-list.md).

## Задача

Сделать компактный список материалов для тематической папки, отдельного фида и всех материалов. Ориентир — приложенные пользователем скриншоты News Explorer. При проектировании реализация не была разрешена.

## Согласованные решения

1. Один вид списка для папки, фида и «Всех материалов». Выбор меняет название в шапке и состав списка.
2. Строка содержит превью слева, заголовок до двух строк, краткий текст до двух строк, название фида и дату. Длинный текст обрезается многоточием. Событие и обзор имеют отметку типа карточки. Полный материал открывается справа.
3. Открытие не означает «Просмотрено». Выбранная строка выделяется фоном. Точка непрочитанного не добавляется. «Просмотрено» сохраняет существующее значение: удаление собранного содержимого.
4. Название и число карточек находятся в шапке. Сортировка, показ скрытых, обновление обзора и сжатие истории находятся в меню «⋯». «Всё просмотрено» — отдельная кнопка шапки папки с существующим подтверждением. Недоступные действия отсутствуют в меню фида.
5. При сортировке по дате список имеет разделители «Сегодня», «Вчера», затем конкретные даты. При сортировке по важности разделители отсутствуют.
6. Описание YouTube-видео сохраняется из Atom при обычном сборе, без дополнительных запросов к YouTube. В строке используется описание; для ранее собранных видео без описания — начало сохранённых субтитров. Для других публикаций — начало сохранённого текста; для событий и обзоров — начало готовой сводки. При отсутствии текста блок краткого текста отсутствует. Сохранённые субтитры повторно не запрашиваются.
7. Превью публикации — первая сохранённая картинка. При её отсутствии используется значок типа материала в той же области. Событие и обзор имеют свои значки вместо картинки одного из исходников.
8. Начальная ширина списка — 440 px. Граница с областью чтения перетаскивается. Выбранная ширина сохраняется между запусками. Объём — настольный интерфейс.
9. Подпись счётчика — «15 карточек», по числу текущих строк с учётом показа скрытых. Дерево сохраняет счётчики исходных публикаций.
10. Обновление списка сохраняет видимую строку и её положение в области прокрутки. Поступление новых карточек не сдвигает читаемый участок. Загрузка превью не меняет высоту строки.
11. В текущем сеансе положение прокрутки запоминается отдельно для каждой папки, фида и всех материалов. При возвращении положение восстанавливается; первый вход открывает начало списка. Переключение очищает открытый материал по действующему правилу.
12. Стрелки вверх/вниз перемещают фокус между строками; Enter открывает материал. Перемещение фокуса не открывает материал и не означает «Просмотрено». Клик открывает материал сразу.
13. Дата, время и разделители используют часовой пояс устройства. Если дата публикации неизвестна, подпись — «Дата неизвестна». При сортировке по дате такие карточки находятся в отдельной группе в конце списка.
14. После «Просмотрено» строка исчезает, область чтения очищается без автоматического открытия следующего материала. Фокус переходит к следующей строке, при её отсутствии — к предыдущей.
15. Первая загрузка: «Загрузка материалов…». Пустой список: «Нет материалов». Ошибка обновления сохраняет показанные строки и добавляет сообщение с кнопкой «Повторить»; исключение попадает в диагностику. Ошибка превью заменяет его значком, не блокируя строку. Незавершённая загрузка материала обозначается подписью «Загружается».
16. Ширина списка ограничена 320–640 px, начальная — 440 px. Для области чтения остаётся минимум 360 px. Ширина ограничивается доступным местом при уменьшении окна. Граница управляется мышью и стрелками клавиатуры. Мобильная компоновка вне объёма.
17. Описание ранее собранного видео сохраняется при его появлении в обычной загрузке Atom. Отдельного массового обхода старых видео нет. До получения описания используются сохранённые субтитры, если есть. Повторные запросы полученных субтитров не выполняются.
18. Одна сортировка для всех списков, по умолчанию «Новые сверху». Выбор сохраняется при переключениях и между запусками.

## Проверенные ограничения текущего продукта

- Список считает карточки, дерево папок и фидов — исходные непросмотренные публикации. Карточка события или обзора может представлять несколько публикаций.
- Сортировки: новые сверху, старые сверху, по важности. Группировки по датам пока нет.
- В список передаются заголовки и даты, но отдельного краткого текста нет. Для YouTube описание из Atom сейчас отбрасывается; сохранённые субтитры могут быть доступны.
- Картинки оригиналов уже сохраняются локально. Для событий и обзоров превью в проекции списка пока нет.
- Выбор фида сохраняет событие или обзор целиком, если в его составе есть публикация этого фида.
- Смена папки или фида очищает открытый материал. Сортировка сохраняет выбор. Исчезновение карточки очищает открытый материал.
- Средняя колонка сейчас имеет ширину 340 px.

Источники: `oko/web/app.js`, `oko/web/index.html`, `oko/web/style.css`, `oko/reader/app.py`, `oko/reader/composition.py`, `oko/collection/youtube/source.py`.
