# Скрытая запасная заглушка Telegram

Исправить только скрытый `.media_not_supported_cont` рядом с доступным содержимым. Самостоятельная заглушка и активный `.media_not_supported` остаются ошибками/ограничениями по прежним правилам. Пять реальных постов только с пересылкой не перепроверять и не менять. После обновления вручную перепроверить только 25 подтверждённых скрытых заглушек; сохранить текст/ссылки и не создавать видимую авторскую правку при исправлении ложного ресурса.

Регрессии: частичный Telegraph без автоматических повторов, ручной повтор, красный блок, сохранение полной копии/версий, настоящие внешние вложения и посты без веб-содержимого. Влить main и обновить рабочее Око.
