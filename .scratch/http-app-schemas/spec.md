# Однократная компиляция схем HTTP-ответов

Основа: локальный проверенный пакет 4849a49, рабочие настройки Око не менять.

- Полные generated Pydantic response contracts подготавливаются один раз на тип
  в процессе. Кэш ограничен, первая компиляция синхронизирована между threads.
- Прямые и включённые router используют одинаковую подготовку через APIRoute
  и публичные hooks Pydantic. FastAPI не monkeypatch-ится.
- Проверка выполняется для каждого ответа. Данные/результаты/ошибки не кэшируются.
- Runtime, Store, Journal, Lifetime, BrowserSessions, handlers и зависимости
  остаются отдельными для приложения; кэш не удерживает приложения/Runtime.
- Сохраняются strict validation, фильтрация подклассов, aliases, include/exclude,
  unset/default/null, computed fields, field serializers и OpenAPI definitions.
- Canonical API/SDK и рабочая установка не меняются. Нет новых пользовательских
  настроек/флагов и повторного использования mutable client между сценариями.
- Сравнить cold/warm создание приложений, реальный HTTP и полный all tools.
  Зафиксировать цену сериализации больших ответов и прежний browser p95 budget.

Схемы в кэше принадлежат загруженному коду. Новая версия кода запускается новым
процессом. Штатные дешёвые FastAPI обёртки маршрутов и scalar parameters остаются
per app; тело большого контракта ответа компилируется единожды. Произвольная
unhashable metadata делегируется обычному FastAPI.
