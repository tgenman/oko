# Копии библиотек и матрицы валидации

База: `7865118` (код слит в main как `55705e1`).

- Подготавливать закрытые синтетические библиотеки один раз на форму данных в процессе тестов. Каждый сценарий получает собственную файловую копию SQLite и материалов; mutable Store/client между тестами не разделяются.
- Кэш ограничен жизнью процесса и временным каталогом. Исходные данные строятся настоящим Store; результаты тестов не кэшируются. Ошибка подготовки не публикует неполный шаблон.
- Browser performance получает библиотеку через уже существующий Python fixture host, с отдельным хранилищем на сценарий. Оба размера, idle/active, 320 кликов, HTTP и прежний p95 <200 мс сохраняются.
- Матрицы ошибок OpenAPI вызывают настоящий `scripts.api.contract` в процессе. Оставить реальные CLI-проверки canonical контракта, успешного bundle, ошибок/exit codes/отсутствия частичной записи для validate и bundle, SDK и Git index.
- Новые тесты проверяют независимость копий через HTTP, неизменность шаблона после мутаций, повторную подготовку после ошибки и уборку временного каталога.
- Измерить `./scripts/check all tools --compact` до и после одинаковой командой, не запускать конкурирующие benchmark. Отдельно показать результаты и ограничения каждого прогона.
- Production код, настройки и рабочий экземпляр Око не меняются.
