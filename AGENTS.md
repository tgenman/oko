# Работа над Око

## Контекст задачи

- Для продуктового поведения используй [GLOSSARY.md](GLOSSARY.md) и спецификацию текущей задачи. Спецификации и тикеты находятся в локальном Markdown-трекере: [правила](docs/agents/issue-tracker.md), [статусы](docs/agents/triage-labels.md).
- Для выбора объёма работы, проверок и завершения используй [порядок разработки](docs/agents/development.md). По умолчанию ограниченную задачу выполняет один исполнитель; явно вызванный пользователем скилл задаёт свой процесс.
- При запросе на проектирование изменяй документы в согласованном объёме. `ready-for-agent` означает готовность описания, а начало реализации определяется указанием пользователя.

## Архитектурные решения — читать по затронутому сценарию

- Действия читателя, отмена, остановка, внешние ожидания: [управление работой](docs/architecture/reader-work.md). Runtime владеет выполнением, Store — сохранением и восстановлением.
- Открытие материала, версии и медиа, поздние ответы браузера: [открытый материал](docs/architecture/opened-material.md).
- Фильтрация, тезисы, события, обзоры и актуальность результатов: [согласование обработки](docs/architecture/processing-coordination.md); этапы и восстановление обзора — [прогресс обзора](docs/architecture/digest-progress.md).
- Состав карточек, завершение чтения папки, скрытые материалы: [состав чтения](docs/architecture/reading-composition.md).
- Перенос кода, общие контракты, организация тестов: [структура пакетов](docs/architecture/package-layout.md).

## Проверка и данные

- Проверяй поведение через существующий HTTP interface читателя и настоящий браузерный интерфейс. Устройство браузерных проверок и зависимости: [инструкция](tests/browser/README.md).
- Для автоматических проверок используй временные хранилища и синтетические источники/модели. Работа с личными подписками, Telegram-аккаунтом или настоящим обработчиком требует соответствующего задания пользователя.
- Фактическую проверку записывай отдельно от плана: что запускалось, результат, ограничения. Исторические отчёты сохраняют результаты своих версий.
