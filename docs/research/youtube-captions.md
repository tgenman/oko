# YouTube: обновления и субтитры

2026-10-09. Для №08 выбран публичный Atom `https://www.youtube.com/feeds/videos.xml?channel_id=<ID>` из уже распознанных OPML-подписок. RSSSource сохраняет границу периода и переигрывает конечное окно; потерю истории нельзя считать исключённой. YouTubeSource принимает только `yt:video:<11 символов>` и создаёт каноническую ссылку видео. Превью загружается отдельно из `i.ytimg.com`, до 2 МБ, с проверкой сигнатуры JPEG/PNG.

Для субтитров используется [youtube-transcript-api 1.2.4](https://github.com/jdepoix/youtube-transcript-api). Документированный interface: `YouTubeTranscriptApi().list(video_id)`, выбор дорожки, `track.fetch()`, текст snippets. Ручные и автоматические дорожки допустимы; предпочтение ru, затем en, затем доступному языку, ручной дорожке внутри языка. Перевод не запрашивается. Библиотека использует неофициальные интерфейсы YouTube; блокировки IP и изменения сайта остаются ограничением интеграции. Cookies, аккаунты и обход блокировок не подключаются.

Синхронная библиотека выполняется в отдельном принадлежащем Око процессе: один запрос, вывод JSON по pipe до 2 МБ, общий срок 60 секунд. При отмене/таймауте процесс уничтожается и pipe освобождается. stderr отключён, содержимое не записывается в промежуточные файлы. Переменные прокси из среды не наследуются HTTP-клиентом, как у RSS. Видео и аудио не скачиваются; ASR отсутствует.

Субтитры становятся оригинальным текстом материала. Состояния `not_requested / available / unavailable / error` сохраняются в контентном Markdown, вместе с заголовком и причиной. Высокая важность автоматически включает субтитры и тезисы; иначе используется эффективный режим тезисов. После включения ранее не запрошенные материалы ставятся на повторную загрузку. Ошибка и отсутствие требуют явного повтора; заголовок не передаётся модели вместо отсутствующих субтитров. Настройки обработчика, промпт и разрешение публичного AI остаются общими.

Старые импортированные YouTube-фиды без транспорта подключаются выбором «YouTube: обновления и субтитры» в настройках существующего фида. Повторный импорт сохраняет существующую идентичность и транспорт; новая подписка подключается автоматически. Транспорт можно отключить.
