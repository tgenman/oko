# Проверка прогресса обзора за период

2026-10-09. Основание: [дизайн](../architecture/digest-progress.md). База изменения: `56cd7a4`; первая реализация: `7b8fa39`.

## Что изменилось

`Progress` остаётся типизированным до записи. Неизменяемый `ReviewStep` содержит точный запрос и исходное состояние, привязан к заданию, поколению и актуальности исходников. Подготовка выбирает этап один раз; принятие использует этот же план. Счётчики, согласованность стадий и ссылки проверяются при чтении и переходе. `Runtime` освобождает временный план при любом исходе задания.

Корректные файлы старого формата продолжают работать. Частичный файл не отображается при ошибочном done-состоянии задания. Повреждённый прогресс пересобирается из прежнего manifest без удаления оригиналов и добавления новых поступлений. При корректном внешнем изменении прогресса старый ответ отбрасывается, затем подготовка продолжается с нового состояния.

Формат SQLite/Markdown, промпты, размер запросов, лимит раундов, контракт обработчиков и поведение читателя сохраняются. Общая атомарная запись Store и существующие проверки допуска и отмены не заменялись.

## Доказательства

Первая проверка сначала воспроизвела HTTP 200 и ложную готовность при `parts=999999`. Расширение проверок выявило пять дополнительных случаев: пустые тезисы непустого набора, неверный указатель, раунд вне стадии и неизвестные источники в результатах. Проверка задержанного ответа сначала показала, что старый ответ всё ещё попадал в последующий финальный запрос; после введения плана он отбрасывается.

Все новые проверки проходят через HTTP interface с настоящими временными SQLite/файлами и заменяемым AI adapter:

- 12 вариантов повреждённого прогресса: счётчики, флаги, пустые результаты, неизвестные ID, неверный URL и чужая ссылка в тексте.
- Корректное изменение промежуточного тезиса во время задержанного ответа: старый ответ не применяется, первая принятая часть не повторяется.
- Продолжение посреди раунда сжатия после 503 и перезапуска: принятые группы и исходные части не повторяются; файл сохраняет прежние поля.
- Совместимость одной части после сбоя атомарной записи, включая отсутствующие необязательные поля старого формата: второго обращения к модели нет.
- Пустой набор источников AI при скрытых оригиналах: обзор завершается и переживает перезапуск без обращения к модели, полный набор оригиналов удаляется по «Просмотрено».
- Новое поступление после создания обзора остаётся вне его набора при восстановлении повреждённого прогресса.

Сохранены проверки больших исходников, глобального промпта, отзыва публичного AI, просмотра и остановки во время ответа, аварий процесса после переноса файла и после транзакции удаления.
