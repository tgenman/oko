## Реализовано

Импортированный YouTube-фид подключается в общей очереди. Устойчивый ID видео, каноническая ссылка, заголовок, время и локальное превью. Высокая важность включает субтитры и тезисы автоматически; для остальных действует режим фида с наследованием. Субтитры — исходный текст, тезисы используют существующий контракт, промпт, выбранный обработчик и разрешения. Нет видео/аудио/ASR. Нет генерации по заголовку без субтитров. Ошибка, отсутствие и незапрошенные субтитры различаются, доступен повтор.

Общий lifecycle сохраняет защиту от поздних ответов; просмотр удаляет Markdown субтитров, превью и тезисы. Перезапуск сохраняет готовый результат и не запускает модель повторно.

После сообщения пользователя о доступности YouTube сеть повторно проверена через существующие адаптеры, без cookies, аккаунта, видео и аудио. Исходная точка: `75c0ffe15d90a03fc28edba607fd48600a282f17`. Код менять не потребовалось.

- Настоящий `LocalCaptions` через принадлежащий Око дочерний процесс получил субтитры `H14bBuluwB8` (5350 символов), `jNQXAC9IVRw` (217) и `h6CmKF-mN2U` (4115). Для `aqz-KE-bpKQ` получен штатный результат `None`: субтитры недоступны. Последний проверен на границе адаптера; API-поведение этого результата проверено отдельно с управляемым внешним источником.

Материал содержит 4115 символов настоящих субтитров, заголовок, каноническую ссылку и доступное локальное изображение с сигнатурой JPEG/PNG.
