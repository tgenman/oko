# Ограничение запросов субтитров и прокси

Дата: 2026-10-13. База: `309a8097c3cddbfd13ed77a24ad73b3fe2f3caa0`.
Спецификация: [управление запросами YouTube](../../.scratch/youtube-request-control/spec.md).

## Реализованное поведение

- Один общий допуск получения субтитров для всех YouTube-фидов хранилища: не чаще одной операции в 10 секунд. Операция выбора/получения дорожки может содержать несколько HTTP-запросов SDK.
- Блокировка SDK или HTTP 429 сохраняет общую паузу 15 минут, далее удвоение до 6 часов. Более длинный корректный Retry-After имеет приоритет. Пауза и минимальный интервал восстанавливаются независимо от начала монотонных часов нового процесса.
- Ожидание освобождает слот сбора. После паузы допускается одна операция; другие источники и сохранённые материалы остаются доступны. Автоповторы блокировки ограничены тремя попытками материала. Явный повтор начинает новый цикл материала, сохраняя общую паузу.
- Отсутствие субтитров и обычная сетевая ошибка не приостанавливают остальные фиды и не включают автоматические повторы. Сохранённый текст повторно не запрашивается.
- HTTP/HTTPS-прокси и учётные данные задаются в общих настройках. Сохранение формы не обращается к YouTube. Маршрут явный, без наследования proxy-переменных среды и без прямого fallback. Учётные данные не возвращаются при чтении настроек; локальный файл создаётся с правами 0600. В worker они передаются через stdin.
- Ошибки worker сохраняют класс, безопасное сообщение и позиции стека. URL, строки исходного кода и цепочки исключений не пересылаются; учётные данные очищаются до передачи диагностики.
- Настройки показывают маршрут, причину паузы и срок следующего допуска. Черновики сохраняются; поздние ответы не восстанавливают закрытую форму и не заменяют новый ввод. Пустое поле сохраняет прежний пароль; удаление выполняется отдельным флажком.
- Смена подключения, остановка, закрытие читателя и «Просмотрено» сохраняют существующие правила отмены. Поздняя блокировка прежнего запроса не меняет состояние нового подключения; новый worker не запускается одновременно с ещё не завершившимся прежним вызовом.

## Фактические проверки

Использован Python существующего окружения, Node и Playwright локального runtime. Все хранилища, источники, обработчики и прокси в тестах синтетические.

| Настройки и пауза в настоящем браузере, включая настоящий HTTP-сервер | 2 passed |
| Первый полный `./scripts/check all` | 66 browser passed; 343 Python passed, 3 failed, 1 skipped; contracts, syntax, lint, HTTP assets, diff, types (42 файла), CLI — PASS; 239.91 с |
| После исправлений: версии источников, события, YouTube, прокси и HTTP-допуск | 54 Python passed; 2 browser passed; contracts, lint, syntax, types (42 файла), diff — PASS; 28.87 с |

Три падения полного прогона: один существовавший в исходной базе неверный импорт NoCaptions и два сценария событий, ожидавшие загрузку второго видео без нового 10-секундного интервала. Импорт исправлен на существующий синтетический клиент; проверки событий переведены на управляемые часы с соблюдением интервала. Все три сценария входят в успешный повтор. После исправлений весь полный набор повторно не запускался; успешный повтор относится к указанным затронутым наборам. Один пропуск полного набора относится к отдельному API загрузки истории YouTube, отсутствующему в исходной базе этого worktree.

На раннем целевом прогоне существующего YouTube-набора было 5 падений из 12. После сохранения безопасной диагностики SDK и адаптации повторов к управляемому времени все 12 входят в успешный итоговый повтор.

Проверка прокси использует реальные Session, SDK, дочерний процесс и локальный TLS CONNECT с временным сертификатом. Подменены только адреса внешнего сервиса и тестовый центр сертификации; внешние соединения запрещены. Проверены list/fetch, авторизация прокси, игнорирование переменных среды, отсутствие прямого fallback, HTTP 429 с числовым/датированным/некорректным Retry-After, блокировка SDK и удаление подписанных URL из диагностики.

Независимое read-only ревью выполнено относительно указанной базы с учётом новых файлов. Замечание о случайном удалении сохранённого пароля после очистки введённого значения исправлено и покрыто браузерным сценарием; после исправления подтверждённых actionable findings нет.

## Ограничения

Настоящий YouTube, личные подписки, платный прокси и пользовательский экземпляр не запускались. Проверки подтверждают управление запросами и маршрут прокси, но не снятие блокировки реального IP. Worktree не содержит незакоммиченных изменений основной рабочей копии, включая новую загрузку истории YouTube. Коммит, merge и перезапуск пользовательского экземпляра не выполнялись.
