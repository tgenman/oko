2026-10-20. [Задача #63](https://github.com/tgenman/oko/issues/63).
[Согласованная спецификация](../../.scratch/rss-pagination/agreed-spec.md).

## Проверенное изменение

Ветка `codex/rss-pagination`, база `4c13bffe63f8bd6cfc585bb765bd01c3ae034391`.
Реализация `700d2d8`, исправления ревью `076dc57`, окончательная обработка
некорректных адресов и XML base `a7269a5`. Последующая правка браузерного теста
меняет только скриншоты: viewport вместо fullPage, анимации отключены.

RSS/Atom следует next/prev-archive, сохраняет отложенные архивы и выбирает N
или публикации до первой даты старше нижней границы. Новые поступления не
расходуют N. Недобор имеет сохраняемую причину. Ошибка страницы завершает
попытку без автоматического повтора, частичный результат сохраняется.
Доступны новый подбор и отмена для подключённого RSS. Старые курсоры сохраняют
поведение до явно запрошенного нового подбора. Старым результатам причина
завершения не приписывается.

## Проверки

Все проверки использовали временные SQLite/файлы и синтетические внешние
источники. Проверочные деревья получены task_changes.py из явно выбранных
файлов; прежние правки пользователя исключены. Их HEAD/индекс сохранены.

| Повтор затронутых `ui python types --compact --files …` после 076dc57 | PASS: сервер 95, браузер 14, HTTP 9; contracts, syntax/lint, types, build и diff PASS. 90.73 s. |

В полном прогоне два UI-теста и один API-тест сохраняли прежнее ожидание:
отсутствие управления историей RSS, отказ POST history и безусловный текст
завершения. Ожидания приведены к согласованному поведению. Четвёртый сбой
выявил реальную регрессию: повторное включение в историю заменяло исход
«недоступно» сохранённым анонсом; исправлено сохранением source_deleted
перед классификацией материала. Его сценарий прошёл повтор.

Ранние ручные запуски широких Python/браузерных наборов также встречали
устаревшую сборку frontend после генерации API. Они не считались успехом;
после сборки и в изолированных деревьях выполнялись перечисленные повторы.
Полный all на окончательном дереве заново не запускался: повторены затронутые
проверки, результаты неизменённых успешных групп сохранены.

Критерии HTTP включают 200 материалов через RSS и Atom, перекрывающиеся
страницы и изменённый GUID, next вместе с архивом, пустую промежуточную
страницу, относительные ссылки и xml:base, дату включительно и раннюю
остановку, новые поступления, просмотренные материалы, ошибки первой и
последующей страницы без повтора, ошибочные href/root/channel/entry bases,
неоднозначные ссылки, цикл, реальный предел 1000 страниц и перенаправление
на ранее посещённую ветвь у лимита. Проверены штатное выключение/Start,
перезапуск и ответ источника, игнорирующий отмену.

## Spec

Независимый reviewer: rss_spec_review. Исправлены три первоначальных замечания:
новый подбор поверх legacy cursor, некорректный адрес продолжения и превышение
лимита при перенаправлении в другую посещённую ветвь. Повторное ревью выявило
тот же класс ошибки в XML base; для root/channel/entry добавлены падающие
HTTP-регрессии, затем исправлена граница обработки. Итоговое ревью a7269a5:
все замечания устранены, новых actionable замечаний нет.
