## Работа SQLite, отдельно от числа SQL

Синтетический набор планов: 100 фидов, 20000 публикаций (10000 непросмотренных), 20001 заданий, 20000 последних успешных команд с разными identity, 100000 reader_entities; выполнен ANALYZE. Триггеры отключены только при подготовке этого планового набора. Счётчик VM имеет шаг 100: ноль означает менее 100 инструкций. Это не коэффициент ускорения HTTP.

| Запрос | VM до | VM после |
|---|---:|---:|
| Список одного фида | 84200 | 4500 |
| Поиск проблемных команд | 140000 | <100 |
| Очистка архива команд без вытесненных квитанций | 680000 | <100 |
