# Telegram web: частичный результат при обрыве загрузки

22 октября 2026. База e7fa7d7cdba9fd1a7ec9690bbc86243ba739f975.

## Причина и изменение

Рабочий retry поста danieltrbn/3606 получал HTTP500 от CDN видео 3611,
затем обрыв тела 1 932 675 из 13 141 780 байт. httpcore.RemoteProtocolError
не перехватывался Downloader и превращался в общую ошибку Runtime.

Downloader переводит ProtocolError в понятную ошибку вложения; незавершённый
incoming-файл удаляется, остальные ресурсы продолжают собираться. При пригодном
тексте/вложениях WebTelegram сохраняет download_partial, завершает работу без
collection_error и больше не повторяет загрузку автоматически. Store учитывает
этот результат при обычном обновлении и после рестарта. Явный retry сохраняется.

Читатель использует существующий красный callout: стабильный Telegram permalink
конкретного сообщения, причина (HTTP-код/обрыв/таймаут), отметка сохранённой копии.
Telegraph остаётся отдельным блоком. Флаг не является авторской правкой.
Сохраняются SourceDeferred/429, mixed terminal failures и проверка потери локального
файла. Независимое ревью обнаружило край совместного сбоя поста и Telegraph:
ранний guard полного Telegraph больше не отбрасывает download_partial поста.
