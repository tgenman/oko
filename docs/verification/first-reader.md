## Ревью

Две независимые проверки по code-review относительно исходного коммита `c4a6978`: Standards — замечание к типизации задания исправлено введением Job; Spec — исправлены повтор удаления при восстановлении и неограниченное ожидание отмены. Повторное ревью обоих направлений не выявило оставшихся блокеров. Добавлены проверки повторной ошибки удаления после рестарта и остановки процесса даже с адаптером, игнорирующим отмену.

Финальная проверка: `python -m pytest -q` — 15 passed; `mypy oko` — без ошибок; `node --check oko/web/app.js` — без ошибок. В тестовом HTTP-клиенте есть предупреждение Starlette о будущем переходе с httpx на httpx2; оно не касается рабочего сервера.
