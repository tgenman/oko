# Переносимость браузерной проверки истории

PR [#238](https://github.com/tgenman/oko/pull/238), CI
[42577286503](https://github.com/tgenman/oko/actions/runs/42577286503),
коммит `31d6c366`: `browser-1` завершился с 94 passed и двумя ошибками.
Оба сценария повреждённой истории пытались сохранить скриншот в `/private/tmp`,
которого нет на Linux runner. До ошибки они дошли до снятия скриншота; это
падение тестового пути, а не доказательство ошибки пользовательского поведения.

Пять путей скриншотов переведены на общий `artifactPath`, который создаёт
каталог тестовых артефактов или использует системный временный каталог.
Локальный повтор с синтетической PostgreSQL и настоящим HTTP: **2 passed**;
скриншот проблемы просмотрен. Результат Linux CI после исправления должен
проверяться отдельно на новом SHA.
