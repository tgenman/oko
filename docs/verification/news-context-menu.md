## Поведение

Правый клик либо ContextMenu/Shift+F10 на карточке открывает пять английских действий: Mark Above as Read, Mark Below as Read, Mark as Read, Open in Browser, Copy Link. Обычный клик сохраняет прежнее открытие материала. Меню действует на карточку под указателем, не переключая уже открытый материал.

Above/Below захватывают точные ID выше/ниже цели в текущем порядке `cards`; сама цель исключена. Учитываются сортировка, область all/folder/feed и текущий показ скрытых. Карточки за пределами viewport включены, скрытые вне текущего списка не включены. Пустой диапазон выключен. Наведение/фокус подсвечивают охват; перед запуском диапазона показаны заголовки и количество. Новые поступления после подготовки подтверждения не расширяют действие.

Используются существующие per-material `viewed` команды и их receipts, последовательно, без нового API, DTO, настройки или миграции. Частично выполненный диапазон не атомарен: принятые просмотры сохраняются. Stop/закрытие/смена области прекращают ещё не отправленные команды; уже отправленный запрос может завершиться. Ошибка останавливает выполнение без автоматического повтора, показывает количество выполненных; дальнейший исход сверяется существующим журналом команд.

Открытый материал закрывается только при подтверждённом завершении его ID. Поздние ответы не заменяют новое меню и не отключают его команды навсегда. Open in Browser — обычная ссылка source_url в новой вкладке с noopener/noreferrer; Copy Link пишет тот же source_url в clipboard и показывает результат/ошибку. Keyboard: стрелки/Home/End, Escape/Tab, возврат фокуса; внешний клик, прокрутка и resize закрывают меню.
