## Spec

Первоначально выявлены два P2:

1. Повтор GUID с другим URL мог заменить сохранённый анонс исходного задания. Исправлено: актуальная запись выбирается по тому же URL; иначе используется локальный анонс. Воспроизводящий API-тест сначала падал, после исправления прошёл.
2. Любая ошибка выбирала «Завершено с ошибками», хотя другие источники ещё работали. Исправлено: при pending/running показывается продолжающийся сбор с ошибками или ожидание повтора. Проверка сначала воспроизвела ложное завершение, затем прошла.

Повторное Spec-ревью подтвердило закрытие обоих P2 и прохождение двух относящихся к ним API-сценариев. Остаточных замечаний по этим исправлениям нет.
