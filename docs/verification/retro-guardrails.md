2026-10-14. Запрос: внедрить короткий набор поздних ответов, защиту checkout от тестовых записей и быстрый выбор браузерных сценариев. Скилл to-spec не менялся.

## Реализовано

- `check lifecycle`: синтаксис, lint, пять существующих браузерных регрессий, diff. Сценарии выделены без потери имён и проверок; по-прежнему входят в полный UI/CI. Проверяют позднее сохранение, более новый черновик, фокус после рендера, видимость Telegram-формы, прерванный каталог и повторное открытие подключения.
- `check browser --match <regex>`: выбор по имени и фиксация фильтра в JSON. Отсутствие прошедшего совпадения даёт FAIL. Выбранные contracts/syntax/lint выполняются раньше браузера независимо от порядка аргументов; ошибка syntax/lint пропускает браузер, остальные результаты сохраняются.
- Обычные UI-действия общих browser contexts ждут 5 секунд, навигация — 10; длительные операции сохраняют явные ожидания. Специальный YouTube HTTP fixture использует те же таймауты. Реальный тест отсутствующей кнопки подтверждает быстрый отказ.
- Перед/после browser и python-tests runner сравнивает Git inventory, режим и SHA-256 содержимого файлов. Исходные dirty/untracked изменения допустимы. Новые, изменённые и удалённые неигнорируемые файлы дают FAIL с путями в `checkout_changes`. Символические ссылки проверяются без чтения целей. Файлы не откатываются автоматически.
- Артефакты: `OKO_TEST_ARTIFACT_DIR` указывает в каталог отчёта; общий browser helper разводит снимки по процессам. При прямом запуске используется системный временный каталог. Собственный отчёт исключён из guard; старые иллюстрации не перезаписываются тестами.

Использование и таблица обязательных порядков для новых редакторов: [инструкция браузерных проверок](../../tests/browser/README.md).

## Ограничения

Guard обнаруживает изменение за время набора, но не устанавливает автора: параллельная правка другого чата также даёт FAIL. Он не требует чистого checkout и ничего не восстанавливает. Автоматические проверки используют только временные данные и синтетические подключения. Скиллы, личные источники и работающий экземпляр Око не менялись.
