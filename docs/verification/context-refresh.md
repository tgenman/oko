## Реализовано

Refresh в меню фида/папки использует реальную серверную очередь: новое от сохранённого указателя, незавершённая загрузка, ошибки фильтрации и тезисов. Актуальные успешные результаты сохраняются. Активные discovery/fetch не перезапускаются. Обновление версий допускается во время ИИ; поздние результаты проходят обычную проверку актуальности.

Ручная пауза удалена из UI, старые сохранённые паузы снимаются при открытии Store. Вынужденные ограничения Telegram/YouTube сохраняются. Терминальная недоступность получает одну попытку на ручное обновление, с сохранением копии и причины неудачи. Признак однократности переживает частичный результат и вынужденное ожидание.

## Граница проверки

HTTP interface читателя, временные SQLite/файлы, синтетические Source, Telegram, HTTP transports и Codex. Playwright + headless Google Chrome. Личные подписки, Telegram-аккаунты и настоящий обработчик не запускались. Пользовательский процесс не перезапускался.
