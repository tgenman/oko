# Обзоры за период и сжатие истории

2026-10-09. Тикет [11](../../.scratch/oko-implementation/issues/11-digests-compression.md). База `d32c260336996df9aeee7ae80edef9a01eaea0d3`, реализация `21df040`, исправления ревью `07b7e80`.

## Поведение

В папке варианта A доступны «Обновить обзор сейчас» и «Сжать историю». Второе по умолчанию выбирает всё непросмотренное; даты ограничивают период включительно. Первое использует наследуемый `digest_days` до текущего времени, если даты не заданы. В настройках фида/папки тоже доступно ручное обновление обзора. Создание фиксирует ID и версии всех исходников, включая скрытые; неполная загрузка требует сначала завершить сбор. Открытие папки и копирование ссылок не запускают AI и не меняют просмотр.

Настройки `digests`, `prompt_digest`, `digest_days`, `schedule`, `processor` наследуются по полям. Расписание — ежедневное HH:MM в локальном времени компьютера либо off; проверяется только при живом читателе. Пропущенные дни объединяются в последний актуальный запуск. Маркер тика и manifest сохраняются в одной транзакции. Наследуемые настройки создают папочный обзор; фиды с отдельными настройками обзора получают собственный и исключаются из расписания папки. Ручное сжатие папки охватывает весь выбранный набор независимо от настройки расписания.

Эффективный `originals` управляет первоначальным раскрытием публикации: тезисы и оригинал можно показывать вместе, либо оставить оригинал под раскрываемым блоком. Удаления или запрета явного доступа эта настройка не означает. Скрытый/очищенный фильтром оригинал автоматически не раскрывается. В обзоре и событии исходники всегда доступны через отдельные раскрываемые блоки.

Повторное сжатие читает оригиналы из manifest, а не прежние сводки. Новые поступления остаются отдельными карточками. Готовая сводка занимает одну карточку; время — максимум публикаций, важность — максимум фидов. Папочный обзор сохраняет выбранную папку при переносе отдельного фида. Старые перекрывающиеся обзоры заменяются после успешного завершения нового; их исходники, не вошедшие в новый набор, остаются доступны отдельно.

## Хранение и обработка

SQLite `digest_sets` содержит только область, владельца, точные ID/версии и подпись. `digests/<id>.md` содержит текущий прогресс и тезисы. Части и промежуточные результаты недоступны как готовый обзор. Запись идёт через общий atomic writer: flush/fsync → replace → fsync каталога → фиксация задания. После остановки продолжается следующая часть; повреждённый/потерянный результат повторяется по исходникам.

Исходники делятся без обрезки текста: фрагменты до 40 000 символов, до десяти источников и 60 000 символов в части. Скрытая реклама и YouTube без доступных субтитров не передаются в AI, но остаются в составе для удаления. Для нескольких частей выполняется итоговая сводка по общему пользовательскому промпту. Слишком большие промежуточные темы сжимаются ограниченными раундами: до 50 000 символов и ста ID в группе; максимум восемь раундов, далее явная ошибка, исходники остаются доступны. Все этапы ссылаются на исходные ID/URL. Промежуточные темы не создают новых публикаций.

Каждый этап требует обработчик, разрешённый всему manifest. Codex не получает текст до разрешения публичного AI всех фидов; локальная модель проходит прежнюю проверку режима. Смена разрешений/настроек инвалидирует подпись и прежний прогресс; поздний ответ не фиксируется. Неуспех модели оставляет исходники доступными, без fallback.

«Просмотрено» проходит общий сценарий Runtime/Store по всем ID manifest, включая скрытые и неупомянутые моделью. Он отменяет поколения, удаляет контент/медиа/производные/промежуточные данные и оставляет служебные отметки. Генерация не вызывает просмотр и не отправляет Telegram-подтверждения. Реальный адаптер отметок Telegram остаётся задачей 05; проверка состава не зависит от него.

Итог содержит атрибутированное расхождение 24/30 без разрешения противоречия и отдельный тезис о спутнике, ссылки точные.

Из браузера запущено повторное сжатие: диалог периода → проверка обработчика → новая готовая сводка, одна карточка. Проверены раскрытие исходника, исходные ссылки и остановка с очисткой экрана. Отдельный синтетический стенд подтвердил `originals=false`: тезисы видны, оригинал свёрнут и раскрывается явно. [Скриншот](digest-reader.jpg).

После исправления ревью отдельно проверен настоящий `digest_final` на трёх синтетических промежуточных темах. За 6.64 с модель вернула ровно два запрошенных тезиса: атрибутированное противоречие библиотеки плюс детский зал; спутник. Проверка схемы и точных ссылок прошла. Это отдельная проверка реального адаптера; полный многопроходный pipeline проверен через API с подменяемой моделью. Два небольших примера не гарантируют общее качество. Качество дайджестов текущей локальной Qwen здесь не проверялось. Ollama не запускалась.

Все собственные стенды, вкладки и временные каталоги закрыты; личные данные и настройки не менялись.
