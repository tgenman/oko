# Согласование проблем при изменении попытки Job

Проверен коммит `3e0854912b6eabbef56d6ab56eb25fd9e8b05230` на базе `e8dee087f286f0fb6a848f8ba81df304fb2fd64d`
в изолированном checkout с синтетической PostgreSQL 18.

- Целевые проверки проблем, транзакций и типов: 54 Python-сценария прошли;
  проверка типов прошла для 170 файлов.
- Playwright: 8 сценариев панели состояния и проблем прошли.
- Первый полный прогон на исходной ветке завершился с ошибками: 700 Python-тестов
  прошли, 7 упали, 2 пропущены; 150 браузерных сценариев прошли, 3 отменены по
  таймауту.
- Полный прогон на интеграционном коммите с двумя браузерными потоками завершился
  с ошибками: 691 Python-тест прошёл, 16 упали, 2 пропущены; 153 браузерных
  сценария прошли, один отменён по таймауту. Проверки contracts, типов,
  синтаксиса, lint, сборки, HTTP, Node, diff и entrypoint прошли.
- Все 16 упавших Python-сценариев второго полного прогона прошли при отдельном
  последовательном повторе. Успех повтора относится только к этим сценариям.
- На чистом `main` при запуске файлов Telegram и YouTube воспроизвелись пять
  из тех же падений: 23 сценария прошли и 5 упали. Браузерный сценарий первой
  страницы и загрузки следующей страницы повторно завершился по таймауту и на
  интеграционном коммите, и на чистом `main`.
- После завершения параллельных прогонов этот браузерный сценарий прошёл отдельно:
  на чистом `main` с временными диагностическими метками — за 28,6 секунды, на
  интеграционном коммите — за 28,8 секунды. Подготовка синтетической библиотеки
  в первом запуске заняла около 24 секунд. Эти повторы не заменяют полный прогон.

Независимое ревью порядка операций и блокировок проведено после изменений;
оставшихся конкретных замечаний reviewer не выявил. Полный прогон не считается
успешным. Причина таймаутов не установлена; при запусках выполнялись другие
проверки и временная база испытывала нагрузку.
