# Упрощение тестовых заготовок

2026-10-13. Объём: явные настройки сценариев, удаление дублирования серверной логики, сохранение проверяемого поведения и замер. Коммит включает работу этого чата, включая предыдущий этап [ускорения браузера](development-speed.md); посторонние продуктовые изменения остаются вне него.

## Результат

- `reader()` использует общий `productionReader()`: настоящий HTTP-сервер Око, отдельное временное хранилище и новый browser context для каждого сценария. Chromium по-прежнему переиспользуется внутри файла, файлы запускаются в два потока.
- Удалены самодельная выдача файлов и вычисление навигации, фильтрации карточек по фидам, удаления просмотренного и группировки диагностики. В `support.cjs` осталось 62 строки вместо 115; общий HTTP-helper вырос с 48 до 52 строк за счёт повторно используемой и идемпотентной очистки.
- UI-сценарии задают снимки ответов и явные переходы `reply.next`; транспорт лишь возвращает их или задерживает ответ. Он не воспроизводит правила сервера. Правила состава чтения и удаления проверяются существующим сквозным HTTP-сценарием. Журнал диагностики теперь использует настоящий сервер во всех этих UI-сценариях.
- `setup_reader` требует явного `theses`. Настройки событий, фильтров и обзоров отключают несвязанные этапы; обработчик обзоров задаётся до начала сбора. Синтетические модели отклоняют неподдерживаемую операцию. Смешанные сценарии явно разрешают тезисы.
- При работе через настоящий HTTP обнаружено, что строгий `BrowserError` отвергал ISO timestamps браузера. Добавлено только преобразование строк ISO перед строгой проверкой двух полей. HTTP-регрессия проверяет первое/последнее время, повторную доставку и отклонение чисел, bool и некорректной строки.

## Сохранение сценариев

В рабочем checkout до изменений прошли 356 Python-случаев и 70 браузерных сценариев. После — 361 и те же 70. Сравнение имён браузерных сценариев и Python test-функций не обнаружило удалений. Добавлены четыре случая запрета неподдерживаемой операции модели и одна HTTP-регрессия времён диагностики. Прежние продуктовые assertions сохранены; независимое ревью это подтвердило. Это проверка сохранения сценариев, не измерение процента покрытия строк.

- Новая HTTP-регрессия до исправления: 422 вместо 200 (`/tmp/oko-fixtures-date-red.log`). После: целевые Python-проверки, типизация и 16 браузерных сценариев прошли (`/tmp/oko-fixtures-fixes/20261013T174837Z-9c084835/report.json`).
- Первый полный прогон после рефакторинга: Python прошёл, lint и два браузерных теста упали из-за передачи несуществующего `t` в сценариях. Сохранён прежний `reader()` interface; cleanup теперь доступен отдельно и вызывается также при ошибке запуска. Затем полный `all` прошёл с результатами выше.
- Независимое ревью изменения: замечаний нет. При дополнительном ревью подготовленного коммита найдены пропущенные разрешения тезисов в смешанных сценариях; четыре места исправлены, повторное ревью закрыло замечание.
