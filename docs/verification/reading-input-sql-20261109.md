# Проверка упрощения чтения публикаций

Продолжение [проверки истории](reading-sql-20261109.md), база сравнения —
`0a26a18c`. Все источники и данные синтетические, PostgreSQL временная.

Полный путь чтения больше не запрашивает владельцев второй раз: он собирает
их из уже загруженных публикаций и прямых связей. Неиспользуемое чтение
принадлежностей удалено. Карточки готовят только публикации, задания,
медиа и прямые связи; настройки обработки и задания связанных публикаций
остаются в полном пути. Проверка public AI по всем прямым владельцам и порядок
связей не изменены.

Убраны неиспользуемые внутренние методы и всегда пустое внутреннее состояние
просмотренных ID; обязательное поле `viewed_ids: []` в HTTP сохранено. Период
опроса не менялся: он влияет на свежесть данных, а допустимое изменение
свежести не согласовано. Навигация и публикация сериализуются один раз; ETag
хеширует фактические байты. Старый ETag остаётся прежним, когда прежний
канонический JSON совпадает с ответом; иначе клиент один раз получит `200`.

Для библиотеки из 104 готовых публикаций в четырёх фидах request-scoped trace
показал:

| Запрос | Исходная версия | После |
| --- | ---: | ---: |
| `/cards`, 200, 1/40/100 карточек | 13 | 9 |
| `/cards`, 304 | 5 | 5 |
| `/publication`, 200 и 304 | 14 | 9 |

Количество включает BEGIN/COMMIT и не является полным подсчётом серверных
обращений или измерением задержки. Для отметки прочитанного сохранён ранее
зафиксированный рост с 53 до 54 событий без истории и до 57 с историей.

Проверено:

- Итоговый совместный прогон карточек, владельцев, ETag, обработки, связанных
  публикаций, просмотренных материалов и базового чтения фидов: **69 passed**.
- Новые HTTP и storage тесты карточек и владельцев: **7 passed**, включая
  `show_read`, скрытые материалы, просмотренных и удалённых владельцев,
  media preview, 402 связанные публикации и переход границы в 400 ID.
- Совместный набор HTTP/ETag и сохранения просмотренных публикаций: **39 passed**;
  обработка и связанные публикации — **22 passed** и ещё **4** целевых теста.
  Два первых варианта нового ETag-теста ошибочно ожидали обязательной смены
  хеша; исправленный тест проверяет и совпадение, и различие старого ETag.
- `mypy` — 184 файла, TypeScript typecheck и `npm run api:check` — прошли.
- Playwright с настоящим HTTP: **12 passed**, включая повреждение истории и
  четыре latency-серии; скриншот чтения просмотрен. В повторе p95 первого /
  повторного открытия, мс: 104 idle 149/23, 104 с обработкой 126/96,
  400 idle 171/165, 400 с обработкой 140/141. В каждой серии 40 открытий;
  порог теста — 300 мс. Базовое сравнение и ограничения однократного замера
  приведены в предыдущем отчёте; эти числа не доказывают ускорение.

Полный прогон до этой последней оптимизации завершился с ошибками, а следующий
был остановлен после тайм-аутов; успешные отдельные повторы описаны в
предыдущем отчёте. Полный прогон и CI для итогового изменения не подтверждены.
