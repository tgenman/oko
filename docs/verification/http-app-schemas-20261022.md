# Подготовка HTTP-схем один раз — 2026-10-22

База: локальный проверенный пакет `4849a49`. Задача: уменьшить стоимость создания HTTP-приложения, сохранив поведение ответов и изоляцию читателей. Рабочая установка, данные и настройки Око не изменялись; перезапуск не выполнялся.

## Изменение

`SchemaRoute` подготавливает полный `TypeAdapter` контракта ответа один раз на тип и использует публичные hooks Pydantic. Кэш ограничен 256 типами; RLock предотвращает повторную первую компиляцию при конкурентном создании приложений. Прямые и включённые маршруты используют один механизм. После вытеснения тип может быть подготовлен снова. Схемы принадлежат загруженной версии кода; обновление кода запускает новый процесс.

Валидация выполняется для каждого ответа. Кэш не содержит данные, результаты, ошибки, handlers или Runtime. Простые оболочки FastAPI и параметры запросов продолжают строиться для приложения. Unhashable metadata получает штатную обработку FastAPI. Canonical OpenAPI, generated SDK/DTO и настройки не менялись.

## Замеры

Один процесс, временные хранилища, API-only factory без запуска lifespan, три серии по 25 повторных созданий; исходный и новый код на той же машине:

| Создание | До | После |
|---|---:|---:|
| Первое | 52,8 мс | 32,2 мс |
| Повторное, среднее | 32,1 мс | 16,9 мс |

Повторная сборка ускорилась примерно в 1,9 раза. Это замер factory, а не обещание такого же ускорения полного набора.

Цена публичного serialization hook: для 500 типизированных ReadingCard (351501 байт), 50 итераций validation + dump_json — 2,02 → 2,93 мс на ответ. Байты совпадают. Hook сначала получает JSON-совместимые Python-значения, поэтому добавляет около 0,9 мс на такой большой ответ.
