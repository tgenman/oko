# Telegram: реальная приёмка приватных источников

2026-10-10. База: `3e004fc`. Пользователь разрешил самостоятельно выбрать доступные источники из существующего аккаунта. Использован только собственный клиент Око на Telethon; Telegram MCP не вызывался. Авторизация не копировалась, новый вход не создавался.

## Проверочный набор

Просмотрены метаданные первых 200 диалогов аккаунта: доступны 7 приватных broadcast-каналов и 8 обычных групп. Выбраны один приватный канал без публичного username (тип Channel) и одна обычная группа (тип Chat, не forum/supergroup). Из последних 30 сообщений каждого источника выбраны пять сообщений: изображения, обычное видео и кружочек. Названия источников, сообщения, ссылки и идентификаторы приватных публикаций не включены в этот отчёт или fixtures.

Служебные IDs выбранного набора временно хранились в файле с правами 0600. Временное хранилище SQLite/Markdown и медиа удалено по окончании; служебный файл выбора и диагностические скрипты также удалены. Настоящие тексты и вложения не отправлялись в AI и не выводились в журнал.

## Настоящий путь через API

Подключение каждого источника по числовому peer ID через API Око успешно. Автопрочитывание выключено, тезисы/события/обзоры отключены. Диагностический клиент ограничивал discovery выбранными реальными сообщениями; messages, расширение альбомов и download выполнялись настоящим worker Око. Публикации, даты и медиа не подменялись. Такой ограничитель не доказывает полноту импорта всей истории; пагинация и восстановление курсоров отдельно покрыты управляемыми API-тестами.

Получены пять полностью сохранённых карточек. Реальные вложения: пять изображений размером 101088, 23384, 124311, 132480 и 139060 байт; видео 13825172 байт; кружочек 7369610 байт. Дополнительные изображения появились при расширении состава альбомов. Каждое вложение получено через локальный API с HTTP 200 и непустым содержимым.

После завершения первого экземпляра Око новый экземпляр на том же временном хранилище вернул прежние оригинальные тексты и все вложения. «Просмотрено» для каждой карточки вернуло 200; материал и все вложения затем вернули 404. Карточек и контентных файлов не осталось. Это локальное удаление, без серверных отметок прочтения.

Публичный канал ранее проверен отдельно с настоящим текстом/JPEG, включая исправление потери кеша StringSession: [публичное чтение и восстановление](telegram-public-recovery.md). Здесь подтверждены оставшиеся реальные приватный канал, обычная группа, видео и кружочек. Обрыв загрузки, поздние результаты, ошибки, альбомы и миграции проверены через API с управляемой внешней системой; в настоящем аккаунте сбой сети намеренно не создавался.

## Граница результата

№04 принят. Повторная браузерная проверка на приватном содержимом не проводилась: прежняя проверка формы подключения и локальных медиа использовала синтетические данные. Настоящая интеграция подтверждена на согласованной API-границе с временным настоящим хранилищем. Семантика forum topics остаётся явно неподдерживаемой.

№05 теперь разблокирован. Серверные read acknowledgements этой приёмкой не проверены и не отправлялись; она не доказывает реализацию синхронизации прочитанного.
