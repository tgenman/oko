# Проверка независимых медиа (#92)

## Проверенное поведение

На синтетической перенесённой SQLite текст поста и Telegraph доступен по HTTP,
пока файл ждёт, падает или повторяется. Проверены частичный набор, порядок медиа,
сохранение ID при смене подписи, новый ID и недоступность прежнего URL при замене,
пустой файл, исходное имя, отмена и поздний ответ, manual retry и scoped source_wait.
Паузы переживают рестарт; другой хост продолжает работу. failed не крутится,
unavailable перепроверяется явным обновлением. Очистка сохраняет активный поток
и final-файл между move и commit. Настоящий процесс завершался в трёх точках:
после move, до commit, после commit; незакоммиченные байты не выдаются.

Playwright проверил сохранение/сброс задержек, поздний ответ настроек и цепочку
pending → error → Retry Download → ready с сохранением видимого текста.
