# Копии библиотек и матрицы валидации — 2026-10-22

База: `7865118` (то же дерево кода слито в main как `55705e1`). Рабочие настройки, данные и установленный выпуск Око не изменялись; перезапуск не выполнялся. Меняется только тестовая инфраструктура и проверки.

## Изменения

Библиотеки бюджетов чтения строятся настоящим Store один раз на форму данных в процессе. Закрытая SQLite с journal_mode=DELETE и материалы хранятся во временном каталоге процесса. Каждый сценарий получает обычную файловую копию без hardlinks, собственные Store/Runtime/client и глубокую копию metadata. Ошибка builder удаляет неполный источник и не публикует его. Образы не сохраняются между прогонами и не содержат результаты тестов. Проверки наполнения и восстановления Store продолжают строить данные сами.

Browser performance использует те же шаблоны через уже существующий Python fixture host. Первое создание по-прежнему оплачивается прогоном. Idle и active получают отдельные каталоги; active настраивается после копирования в своём хранилище. Все четыре сценария, 104/400 материалов, 320 настоящих кликов, фоновая обработка, HTTP и бюджет p95 <200 мс сохранены.

Матрицы 6 ошибок examples и 3 некорректных references используют настоящий `scripts.api.contract` в процессе pytest. Реальные CLI-проверки сохранены для canonical validation, успешного bundle, отказа validate/bundle с ненулевым кодом без stdout и частичной записи, ошибки внешнего reference, SDK generate/check и Git index.
