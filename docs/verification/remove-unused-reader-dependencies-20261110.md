# Проверка удаления неиспользуемых зависимостей читателя

Из интерфейсов списка и дерева удалён неиспользуемый `readerApi`; из отображения проблем — неиспользуемый индекс. Поведение и отображение не менялись.

- `tsc --noEmit --noUnusedLocals --noUnusedParameters`: успешно; до изменения сообщал об этих трёх параметрах.
- `./scripts/check ui --compact`: PASS, HTTP 5 passed, Node 38 passed, Playwright 189 passed. Использовалась синтетическая PostgreSQL.
- Независимое статическое ревью подтвердило отсутствие использования удалённых параметров и сохранение React keys. Отдельная визуальная галерея не запускалась: визуальное представление не менялось.
