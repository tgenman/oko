# React: состояние и диагностика

14 октября 2026. Тикеты 06–07 [спецификации](../../.scratch/react-typescript-vite/spec.md). Исходная база `830f7fb`, отдельный checkout `codex/oko-react-status`.

Панель состояния и журнал теперь отображаются JSX-компонентами в общем React root. Карточки имеют стабильные ключи, раскрытие хранится в React, порядок и удержание завершённой раскрытой карточки — в явном состоянии владельца. Сохранены мобильный dialog/inert, возврат фокуса, переход к настройкам и материалам. Локальные исходы команд, очередь диагностики и сверка receipts не зависят от открытости журнала. Диагностика и receipts используют операции generated SDK и canonical DTO; значения черновиков не сохраняются владельцем исходов.

Заменённые DOM renderers состояния, индикатора, журнала и локальных исходов удалены. `debug.js` временно реэкспортирует единственный reporter для ещё мигрирующих владельцев; реализации в нём нет. Удаление этого переходного импорта относится к общей интеграции.
