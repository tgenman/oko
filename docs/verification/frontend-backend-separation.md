# Проверка разделения фронтенда и бэкенда

2026-10-13. Спецификация: [явное разделение](../../.scratch/frontend-backend-separation/spec.md). База ревью: `6783dc9367591c7ab66e03ca7e62111662a160ae`; ветка `codex/frontend-backend-separation`.

## Выполненная реализация

Фронтенд находится отдельно от Python-кода, выдаётся общей implementation статики на прежнем origin и использует общий транспорт. Основные HTTP-ответы имеют серверные wire-контракты; браузерные снимки проверяются схемами из того же описания. Сборка установочного пакета доставляет фронтенд вместе с бэкендом.

До правок сохранён снимок checkout. Предыдущие спецификация и шесть тикетов относятся к этой задаче; посторонний прототип настроек исключён из изменений задачи. Пользователь разрешил реализацию через implement-spec, включая локальные коммиты. Личный экземпляр не перезапускался.

## Ограничения

Проверки используют временные SQLite/файлы, настоящий браузер и синтетические внешние adapters. Личные источники, Telegram-аккаунт, настоящие модели и развёртывание пользовательского экземпляра в приёмку не входят. Старые отчёты не переписаны результатами этой версии.
