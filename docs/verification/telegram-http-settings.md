## Изменение

В Настройках Око доступно `Telegram Request Limit`: конечное число от 0,1 до 10
запросов/с, default 2. Одно значение задаёт общий HTML-бюджет и отдельный бюджет
каждого сервера медиа. Оно сохраняется, Reset возвращает 2; способ доступа через
аккаунт сохраняет прежние правила MTProto/FloodWait. У папки и фида переопределений нет.

Изменение применяется при последующих допусках по времени последнего запроса,
без перезапуска и отмены активной работы. Deadline 429 не изменяется ни сохранением,
ни сбросом настройки. Принятые ИИ-результаты не инвалидируются.

API: GET `/api/v3/settings/telegram-http`, поле `telegram_http_rps` существующего
PATCH `/api/v3/settings/oko/global`. Закрытые ответы общих настроек не меняются;
пустой command keys использует прежнюю совместимую форму. OpenAPI и generated
Python/TypeScript обновлены штатной генерацией.

Редактор использует существующие Save/Reset/Discard Change. Поздний ответ сохраняет
новый черновик по значению и ревизии, включая возврат к прежнему числу (4 → 5 → 4).
Отказ записи сохраняет ввод, а Discard Change снимает соответствующую проблему команды.
