# Очистка открытого материала после просмотра диапазона — 2026-10-27

Проверка в текущем checkout с временной PostgreSQL и синтетическими источниками.

- До исправления Playwright воспроизвёл описанный случай: карточка исчезла, а текст открытого материала остался.
- `npm run build` — успешно.
- `./scripts/check browser --files tests/browser/test_news_context_menu.ts` — 9 сценариев успешно, включая выбранную карточку в диапазоне, карточку вне диапазона и поздний ответ после выбора другого материала. Типизация браузерных и tooling-тестов прошла.
- После добавления снимка `./scripts/check browser --files tests/browser/test_news_context_menu.ts --match '^mark above clears the opened material'` — один сценарий успешно; снимок просмотрен: область чтения показывает `Select an item`.
- Предыдущий полный прогон этого файла завершился с 8 успешными и одним упавшим сценарием: утверждение ошибочно искало пустое сообщение внутри скрытого `#material`; проверка исправлена на видимый `#empty`. До этого повтор без сборки завершился ошибкой устаревшей сборки; после сборки сценарии перезапущены.

Полный набор проекта не запускался. Работающий экземпляр Око и личные источники не использовались.
