# Завершение разбора папки

## Поведение

«Всё просмотрено» открывает подтверждение с количеством карточек, включая скрытые, и уникальных исходных публикаций всей папки. Предварительный просмотр не удаляет содержимое. Сводки и события разворачиваются в полный набор исходников, независимо от того, какие источники упомянуты в тезисах. Замороженная папка обзора сохраняется при переносе фида; её исходники не попадают в завершение другой папки.

HTTP: `POST /api/folders/{folder}/completion/preview` возвращает `token`, `cards`, `originals`; `POST /api/folders/{folder}/completion` принимает `token`. Токен непрозрачный, привязан к папке и содержит в памяти только служебные ID, набор членов Telegram-альбома и ID карточек. Сохраняются последние 128 подтверждений текущего запуска. После перезапуска или вытеснения старого токена требуется новый подсчёт. Изменившийся набор или состав карточек возвращает HTTP 409 с обновлённым предварительным просмотром; нужен ещё один явный клик. Повтор уже принятого токена не удаляет новые поступления.

Общий `Store.viewed_set` атомарно фиксирует отметки исходников и задания удаления, отменяет поколения обработки и инвалидирует производные материалы. Runtime отменяет принадлежащую ему работу и выполняет очередь удаления. Физическая ошибка даёт HTTP 503 и видимый статус «Ошибка удаления»; отложенное удаление восстанавливается до дальнейшего сбора. Контент и смысловой архив подтверждений не сохраняются. Существующий путь «Просмотрено» использует тот же контракт наборов.

Telegram-отметки прочитанного пока не отправляются: задача 05 остаётся зависимой от отдельной интеграционной проверки Telegram. Новый путь не создаёт видимость такой проверки и не запускает пользовательскую сессию.

## Проверки

API с временными SQLite/файлами и заменёнными внешними источниками/AI проверяет весь набор, повтор подтверждения, новые поступления, изоляцию папок, чужой/устаревший токен, удалённого участника, скрытое, сводки, события, перенос фида, ошибки диска и поздние ответы загрузки/AI. Реальные процессы проверяют смерть после фиксации всего набора и после физического удаления файлов одного участника до завершения его задания; после запуска ничего не возвращается.

Браузерная проверка выполнена на собственном временном сервере с синтетическими материалами в двух вкладках. Подтверждение показало 3 карточки / 3 исходника; после подтверждения счётчик выбранной папки стал 0, открытый материал во второй вкладке исчез, другая папка сохранила 1 карточку. Снимок: [результат](folder-completion.jpg).

Проверка реального аккаунта Telegram и реальные вызовы модели в этой задаче не выполнялись. Ollama не запускалась.
