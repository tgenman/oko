### Причина и исправление теста

Проверка ждала блокировку тезисов одного материала, затем сравнивала сумму попыток
всех трёх материалов DemoSource. Изолированный probe воспроизвёл гонку 1 раз из 4:
до сдвига времени попытки `[1,0,1]`, после — `[1,1,1]`. Третий материал выполнил
первую попытку; повторов уже заблокированных материалов не было. Это не изменение
серверного поведения вследствие переноса браузерного кода.

Тест теперь через существующий HTTP interface ждёт блокировку каждого из трёх
материалов до замера общей суммы. Проверки отсутствия повторов после +1000
тестовых секунд, вызовов модели, ошибок диагностики и возобновления при разрешении
сохранены. Проверка отсутствия retry_at расширена на все материалы. Ни один тест
не отключён; таймауты не увеличены; production Python не менялся.
