# Рабочий запуск Docker на Mac

2026-10-19. Пользователь явно разрешил проверку обновлённого Codex, перенос личных
данных и запуск рабочего Око. Затем отдельно подтвердил точный SHA-256 нового CLI
и его использование под существующим sandbox.

## Допуск Codex

Версия `0.163.0-alpha.10.2`, SHA-256
`1afb28c01d7d49e892bd75f11076b10f1451e34e0ee308a95e5ab7f69f9c84fe`.
Предыдущий допуск заменён; неизвестные хеши по-прежнему отклоняются.
OS-профиль, запрет инструментов, правила ephemeral, проверка файлов и очистка не менялись.

Выполнен один настоящий синтетический turn: `gpt-6-luna`, effort `low`, Standard.
Применены производственные флаги и `LocalCodex.complete`; кандидат был допущен
только внутри проверочного процесса до завершения gate. Результат —
`{"verdict":"blocked"}`, есть `turn.completed`, tool-call событий нет.
Проверены отсутствие canary в ответе и runtime-файлах, отсутствие синтетического
исходника в runtime-файлах, отсутствие внешнего файла, пустые `logs`, `queued_items`
и `queued_thread_revisions`; неизвестных файлов производственный adapter не обнаружил.
Каталог задания удалён. Хеш бинарника после запроса не изменился.

Отдельные OS-контроли: внутренняя запись разрешена; внешняя запись запрещена
(exit 1); чтение canary через shell builtin запрещено (exit 1); запуск `/usr/bin/id`
запрещён (exit 126). Разрешение контрольного bash не входит в профиль Codex.
После явного подтверждения пользователя хеш закреплён в исходном коде.
Результат проверки: `/tmp/oko-native-approval/result.json`.

Предыдущая проверка без inference сохранена отдельно:
[codex-0.163-preflight](codex-0.163-preflight.md). Она историческая;
запрет на использование нового SHA, описанный в ней, снят только этой проверкой
и явным подтверждением пользователя.

## Исходные данные и план переключения

Данные до остановки: 85 записей материалов, пять фидов Telegram с веб-доступом,
четыре папки, ноль настроенных Telegram-профилей. Подключения через личный аккаунт
не используются; Telegram credentials не требуются текущим фидам и не переносятся.
Настройки Codex сохраняются: фильтрация `gpt-6-luna/low/Standard`, тезисы
`gpt-6.1-sol/low/Standard`. Заголовки и тексты личных материалов в отчёт не включены.

Перенос выполняется копированием остановленного хранилища в
`~/Library/Application Support/Oko/data`; исходный `data/` остаётся для возврата.
Копия сначала запускается с выключенным сбором; фактические результаты запуска
и сверки данных добавляются после переключения.
