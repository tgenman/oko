## Границы проверки

Обновление Docker Desktop или Mac, полное выключение/включение компьютера и будущая
смена release в этой проверке не выполнялись. Автовосстановление настроено существующими
LaunchAgent и Docker restart policy; проверен текущий загруженный сеанс.
Внешняя копия Mach-O CLI не устанавливалась: после автоматического обновления приложения
новый неизвестный хеш снова закроет обработку до проверки.
Исходные data/ и сторонние изменения разработки сохранены.
