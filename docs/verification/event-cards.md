# Карточки событий — проверка

2026-10-09. Тикет 10. Граница проверки: HTTP API с настоящими временными SQLite/файлами, подменяемыми источниками и AI; отдельно настоящий Codex и браузер варианта A.

## Поведение и ограничения

Объединение включено по умолчанию для Око. `events` и `event_hours` настраиваются для Око/папки; окно по умолчанию 24 часа. Поля для фида отклоняются с HTTP 400. Обработчик события берётся из настроек папки. Разрешение публичного AI проверяется для каждого входящего фида; запрещённый исходник не удаляется из запроса ради облачного вызова. Свою локальную модель допускает прежняя проверка llama.cpp.

Наборы кандидатов содержат полностью загруженные, ещё не просмотренные, не скрытые публикации с завершённой либо выключенной фильтрацией. Внутри папки соседние публикации с промежутком до окна образуют набор для классификации. Это позволяет объединять близкие сообщения даже через границу суток. Каждая итоговая группа дополнительно проверяется: разница самой ранней и поздней публикации не превышает окно. Цепочка соседей сама по себе не разрешает объединить многодневное событие.

YouTube без доступных непустых субтитров не входит в обработку событий: такие видео остаются отдельными карточками, summary по заголовку не создаётся.

AI возвращает полное разбиение набора на группы, включая одиночные публикации. Каждая входная идентичность встречается ровно один раз; отдельный `members` задаёт состав, независимо от ссылок в тезисах. Источники каждого пункта должны входить в его группу; противоречию нужны минимум два источника. Карточка показывает все исходники, даже не упомянутые в сводке. Время карточки — максимум времени, важность — максимум важности фидов; прежние сортировки и стабильный ID при равенстве сохраняются.

Оригиналы, тексты после фильтрации, медиа и производные остаются до явного просмотра. Изменение состава, версий, правил, папки, разрешений или подключения инвалидирует старый результат. Состав события просматривается одной транзакцией; удаление файлов, включая производный файл набора, выполняется восстанавливаемыми заданиями. Пересекающиеся представления инвалидируются; чужие публикации не помечаются просмотренными. После удаления нет описаний событий или смысловых отпечатков. Тот же ID/URL в фиде подавляется существующими служебными отметками; новый пересказ с новой идентичностью разрешён.

При ошибке AI оригиналы остаются отдельными карточками, причина видна в состоянии Око, повтор — через 30 секунд. Нет скрытого переключения обработчика или усечения текста. Один набор ограничен 100 публикациями и прежним лимитом входа 150 тысяч символов: превышение даёт явную ошибку с предложением уменьшить окно/разделить папку. Для очень плотной папки пока нет многоступенчатого объединения больших наборов.

## Автоматические проверки

`tests/test_events.py`: 14 проверок API, включая точный состав, обновления/конфликты, разделение папок, смешанные разрешения, важность и сортировки, окно и границу суток, новые публикации, отсутствие смысловой истории, отказ неизвестных ссылок/пропущенных и дублирующихся членов, устойчивый к отмене поздний ответ, медиа, ошибку удаления и восстановление соседнего события; три состояния отсутствия субтитров YouTube.

Реальный дочерний процесс завершается через `os._exit(79)` после атомарного перемещения события и после транзакции просмотра. При перезапуске незавершённый результат не показан; удаление состава и производного файла продолжается до сбора. Тестовый AI здесь — временный loopback HTTP-сервер, это проверка восстановления, не качества модели.

Изолированные проверки тезисов, RSS и удаления теперь явно выключают события в своих API-фикстурах. Первоначальный общий прогон выявил шесть ожиданий старых фикстур о первом AI-запросе/отсутствии ошибок других функций; их область проверки уточнена, без изменения продуктового значения по умолчанию. Повтор затронутых файлов прошёл: 60 тестов.

Финальный общий прогон и независимое ревью будут зафиксированы после завершения.

## Настоящий Codex

Существующий CLI `0.136.0`, вход ChatGPT, проверенные лимиты (28% использовано перед запуском), прежняя изоляция и передача текста через stdin. Временный синтетический фид отдельно разрешил публичный AI. Настройки и содержимое рабочего Око не использовались и не менялись.

Четыре публикации `https://example.org/oko/events/0` … `/3`:

1. Городской портал: в Казани 15 января открылась библиотека «Рассвет» на 24 места.
2. Мэрия Казани: то же открытие, 30 мест; дополнительно детский зал.
3. Спутник «Луч-2» вышел на орбиту.
4. Библиотека «Рассвет» открылась в Омске на 12 мест.

Настоящий ответ объединил только 0 и 1. Сводка: открытие библиотеки в Казани. Обновление: детский зал, ссылка на мэрию. Противоречие: портал сообщает 24 места, мэрия 30, обе точные ссылки. Омск и спутник остались отдельными — три видимые карточки. Генерация заняла 10,44 секунды в этом запуске. Это один небольшой качественный пример, не гарантия качества на всех источниках. Качество событий текущей локальной Qwen в этом тикете отдельно не проверялось; Ollama не запускалась.

## Браузер

Проверен настоящий сохранённый ответ Codex: три карточки/счётчик папки, отдельные блоки сводки, обновления и противоречия, полный список источников, раскрытие текста оригинала, кнопка копирования второго источника с сообщением «Ссылка скопирована». Остановка временного читателя очистила карточки/выбранный материал и отключила управляющие кнопки. Созданная вкладка, сервер и временное хранилище удалены. Локальные медиа используют прежнюю авторизованную загрузку blob; HTML из исходников не исполняется.

Скриншот: [event-reader.jpg](event-reader.jpg). Даты января 2027 года — намеренные даты синтетической фикстуры. При повторном открытии временного результата сборщик не подключён; все задания уже завершены, поэтому «Готово · источники 0/0» ожидаемо.

## Standards

Первое независимое ревью: 0 нарушений документированных правил, 1 possible Duplicated Code — события повторяли атомарную запись/фиксацию производных. Исправлено: `Store.save_derivative` теперь обслуживает фильтры, тезисы и события; проверка актуальности и состава остаётся в `Events.save`.

## Spec

Первое независимое ревью: 1 P2 — событие могло обработать заголовки YouTube без субтитров, обойдя ограничение обычных тезисов. Новая API-проверка сначала воспроизвела передачу входа. Исправлено: только `captions=available` и непустой текст допускаются в кандидаты YouTube; состояния `not_requested`, `unavailable`, `error` проверяются отдельно. Новая работа по YouTube не запускалась, реальные подключения остаются отложены пользователем.
