## Результат

- Общий дефолт тезисов выключен. YouTube получает включённые тезисы как свой дефолт; новые YouTube-фиды разрешают публичный AI. Явные настройки Око, папки и фида сохраняют приоритет. Ранее сохранённый запрет публичного AI не переписывается.
- Запрет публичного AI останавливает передачу исходника модели, но не создаёт ошибку диагностики или текущую проблему. Задание ожидает изменения настроек без таймера повтора; смена разрешения/обработчика пересогласует его подпись и возобновляет работу. Старые сохранённые задания с таким запретом тоже не выбираются повторно. Исторический журнал не удаляется.
- Обновление состояния той же карточки не очищает открытый материал. Порядок ответов проверяется по текущей сессии и номеру загрузки; переход на другую карточку по-прежнему очищает прежнюю сразу. Медиа сохраняют object URLs при неизменной версии и составе вложений. Положение чтения, раскрытые разделы и проигрывание не сбрасываются только из-за изменения состояния обработки.
- Аватар Telegram загружается собственным worker как маленькое фото, кешируется по photo ID и обновляется при изменении фото, включая numeric/private peers. Веб-источник понимает вложенное изображение реальной разметки Telegram. Картинка до 128 КиБ сохраняется локально; API выдаёт её с прежними bearer/Host/Origin проверками. Браузер показывает круглый аватар 24×24 и использует обычную иконку при отсутствии/недоступности фото. Удалённое фото и удалённый фид не продолжают выдавать старый аватар.
- OpenAPI содержит дополнительную binary-операцию `feed_avatar` и optional `avatar_url` для Telegram-фидов. DTO/SDK/metadata сгенерированы из контракта; всего 51 операция v3.
