## Поведение

В заголовке дерева добавлена кнопка «Показать прочитанные» / «Скрыть прочитанные» со счётчиком фидов без непросмотренных публикаций. По умолчанию они скрыты; показанные завершённые фиды приглушены и отмечены «Всё просмотрено». Пустые папки скрываются вместе с ними. Выбранный фид или папка остаётся до смены выбора, включая просмотр последнего материала; перемещение и удаление сохраняют прежнее согласование выбора.

В `NavigationFeed` добавлен обязательный `has_unviewed`: существующий проход по `items.viewed=0` учитывает скрытые, незагруженные и недоступные публикации до фильтра видимых счётчиков. Поэтому фид с нулевым видимым счётчиком и скрытыми материалами остаётся показанным. Новая публикация возвращает завершённый фид в дерево. Telegram read state не используется; подписки и сбор не изменяются. API-операций по-прежнему 51; DTO сгенерированы из OpenAPI.

Переключатель меняет только локальное представление, без сброса открытого материала или выбора. Предпочтение хранится в браузере для текущего origin и сохраняется при перезагрузке страницы; перенос предпочтений между разными адресами/портами не добавлен.
