# Проверка общего восстановления профильных проблем

Проход медиа объединён с проходами фильтра и тезисов. Вызовы и их порядок при открытии Store, отдельные маркеры и точки отказа сохранены. Выборка заданий медиа исключает субтитры и включает задания без записи медиа; поиск старых записей включает субтитры.

- Два новых сценария на исходной реализации прошли: несколько страниц обычных медиа, orphan и субтитры; прерывание обеих стадий и перезапуск.
- После объединения `./scripts/check python --files tests/reader/test_media_problem_lifecycle.py tests/reader/test_processing_problem_lifecycle.py tests/reader/test_subtitle_problem_lifecycle.py tests/reader/test_postgres_migrations.py --compact`: 188 passed, 0 skipped. Дополненный сценарий отдельно подтвердил сохранение старой записи субтитров и последующие обычный и профильный проходы субтитров, а также неизменность записей и указателей после них.
- `./scripts/check types lint`: после исправления несовместимых типов локальных функций прошёл; первоначальный запуск types завершился ошибкой, lint прошёл.
- Независимое статическое ревью сопоставило SQL, курсоры, обработку субтитров и orphan, маркеры, точки отказа и порядок вызовов. Использовалась синтетическая PostgreSQL.
