Дата: 2026-10-24. База: `0558222d6cce42e3597dddb29aab9f5b5ff55c9e`.

## Объём и граница

Постоянный читатель закрыт паролем. Логины имеют одинаковые права и общее
хранилище; фиды, настройки и «Просмотрено» не разделяются. Поддержаны
административное создание/смена/отключение доступа, отзыв и истечение сессий,
ограничение попыток, защита API/медиа/документации и запоздалых ответов.

По уточнению пользователя рабочая установка остаётся локальной. HTTPS-origin
и инструкция Caddy подготовлены; реальный домен, DNS, сертификат публичного
адреса и его достижимость из интернета в этом выпуске не настраиваются.

## Полные прогоны

Первый `./scripts/check all --compact` над подготовленным деревом
`8568400ec4a95329076839f39b6c4205cbbe9124` завершился FAIL только в
`test_full_python_collection_excludes_tools_and_already_selected_http_modules`:
новый инструментальный тест требовал регистрации в TOOL_TESTS. Python 910,
Node 113 и Playwright 224 passed / 2 skipped; tools 212 passed / 1 failed.
После регистрации целевая регрессия runner прошла. Первые локальные попытки
процессных/браузерных запусков внутри sandbox не могли открыть порт/выполнить
ps; реальные проверки затем выполнены с разрешённым локальным доступом.

Второй `./scripts/check all --compact` над деревом
`599eb1e40a01ff6bdc8abba0cc1385c129952fba`: Python 909, tools 214 и Node 113
passed. Браузерная группа: 219 passed / 2 skipped / 1 failed; performance-группа
после этого отказа не запускалась. Сценарий выхода поймал редкую ошибку
`Missing reader surface material-list`: DOM уже очищен, а ResizeObserver и
обработчик resize списка ещё подключены.

Минимальная регрессия `logout disposes layout observers before clearing the reader`
через MutationObserver и resize воспроизводила тот же стек за 1.7 секунды.
Исправление: после остановки владельцев, до удаления DOM, React-root явно
размонтируется; cleanup отключает observers, поздние render/mount запрещены.
Минимальная регрессия и все пять целевых Playwright-сценариев — PASS;
повторное независимое ревью teardown — без замечаний. Две диагностические
попытки с удержанием навигации не годились как быстрый feedback loop
(timeout/interrupted); заменены минимальным тестом без задержанной навигации.

После этой правки повторяется полный UI-набор, Python/tools не менялись.
Final UI: `./scripts/check ui --compact` PASS: HTTP 9, Node 113, Playwright 225 passed / 2 skipped; build, tooling/browser types, syntax, lint and diff PASS. Total 125.95 seconds. Code tree: `4dd31211ec08469dfe2153eee64f398ba3e44e95`.

Проверка точных bytes подготовленного индекса через `check staged` — PASS.
Проверочные копии содержат только выбранные файлы задачи; личные подписки,
