# Ускорение проверок разработки

## Изменения

- Удалён `.githooks/pre-push`, запускавший `check all`. Pre-commit и проверки staged-содержимого сохранены. При действующем `core.hooksPath=.githooks` переустановка hooks не нужна.
- GitHub Actions запускает полный набор для pull request и push в `main`. Push рабочей ветки не дублирует запуск открытого PR; ветка без PR не запускает CI. Полный локальный `./scripts/check all` остаётся доступен.
- Node запускает до двух браузерных тестовых файлов одновременно. Внутри процесса каждого файла Chromium переиспользуется; каждый сценарий получает новый context и собственный HTTP-сервер. Context закрывается после сценария, Chromium — в завершающем hook файла.
- Настоящий HTTP-сценарий чтения использует общий `productionReader`, сохраняя продуктовые assertions и очистку временного хранилища.
- Добавлена проверка изоляции cookies/localStorage, закрытия всех страниц context и работоспособности другого context того же Chromium.

## Обнаруженная гонка в тесте

Первый ускоренный полный `ui` не прошёл: 69 passed, 1 failed, browser 38,03 с. Отчёт: `/tmp/oko-speed-after-20261013/20261013T173637Z-4826750c/report.json`. Это время не включено в успешное сравнение.

`test_youtube_history_http.cjs` после второго клика ждал только `state == done`. Пока POST новой выборки из двух видео ещё выполнялся, этому условию удовлетворяла прежняя завершённая выборка из 60 видео. Затем проверка `viewed == 1` получала 0. Изолированный обычный повтор прошёл, но временный probe с задержкой второго POST на одну секунду воспроизвёл то же падение (`/tmp/oko-speed-race.log`).

Теперь ожидание проверяет одновременно `count == 2` и `state == done`. Итоговые assertions о просмотренном материале, 59 карточках и отсутствии ошибок сохранены. Тот же probe после исправления прошёл (`/tmp/oko-speed-race-fixed.log`), затем прошли оба полных замера выше. Искусственная задержка осталась только во временном диагностическом скрипте; продуктовый код не менялся.

При отделении коммита этого чата новый `test_youtube_history_http.cjs` оставлен в чужой незакоммиченной YouTube-задаче. Точечное исправление в рабочем файле сохранено; условие для переноса вместе с тем тестом:

```javascript
await expect.poll(async () => {
  const history = (await api('settings/feed/' + feed.id)).feed.initial_history;
  return [history.count, history.state];
}).toEqual([2, 'done']);
```
