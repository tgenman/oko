База: `c4a6978` (согласованные документы до реализации). Первый коммит реализации: `86357ef`. Спецификация: `.scratch/oko-implementation/issues/01-first-reader-path.md`, критерии A15 и A24–A31 родительского spec. Выполнено двумя независимыми агентами по skill code-review; последующие задачи не входили в проверку.

## Standards

Первичная проверка: документированных нарушений нет. Возможная Data Clumps / Primitive Obsession: важный набор полей задания передавался как `dict[str, Any]`. Рекомендация — ввести небольшой тип задания для статической проверки отмены и восстановления.

Исправление: frozen dataclass `Job`, используемый Store и Runtime. Строгий mypy проходит.

Повторное ревью: «Замечаний нет. Job явно задаёт контракт задания; предыдущая рекомендация закрыта. Новых документированных нарушений или существенных структурных проблем в изменениях отмены, восстановления и UI не обнаружено».

## Spec

Первичная проверка нашла два пробела:

1. P1: временная ошибка удаления при startup могла перейти в общую ошибку хранилища без повторов. Требование: «Ошибка удаления видна и повторяется» и «Удаления завершаются до возобновления сбора».
2. P2: ожидание отмены источника не имело конечной границы. Требование: «закрытие последней и кнопка остановки прекращают задания и завершают процесс за конечный проверяемый срок».

Исправления: восстановление передаёт просмотренные каталоги долговечной операции удаления; ошибка повторяется и блокирует сбор. Отмена сначала инвалидирует поколение, ждёт максимум 250 мс, поздний результат не публикуется. Собственный цикл событий при выходе завершается с отдельным ожиданием до 250 мс. Регрессии проверяют повтор удаления после рестарта и источник, игнорирующий все отмены, при кнопке остановки и закрытии последней вкладки. Устаревшие UI-запросы инвалидируются при сообщении об удалении.

Повторное ревью: оба замечания закрыты, оставшихся конкретных блокеров в первом тикете не найдено. Выход за согласованный объём не обнаружен.

Итог: Standards — 0 оставшихся замечаний; Spec — 0 оставшихся блокеров. Финальные 15 тестов и проверки типов/JavaScript проходят.
