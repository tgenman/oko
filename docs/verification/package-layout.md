## Результат

Код разделён на пакеты collection, processing, reader, reviews, storage и subscriptions. Источники Telegram/YouTube содержат собственные client/worker modules. Общий контракт обработки отделён от Codex и llama.cpp; SourceError принадлежит общему контракту сбора. Store и алгоритмы обзоров сохраняют прежнюю ответственность и форматы.

Тесты сгруппированы по возможностям; тезисы и обзоры имеют отдельные наборы восстановления. Общие синтетические adapters и процессные помощники находятся в `tests/support`, без импортов других сценарных наборов.
