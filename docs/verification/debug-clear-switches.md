# Переключатели и очистка диагностики

Все checkbox-переключатели Око оформлены как округлый корпус с белым ползунком: выключенное состояние серое, включённое чёрное, по образцу пользователя. Сохраняются native input, подписи, управление клавиатурой, видимый фокус и disabled; анимация отключается при prefers-reduced-motion.

В нижней панели диагностики добавлена кнопка «Очистить историю ошибок». Авторизованный DELETE /api/debug очищает группы и сохраняет пустой журнал на диск. При отказе записи прежние группы остаются доступными. Новые ошибки продолжают регистрироваться.

Браузер завершает ранее отправляемую запись перед DELETE, сохраняет новые локальные ошибки, возникшие во время очистки, и отбрасывает старые ответы журнала и статуса. Ошибка очистки показывается в панели.
