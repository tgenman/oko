# Тезисы llama.cpp — 2026-10-09

Адаптер Ollama заменён на llama.cpp. Общие ProcessingRequest/Theses, хранение theses.md, durable jobs, поколения и запрет поздней публикации сохранены. Настройки подключения отделены ключом `processor:llamacpp`; старое подключение и старый выбор Ollama автоматически не переносятся. Остальные настройки и источники сохраняются. Укажите новый сервер и выберите обработчик явно.

API: GET/PUT `/api/processors/llamacpp`, POST `/api/processors/llamacpp/check`. Конфигурация: endpoint, model, local_execution (по умолчанию false). В UI A — блок «Модель llama.cpp», адрес без `/v1`, точный ID/alias и подтверждение выполнения на этом компьютере без прокси/RPC. Смена адреса/модели в форме снимает подтверждение. Для неподтверждённого подключения действует public_ai. Проверка метаданных перед каждым заданием не передаёт публикацию. Поддержка не является аттестацией произвольного сервера.

Автоматические проверки идут через согласованный API с настоящими временными SQLite/файлами, подменяемыми внешним источником и HTTP llama-server. Это не генерация настоящей моделью. Проверены исходные ID/URL и наследуемый промпт, удаление исходника/тезисов, перезапуск без повторной генерации готового результата, потеря файла, авария после перемещения результата, повтор ошибки, отмена и защита от позднего ответа. Дополнительно проверяются неизвестные метаданные, многомодельный список, отсутствие локального подтверждения, исчезнувшая модель, незавершённый/повреждённый ответ и tool calls.

Red → green: первый новый API вызов возвращал 404 до замены адаптера. Неверный message вызывал общий сбой до проверки формы ответа. Многомодельный список ошибочно считался локальным до ограничения режима одним загруженным сервером.

Реальная проверка **не выполнена**: пользователь сообщил, что модель ещё скачивается. Ollama не запускался. Не установлены движок/веса, чужие процессы не остановлены, личные RSS/Telegram-материалы не отправлялись модели. На доступном по умолчанию 127.0.0.1:8080 сервер не найден; это только наблюдение подключения, не результат приёмки модели.

Браузер: сохранение подключения, проверка режима, выбор обработчика, включение тезисов, атрибуция и раскрытие оригинала в UI A; смена модели снимает локальное подтверждение, stop очищает UI. HTTP модели был подменён. [Скрин тестового результата](llamacpp-reader.png).
