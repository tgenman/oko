# Тезисы по сохранённым субтитрам YouTube

2026-10-13. Запрос: скачанные субтитры больше не проверяются; обновления названия и превью не запускают генерацию тезисов.

## Результат

- Повторное использование полученных субтитров уже было в YouTubeSource и сохранено. При недоступных субтитрах или ошибке успешного результата ещё нет; повторные попытки сохраняются.
- Подпись тезисов YouTube использует hash исходного текста субтитров вместо общей версии материала. Модель получает тот же исходный текст. Фильтр определяет допуск и скрытие; готовый результат сохраняется на время повторной фильтрации.
- Чтение готовых тезисов ищет совпадающую подпись в зарегистрированных версиях материала. Обновление метаданных и перезапуск не требуют повторной генерации. Просмотренное удаляет все версии и результаты.
- Старая подпись совместимого принятого результата переносится без модели, включая восстановление после прерывания между записью файла и SQLite. Старый результат по тексту с удалёнными фильтром фрагментами не переносится: новый вход — исходные субтитры.
- Остальные источники сохраняют прежнюю привязку к общей версии и очищенному тексту. Настройки обработки и разрешения продолжают участвовать в подписи.
