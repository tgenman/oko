# Контекстное меню фида — #33

База: `28225d4d3aa1fcbf42851f93781640395974e335`. Реализация: отдельный worktree `feed-context-menu`, ветка `codex/feed-context-menu`.

Выбран вариант A из [прототипа b803f26](https://github.com/tgenman/oko/tree/b803f26): правый клик, обычный клик сохраняет выбор. Прототип и его альтернативы остаются вне main.

## Реализованное поведение

- `Mark All as Read` — подтверждение количества известных публикаций, включая скрытые/незагруженные, затем завершение только этого фида. Подписка сохраняется. Новые поступления до подтверждения требуют пересчёта и нового подтверждения; повтор принятого токена не захватывает будущие публикации.
- `Settings…` — существующий редактор выбранного для меню фида, без смены области чтения.
- `Move to Folder ›` — боковое подменю существующих папок, галочка текущей папки. Перенос сохраняет фид, материалы и текущий выбор.
- `Delete…` — подтверждённая локальная очистка существующим сценарием. Для веб-доступа удаляется весь фид. Для доступа через аккаунт сохраняются подключённый аккаунт и подписка в Telegram; не вызываются выход из канала, удаление сообщений или отметка прочитанного.

Клавиатура: ContextMenu / Shift+F10, стрелки по пунктам, ArrowRight/ArrowLeft для подменю, Escape и возврат фокуса. Клик вне меню, прокрутка и остановка закрывают меню. Подменю при необходимости открывается слева. Названия действий английские; названия папок пользовательские.

Сервер: два новых маршрута `/api/v3/feeds/{feed}/completion[/preview]`, `complete_feed` в command receipts. Всего 53 операции v3. Runtime использует существующие viewed_set, очистку и безопасную Telegram read frontier; токен привязан к паре scope/identity, поэтому токен папки не применяется к одноимённому фиду. Новых настроек, миграций, внешних клиентов и пользовательских параметров нет.

Поздние ответы применяют завершённую серверную запись, но не закрывают новый диалог. Открытый материал согласуется с актуальными карточками, а не очищается целиком по ID фида; это сохраняет публикацию, поступившую после завершения. То же правило действует для межвкладочного feed-viewed.
