# Проверка восстановления проблем обработки

Два прохода восстановления профильных проблем фильтра и тезисов объединены. Отдельные маркеры, транзакции, страницы и точки отказа сохранены; вид этапа ограничен двумя допустимыми значениями.

- До изменения четыре сценария прерывания прошли на прежних реализациях. После изменения эти же сценарии прошли для обоих этапов и обеих точек сбоя с повторным открытием Store и сохранением неоднозначной записи.
- Два сценария с 101 заданием и 101 старой записью прошли после изменения; каждый подтвердил два пакета обеих стадий, завершение маркера, содержимое исходных записей, значения защитных указателей и результаты всех заданий.
- `./scripts/check types lint`: успешно. Запуск трёх наборов обработки и миграций дал 170 passed, но общий статус `checkout_changed`: во время работы добавлялся тест; итог этого запуска не является успешной проверкой неизменного дерева.
- Независимое статическое ревью сопоставило SQL, `%`, порядок транзакций, маркеры и точки отказа; расхождений не найдено. Использовалась синтетическая PostgreSQL.
