## Результат

1. `scripts/task_changes.py snapshot` использует только Git inventory, включая tracked/untracked и исключая ignored. Symlink сохраняются как ссылки, цели не читаются; переход через symlink-родителя и подмена объектов снимка отклоняются. Manifest фиксирует HEAD, индекс, байты и режимы. Неподдерживаемые состояния индекса, включая intent-to-add, отклоняются явно.
2. `tests/support/app.py` собирает production-приложение с синтетическими Codex, субтитрами и историей. HTTP по умолчанию запрещён, включая localhost. Принадлежащий тесту сервер требует явного `OwnedServerTransport(origin)` с точным адресом; тестовые subprocess получают такой адрес только из своего launcher. Проверки границы настоящего worker/CLI явно подключают adapter с подставным SDK/CLI. Продуктовые defaults не менялись.
3. Общий Codex double типизирован по `CodexClient`. `check contracts` проверяет сигнатуры наследуемых методов, межфайловые родители и aliases до длинного прогона; применение фабрики проверяется, когда она присутствует в проверяемой версии. В staged режиме читаются байты индекса. Режим включён в `python`/`all` и pre-commit; прежние CI/pre-push уже вызывают `all`.
4. CLI строит diff относительно снимка, готовит task-only индекс по выбранным файлам и выполняет явный commit. Рабочие файлы и прежние staged/unstaged изменения сохраняются. Изменения HEAD, индекса, рабочих файлов и preview обнаруживаются до commit; конфликты останавливают подготовку. Восстановление индекса выполняется атомарно под принадлежащим инструменту `index.lock`; чужая конкурентная запись не перезаписывается. Подробный порядок: [инструкция](../agents/task-changes.md).

Реальные источники, модели и пользовательский экземпляр для проверки не запускались. Git commit-команды нового инструмента проверялись только в временных репозиториях; HEAD пользовательского checkout не изменялся. Push, публикация и перезапуск не выполнялись. Сохраняется существующее предупреждение Starlette о deprecated httpx TestClient.
