# Открытый материал: проверка реализации

2026-10-12. Основание: [план](../architecture/opened-material.md), подтверждённый пользователем. База ревью `80e9a7e` подтверждена пользователем.

## Изменение

`oko/web/opened-material.js` владеет выбором карточки, актуальностью асинхронных ответов, раскрытием предыдущих версий и исходников сводки, медиа, DOM и blob URL. Его interface — open / reconcile / clear / viewed / folderCompleted и сведения о выбранной карточке. Callers не получают поколения запросов, список медиа или внутреннее содержимое сессии.

При выборе другой карточки прежний материал сразу очищается, отображается загрузка. AbortController прекращает принадлежащие открытию запросы; проверка актуальности независимо от отмены отбрасывает поздние успехи и ошибки. Просмотр исходника сводки из другой вкладки закрывает затронутый открытый материал; завершение другой папки его сохраняет. Асинхронные действия материала и копирование ссылки также не изменяют сообщение уже другой карточки.

Статический interface читателя выдаёт новый ES module. Формат хранения, Runtime, состав чтения, processing и реальные source adapters не менялись. Словарь включает уточнения предыдущей работы domain-modeling и термин «Открытый материал».

## Проверки

- Первое RED: настоящий headless Chrome показал оставшийся «Текст A» после выбора задержанной карточки B. После изменения этот сценарий проходит.
- Восемь автоматических браузерных сценариев проходят: немедленная очистка и поздняя ошибка открытия; поздний успешный ответ; поздняя версия и медиа; просмотр во время загрузки с остановкой видео и освобождением ресурсов; две вкладки с исходником сводки и другой папкой; остановка; потеря связи; обычное раскрытие исходников и предыдущей версии с изображениями, видео и кружочками.
- Тесты исполняют настоящие HTML/JavaScript Око в отдельном Chrome. Подменён только внешний fetch transport; задержанный adapter намеренно игнорирует AbortSignal. DOM, BroadcastChannel и object URL — настоящие браузерные механизмы. Canvas/MediaRecorder создают синтетический WebM; тест действительно запускает воспроизведение, затем наблюдает paused и отсутствие src после просмотра.
- Первая попытка видеофикстуры не создала воспроизводимых кадров: Chrome отказался играть источник. Исправлена только фикстура (явные кадры canvas); это не считалось ошибкой продукта.
- Сервер браузерных проверок выдаёт статические файлы, материалы живут в памяти тестового транспорта. SQLite/файлы проверяются существующими Python-тестами с настоящими временными хранилищами. Добавлена проверка выдачи нового скрипта через настоящий interface приложения.
- mypy: 33 файла, ошибок нет. JavaScript syntax и git diff check прошли. Отдельный reader test: 1 passed.
- Первый полный Python-прогон: 197 passed / 1 failed. Существующий тест восстановления скрытого исходника начинал обзор после готовности первой скрытой публикации, не дождавшись остальных; ошибка повторилась при отдельном запуске. Ожидание полного состава добавлено через interface читателя, 3 теста координации проходят. Повтор полного набора и итоговое ревью будут записаны после завершения.

Повторить браузерные проверки: [инструкция](../../tests/browser/README.md). На этом компьютере использованы bundled Node/Playwright и отдельный headless Google Chrome; все собственные серверы и браузерные процессы закрываются runner после теста.

## Границы доказательств

Личные аккаунты, настоящие RSS/Telegram/YouTube, llama.cpp и Codex AI в этой работе не запускались. Проверено управление показом и ресурсами браузера; повторная реальная приёмка источников и всей V1 не заявляется. Новые проверки не подменяют backend-проверки физического удаления файлов.
