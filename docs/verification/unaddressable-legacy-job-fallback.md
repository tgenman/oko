# Временный статус заданий без цели

Старая схема допускала `NULL` и пустую строку в `jobs.item`. Для legacy Job
загрузки, обработки, медиа, пользовательского удаления или чтения с ошибкой без кода без адресуемой цели статус показывает общую
карточку без материала и действий. Исходная Job сохраняется. Время возникновения ошибки неизвестно и выдаётся как `created_at: null`,
не как дата постановки Job. Карточка вычисляется при чтении и не создаёт отдельную запись в истории. Её ID основан
на ID Job; при совпадении с ID другой видимой карточки выбирается свободный
суффикс, поэтому при изменении состава коллидирующих карточек ID может
измениться.

Старая карточка ошибки источника без подтверждённого владельца сохраняется
без изменений и после исчезновения Job. Это осторожное поведение: такая
карточка может оставаться видимой до явного восстановления её владельца.
Полная передача владения от GET событиям остаётся отдельной работой. Эта обработка не является
подтверждением read-only поведения всего status GET.
