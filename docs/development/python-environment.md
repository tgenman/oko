# Python-окружение

Око использует Python `>=3.11,<3.15` и uv 0.11.28. Верхняя граница соответствует закреплённому `youtube-transcript-api==1.2.4`. Версии runtime- и dev-библиотек задаёт `pyproject.toml`; прямые и транзитивные зависимости разработки и CI фиксирует единственный `uv.lock`.

## Новый checkout

Установите uv отдельно от окружения приложения по [официальной инструкции](https://docs.astral.sh/uv/getting-started/installation/), выбрав версию 0.11.28. Например, через установленный pipx:

```sh
pipx install 'uv==0.11.28'
uv --version
```

Из корня checkout:

```sh
uv sync --locked --python python3.11
uv run --locked python -m oko --demo
./scripts/check all
```

uv создаёт `.venv` внутри checkout. Группа `dev` устанавливается по умолчанию: тесты, генераторы API и типизация. Проект запускается из исходников; `package = false` исключает сборку и установку самого Око. Backend упаковки не нужен.

`--locked` проверяет соответствие `uv.lock` и `pyproject.toml` и завершает команду ошибкой при расхождении. Обычная установка и CI не обновляют lock. `--frozen` для этой задачи не подходит: он пропускает проверку актуальности lock.

Для подготовки frontend нужны npm-зависимости: [запуск из checkout](package.md). Runner и генераторы принимают `OKO_PYTHON`; обычно они используют `.venv/bin/python`. После синхронизации runner запускает проверки напрямую из готового окружения; отдельного `uv sync` перед каждой группой нет.

В минимальном Linux-образе нужен системный пакет `tzdata`: приложение использует IANA-часовые пояса через стандартный `zoneinfo`. Обычные macOS и Ubuntu CI images предоставляют эту базу на уровне ОС.

## Изменение зависимостей

```sh
uv add пакет
uv add --dev инструмент
uv lock --upgrade-package пакет
```

Проверяйте diff `pyproject.toml` и `uv.lock` и запускайте затронутые проверки. Обновление всех библиотек требует отдельного решения.

## Переход существующего checkout

Когда потребуется переключить локальное окружение, штатно остановите свой экземпляр Око и выйдите из активированной `.venv`. Сохраните прежнее окружение вне checkout, затем выполните команды настройки выше. Синхронизация удаляет пакеты, отсутствующие в lock, поэтому её нельзя выполнять поверх окружения работающего экземпляра.

Для отката восстановите согласованные конфигурацию, lock-файл и инструкции предыдущего коммита. Верните сохранённое окружение на исходный путь `.venv` либо создайте его заново. Virtualenv не следует запускать из переименованного каталога: его scripts содержат абсолютные пути.

## CI и запуск приложения

Ubuntu job использует Python 3.11 и закреплённый uv. CI кэширует загруженные пакеты uv, а не `.venv`; `uv sync --locked` создаёт и проверяет окружение перед проверками даже при попадании в кэш. Затем CI запускает runner напрямую. Расширение Python/platform matrix — отдельная задача; проверки macOS выполняются на временных данных.

Приложение запускается из checkout. Сборка и проверка установочного пакета временно удалены.
