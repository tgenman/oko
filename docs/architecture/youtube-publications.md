# YouTube в Publication

После офлайн-миграции YouTube использует общий FeedAdapter: resolve_feed,
cursor_before, discover и fetch возвращают внешние ключи и описания; Store
владеет UUID, файлами, jobs и короткими транзакциями. Ключ Feed — ID канала,
ключ Publication — ID видео. Видео остаётся внешней ссылкой.

Обложка и UTF-8 субтитры — независимые MediaFile. Runtime допускает отдельную
операцию субтитров, поэтому задержка обложки не задерживает текст и обработку.
Действующие настройки доступа YouTube, прокси и интервалы субтитров сохраняются.
Видеопоток и аудиопоток не скачиваются. Обложка проверяется по MIME/сигнатуре,
лимит обложки и субтитров — 2 000 000 байт.

В content находятся ссылки на media_id и extra.youtube с состоянием и digest
субтитров. Исходный текст читается из MediaFile. Фильтр работает с исходными
субтитрами, filter_out запрещает тезисы; тезисы YouTube используют исходный текст.
Подтверждённое отсутствие субтитров завершает обработку пустым результатом без
модели. Ошибка получения оставляет неизвестный вход и повторяемую ошибку.

Повторное окно Atom проверяет метаданные и обложку, сохраняя скачанные субтитры.
Retry Download отдельно перепроверяет субтитры. Неизменные байты сохраняют ID и
результаты; изменённые получают новый ID и требуют новой обработки. Ошибка
перепроверки сохраняет последнюю проверенную копию. Прежний URL файла никогда
не начинает отдавать новое содержимое. Подтверждённое исчезновение удаляет текущую
ссылку и прежние результаты; последующее появление получает новый файл.

Подбор истории фиксирует верхнюю границу, выдаёт от старых к новым и сохраняет
непрозрачный курсор между порциями. Недобор отображается как предупреждение.
Пауза не продвигает курсор, отмена завершает текущий подбор. Legacy-путь остаётся
доступным до переноса хранилища; мигратор работает только с новой офлайн-копией,
сохраняя исходную базу и резервную копию.
