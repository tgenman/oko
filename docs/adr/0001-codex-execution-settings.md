# Выбор модели Codex отделён от актуальности готового результата

Для фильтрации и тезисов одной публикации выбираются отдельные модель, усилие рассуждения и Fast. Изменения применяются только к новой работе. Готовые результаты сохраняются; начатая работа продолжает использовать зафиксированные при её начале параметры. Это предотвращает неожиданный массовый пересчёт.

Происхождение результата хранится отдельно от правил его актуальности. Изменения исходников, промптов, обработчика и разрешений учитываются при проверке актуальности; явное пересоздание использует текущий выбор модели.

Фактические результаты прежней версии сохранены в [отчёте](../verification/codex-model-settings.md).
