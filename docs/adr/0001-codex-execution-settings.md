# Выбор модели Codex отделён от актуальности готового результата

2026-10-13: пользователь выбрал отдельные модель, усилие рассуждения и Fast для четырёх типов обработки, с применением изменений только к новой работе. Готовые результаты сохраняются, а начатая работа, включая все этапы обзора и восстановление после перезапуска, продолжает использовать зафиксированные при её начале параметры: это предотвращает неожиданный массовый пересчёт и смешение моделей внутри одного обзора. Происхождение результата хранится отдельно от правил его актуальности; изменения исходников, промптов, обработчика и разрешений продолжают учитываться по существующим правилам, а явное пересоздание использует текущий выбор модели.
