# Документация Око для человека

Здесь постепенно фиксируем согласованную модель продукта и архитектуру простым языком.
Открытые вопросы и предложения отмечаем отдельно от принятых решений.

Интервью завершено. [Спецификация в GitHub — #89](https://github.com/tgenman/oko/issues/89). **Итоговая [спецификация](https://github.com/tgenman/oko/issues/89)**
сводит решения и закрывает оставшиеся детали по поручению пользователя (KISS).
При расхождениях со старыми эскизами действует итоговая спецификация;
миграция и design-review сохраняют историю обсуждения.

Документы сохраняют согласованную модель и историю проектирования. Сведения о
SQLite и этапах перехода относятся к моменту проектирования; действующее хранилище
описано в [PostgreSQL](../development/postgresql.md).
