# Статусы локального трекера

`Status:` отражает текущее состояние документа. `Label: ready-for-agent`, если присутствует, отмечает подготовленность описания и не заменяет статус выполнения.

## Спецификации и задачи реализации

- `ready-for-agent` — описание готово к работе. Зависимости и разрешённый пользователем объём проверяются перед началом.
- `claimed` — задачу взял исполнитель; `Assignee:` указывает владельца.
- `done` — критерии приёмки выполнены, проверки и результат зафиксированы.

## Вопросы и исследования wayfinder

- `open` — вопрос ещё не взят.
- `claimed` — вопрос взят исполнителем.
- `resolved` — ответ записан в `Answer` и связан с картой.

Разрешение на реализацию берётся из задания пользователя. Готовность спецификации сама по себе его не предоставляет. Задачи реализации завершены при `done`, вопросы исследования — при `resolved`; зависимости читаются с учётом типа документа. Расположение файлов и остальные соглашения: [issue-tracker.md](issue-tracker.md).
