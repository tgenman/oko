    Завершить разбор папки

    Удалятся тексты, медиа и сводки всей папки, включая скрытые материалы. Другие папки останутся.

    Сжать историю папки

    По умолчанию — всё непросмотренное. Оригиналы останутся доступны до отметки «Просмотрено».

    Подписки и настройки

    RSS/Atom собираются при открытой вкладке. Telegram через RSS требует явного выбора ограниченного подключения. Тезисы доступны через подключённую модель llama.cpp. Настройки сохраняются локально.

    Импорт OPML
    Подключить Telegram-канал или группу

    Используется существующий клиент, указанный при запуске. Приватный источник: ID диалога из Telegram MCP. Forum topics пока не поддерживаются. Отметки прочитанного пока не отправляются.

    Модель llama.cpp

    Codex

    Используется существующий вход CLI. Перед обработкой требуется разрешение публичного AI. Одноразовый запуск изолирован внешним sandbox на macOS. Поддерживается проверенная сборка CLI; другая версия остаётся недоступной до проверки. Текст передаётся через память, временные файлы удаляются после задания.

    Представление и обработка

    Каждое поле наследуется отдельно: Око → папка → фид. «Сбросить» возвращает значение родительского уровня. Расписание действует только при работающем Око.
