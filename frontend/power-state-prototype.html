Выключить и снова включить Око

Проверяем поведение одной кнопки: после выключения Stop заменяется на Start на том же месте. Во время перехода повторное нажатие недоступно.

Это автономная модель с вымышленными материалами. Запуск и остановка имитируются; личные источники не используются.

Сценарии

Граница реализации: сегодня Stop завершает HTTP-сервер и закрывает хранилище. Для настоящего Start потребуется доступный после выключения механизм запуска. Этот прототип проверяет поведение кнопки; способ запуска ещё не выбран. Остальные кнопки шапки показаны только для контекста.
