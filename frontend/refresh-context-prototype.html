«Обновить» в меню папки и фида

Проверяем одну команду: собрать последние обновления от текущего указателя и повторить недокачанные материалы и ошибки сбора. У папки команда охватывает её фиды. Данные вымышленные, всё состояние — в памяти.

△ Око

Нажмите ⋯ или правую кнопку мыши на папке либо фиде. Меню оставлено открытым для сравнения состояний команды.

Свободная проверка

Завершение работы моделируется кнопками. Указатели здесь условные: числа помогают видеть, что повтор загрузки старого материала не отматывает сбор нового.

Сценарии

Предположения для обсуждения: уже работающий фид не запускается второй раз; сбой одного фида не мешает другим; неуспешные загрузки остаются для следующего повтора. «Ошибки» здесь относятся к сбору, поведение ошибок ИИ-обработки этим прототипом не определяется. Реальное API и правила допустимости ретраев ещё предстоит согласовать.
