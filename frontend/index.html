    Модели

    Подключение модели и выбор обработчика задаются отдельно.

    llama.cpp

    Сервер выполняет модель на этом компьютере, без прокси и удалённого RPC. При изменении адреса или модели подтвердите этот режим заново.

    Проверяется сохранённое подключение. Проверка не сохраняет введённые значения.

    Codex

    Используется существующий вход CLI. Перед обработкой требуется разрешение публичного AI.

    Fast увеличивает расход лимита. По умолчанию выключен.

    Одноразовый запуск изолирован внешним sandbox на macOS. Поддерживается проверенная сборка CLI; другая версия остаётся недоступной до проверки. Текст передаётся через память, временные файлы удаляются после задания.

    Субтитры YouTube

    Пустые поля сохраняют прежние учётные данные. Чтобы удалить их, отметьте действие выше и сохраните подключение.

    Прокси используется только для субтитров. Сохранение не запускает проверку YouTube.
